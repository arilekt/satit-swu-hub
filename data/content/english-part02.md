## เป้าหมายของบทนี้

- ขอร้องอย่างสุภาพด้วย Can/Could you ...? และ Do/Would you mind + V-ing? และตอบรับ/ปฏิเสธได้ถูก
- แสดงความเห็นด้วย/ไม่เห็นด้วย โดยใช้ So do I / Neither do I ให้ถูกกริยาช่วย
- ชื่นชมผู้อื่นด้วยประโยคอุทาน What a ...! / How ...! และตอบคำชมอย่างสุภาพ
- เชิญชวนด้วย Would you like to ...? / How about + V-ing? และตอบรับ/ปฏิเสธคำเชิญ
- อ่านบทสนทนายาว (Example 1–5) แล้วจับได้ว่าเป็นสถานการณ์อะไร ใช้สำนวนอะไร

## 11 Requesting (การขอร้อง)

### รูปประโยคขอร้อง (จากสุภาพน้อย → สุภาพมาก)

| รูปประโยค | ตัวอย่าง |
|---|---|
| Can you + V1? | Can you pass me the salt? |
| Could you (please) + V1? | Could you please open the window? |
| Do you mind + V-ing? | Do you mind closing the door? |
| Would you mind + V-ing? | Would you mind lending me your pen? |
| May I + V1? (ขออนุญาตทำเอง) | May I use your phone? |
| Do you mind if I + V1? | Do you mind if I sit here? |

จำให้แม่น: หลัง **mind** ต้องตามด้วย **V-ing** เสมอ (mind closing ไม่ใช่ mind to close)

### การตอบรับ / ปฏิเสธคำขอร้อง

| ตอบรับ | ปฏิเสธ (สุภาพ ต้องบอกเหตุผล) |
|---|---|
| Sure. / Of course. / Certainly. | I'm sorry, but I can't. I'm busy now. |
| No problem. | I'm afraid I can't. I need it today. |
| Here you are. (ยื่นของให้) | Sorry, I'm using it right now. |

### กับดักใหญ่: ตอบ Do you mind ...?

mind แปลว่า "รังเกียจ/ขัดข้อง" คำถามจึงแปลว่า "คุณขัดข้องไหมถ้า..."

- ถ้า **ยินดีทำ** ตอบ **No, not at all.** / No, of course not. (= ไม่ขัดข้องเลย)
- ถ้า **ไม่สะดวก** ตอบ I'm sorry, but ... (การตอบ Yes, I do. = ขัดข้อง ซึ่งฟังแรงมาก)

## 12 Expressing Opinion (การแสดงความคิดเห็น)

ขึ้นต้นความเห็น: I think ... / I believe ... / In my opinion, ... / I feel that ...

| เห็นด้วย | ไม่เห็นด้วย |
|---|---|
| I agree (with you). | I don't agree. / I disagree. |
| So do I. / Me too. | I'm not sure. (ไม่แน่ใจ) |
| That's true. / You're right. | I don't think so. |
| Exactly! / Absolutely! | I see your point, but ... (สุภาพที่สุด) |

### สูตร So ... / Neither ... (เห็นด้วยแบบสั้น)

- ประโยคบอกเล่า → **So + กริยาช่วย + I**
- ประโยคปฏิเสธ → **Neither + กริยาช่วย + I** (หรือ Me neither)
- กริยาช่วยต้อง "ตรงกับ" ประโยคแรก

| ประโยคของเพื่อน | เห็นด้วย |
|---|---|
| I like cats. | So do I. |
| She likes cats. → ถ้าเราตอบแทนตัวเอง | So do I. |
| I am hungry. | So am I. |
| I can swim. | So can I. |
| I went to the zoo. | So did I. |
| I don't like durian. | Neither do I. |
| I can't dance. | Neither can I. |
| I'm not tired. | Neither am I. |

ระวัง: Neither เป็นความหมายปฏิเสธอยู่แล้ว ห้ามใส่ not ซ้ำ (Neither don't I ผิด)

## 13 Admiring (การชื่นชม)

| ชมสิ่งของ/ผลงาน | ชมโดยตรง |
|---|---|
| That's great / wonderful / amazing! | I really like your new bag. |
| Brilliant! / Well done! / Good job! | You look great in that dress. |
| What a beautiful picture! | You're a great singer! |

### โครงสร้างประโยคอุทาน (Exclamation)

| สูตร | ตัวอย่าง |
|---|---|
| What + a/an + adj + นามเอกพจน์! | What a beautiful day! / What an easy test! |
| What + adj + นามพหูพจน์/นับไม่ได้! | What lovely flowers! / What nice weather! |
| How + adj + (S + V)! | How beautiful! / How kind you are! |

การตอบคำชมแบบฝรั่ง: ไม่ปฏิเสธคำชม แต่ **ขอบคุณ** เช่น Thank you. / Thanks, I'm glad you like it. / That's very kind of you.

## 14 Inviting (การเชิญชวน)

| การเชิญ | ตัวอย่าง |
|---|---|
| Would you like to + V1? | Would you like to come to my party? |
| Would you like + N? | Would you like some tea? |
| How about + V-ing / N? | How about going to the beach? |
| What about + V-ing? | What about watching a movie? |
| Why don't we + V1? | Why don't we have lunch together? |
| Let's + V1. | Let's go swimming. |
| Shall we + V1? | Shall we go biking? |

| ตอบรับ | ปฏิเสธ (สุภาพ + เหตุผล) |
|---|---|
| I'd love to. / I'd like that. | I'd love to, but I have to study. |
| That sounds great! / Sounds good! | Sorry, I can't. I'm busy on Saturday. |
| Sure, why not? / Good idea! | Maybe next time. Thanks for asking. |

ระวังรูปกริยา: Would you like **to go** / How about **going** / Why don't we **go** / Let's **go**

## บทสนทนาตัวอย่าง (Example 1–5) สรุปสาระ

เอกสารหน้า 8–9 มีบทสนทนา 5 ชุด ให้ฝึกจับ "สถานการณ์" และ "สำนวนสำคัญ"

| ชุด | สถานการณ์ | สำนวนที่ควรจำ |
|---|---|---|
| Example 1 | ถามทาง–บอกทาง | how can I get to ...?, Could you give me directions to ...?, turn left, go ahead, It is between A and B. |
| Example 2 | ผู้ป่วยคุยกับหมอ | How are you feeling today?, I have a sore throat / a fever, symptoms (อาการ), prescription (ใบสั่งยา), How often should I take it?, twice a day |
| Example 3 | ขอให้คนแปลกหน้าช่วย แล้วขอบคุณ | Sorry for bothering you, but could you ...?, No problem!, Thank you so much!, Have a nice day! – You too! |
| Example 4 | คุยเรื่องอากาศแล้วชวนไปเที่ยว / ยกเลิกปิกนิก | How's the weather?, What a beautiful day!, cloudy and cool, Shall we go biking?, Sounds great!, I think it's going to rain., I guess so. |
| Example 5 | ขอบคุณที่ช่วยทำรายงาน / ขอโทษที่ผิดนัด | I can't thank you enough, Don't mention it, return the favor (ตอบแทนน้ำใจ), stand someone up (นัดแล้วไม่มา), There was an urgent incident. |

ข้อสังเกตจากบทสนทนา

- "Sorry for bothering you, but ..." = ขอโทษที่รบกวน (ขึ้นต้นก่อนขอร้อง สุภาพมาก)
- "How often should I take it?" ถามความถี่ ตอบด้วย once / twice / three times a day
- "I think it's going to rain." ใช้ be going to เพราะเห็นหลักฐาน (เมฆดำ)
- "Don't mention it." เป็นคำตอบของ "I can't thank you enough."

## ตัวอย่างวิธีคิด

**ตัวอย่าง 1:** A: Would you mind turning down the music? B: ______ I'll do it right now.

1. คำถาม Would you mind ... = ขัดข้องไหม
2. ประโยคหลังบอกว่า "จะทำเดี๋ยวนี้" → B ยินดี → ต้องตอบปฏิเสธว่า "ไม่ขัดข้อง"
3. คำตอบ: No, not at all. (ตัวลวง Yes, I do. = ขัดข้อง ขัดกับประโยคหลัง)

**ตัวอย่าง 2:** A: I can't speak Japanese. B: ______

1. ประโยคแรกเป็นปฏิเสธ และใช้กริยาช่วย can
2. เห็นด้วย → Neither + can + I
3. คำตอบ: Neither can I. (ไม่ใช่ So can I หรือ Neither do I)

**ตัวอย่าง 3:** ______ to the cinema with us tonight? – I'd love to!

1. คำตอบ I'd love to แสดงว่าเป็นการเชิญด้วย Would you like ...?
2. Would you like ตามด้วย to + V1
3. คำตอบ: Would you like to come (ไม่ใช่ How about come / Would you like coming)

**ตัวอย่าง 4:** เพื่อนวาดรูปสวย เราชมว่า ______!

1. picture เป็นนามนับได้เอกพจน์ → What + a + adj + N
2. คำตอบ: What a beautiful picture! (ไม่ใช่ What beautiful picture! หรือ How a beautiful picture!)

## จุดที่มักสับสน

| สับสน | วิธีแยก |
|---|---|
| Do you mind ...? ตอบ Yes / No | No, not at all = ยินดีทำ / Yes, I do = ขัดข้อง |
| mind to do vs mind doing | ต้องเป็น mind + V-ing เท่านั้น |
| So do I vs So am I vs So can I | ดูกริยาช่วยในประโยคแรก |
| So do I vs Neither do I | บอกเล่า → So / ปฏิเสธ → Neither |
| Would you like to go vs How about going | like + to V1 / about + V-ing |
| What a ...! vs How ...! | What + (a/an) + adj + N / How + adj |
| ตอบคำชม | ฝรั่งตอบ Thank you ไม่ใช่ You're welcome |
| Can I ...? vs Can you ...? | ขออนุญาตทำเอง vs ขอให้อีกฝ่ายทำ |

## ⭐ Key Takeaways

- ขอร้องสุภาพ: Could you please + V1? / Would you mind + V-ing?
- ตอบ Do you mind ...? ว่า No, not at all เมื่อยินดีทำ
- เห็นด้วยสั้น ๆ: บอกเล่า So + aux + I, ปฏิเสธ Neither + aux + I (กริยาช่วยต้องตรงกัน)
- ชมด้วย What a/an + adj + N! หรือ How + adj! และตอบคำชมด้วย Thank you
- เชิญ: Would you like to + V1 / How about + V-ing / Why don't we + V1 / Let's + V1
- ปฏิเสธคำเชิญสุภาพ: I'd love to, but ... (บอกเหตุผล)
- อ่านบทสนทนายาว: หาว่า "ใครคุยกับใคร ที่ไหน เรื่องอะไร" ก่อนตอบ
