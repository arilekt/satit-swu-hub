## เป้าหมายของบทนี้

- แยกประโยคเงื่อนไข If ทั้ง 4 แบบ (Type 0–3) จากความหมายและรูปกริยา
- ใช้ unless และทำรูปปฏิเสธของประโยค If ได้
- ใช้ wish ได้ 3 กลุ่ม: บอกความต้องการ, อวยพร, ปรารถนาสิ่งที่ไม่เป็นจริง
- เลือกคำบุพบทบอกเวลา สถานที่ ทิศทาง วิธีการ และเหตุผลได้ถูก โดยเฉพาะ in / on / at

## Conditional Sentences (ประโยคเงื่อนไข)

ประโยค If มี 2 ส่วน: **If-clause** (เงื่อนไข) + **main clause** (ผล)
ถ้า If ขึ้นต้นประโยค ให้ใส่ comma คั่น: If it rains, we will stay home.
ถ้า If อยู่กลาง ไม่ต้องใส่ comma: We will stay home if it rains.

### ตารางสรุป IF Clause

| Type | ความหมาย | If-clause | Main clause | ตัวอย่าง |
|---|---|---|---|---|
| 0 | ความจริงทั่วไป/วิทยาศาสตร์ | If + S + V1 | S + V1 | If you heat ice, it melts. |
| 1 | เป็นไปได้จริงในอนาคต | If + S + V1 | S + will + Vinf | If it rains tomorrow, we will stay home. |
| 2 | สมมติ ไม่จริงในปัจจุบัน | If + S + V2 / were | S + would + Vinf | If I had wings, I would fly. |
| 3 | สมมติ ไม่จริงในอดีต | If + S + had + V3 | S + would have + V3 | If she had studied, she would have passed. |

### รูปปฏิเสธ

| Type | ตัวอย่างปฏิเสธ |
|---|---|
| 0 | If you don't water plants, they die. |
| 1 | If you don't hurry, you will miss the bus. |
| 2 | If I didn't have homework, I would go out. |
| 3 | If he hadn't been sick, he wouldn't have missed the trip. |

### ข้อสังเกต

- Type 2 ใช้ **were** กับทุกประธาน (โดยเฉพาะ If I were you, I would ... = คำแนะนำ)
- ความหมายตรงข้ามความจริง: If I **had** wings (ความจริง: ไม่มีปีก) / If she **had studied** (ความจริง: ไม่ได้อ่าน)
- **unless = if ... not**: Unless you hurry, you will be late. = If you don't hurry, you will be late.
- ห้ามใช้ will ใน If-clause: If it **will rain** (ผิด) → If it **rains**

## Wish Sentences

### 1. บอกความต้องการ (ทางการ = want)

โครงสร้าง: **S + wish + to + Vinf**
EX: I wish to speak to the manager. / She wishes to join the club.

### 2. แสดงความปรารถนาดี (อวยพร)

โครงสร้าง: **S + wish + O (คน) + N (สิ่งที่อวยพร)**
EX: I wish you good luck. / We wish you a Merry Christmas. / I wish you a happy birthday.

### 3. บอกความปรารถนาในสิ่งที่ไม่เป็นจริง (มี 3 แบบ)

| เวลา | โครงสร้าง | ตัวอย่าง | ความจริงคือ |
|---|---|---|---|
| ปัจจุบัน | S + wish + S + V2 / were | I wish I had a bike. / I wish I were taller. | ไม่มีจักรยาน / ไม่สูง |
| อดีต | S + wish + S + had + V3 | I wish I had gone to the party. | ไม่ได้ไปงาน |
| อนาคต | S + wish + S + would/could + Vinf | I wish it would stop raining. | ฝนยังไม่หยุด |

เคล็ดลับ: wish แบบ 3 "ถอย tense ไปหนึ่งขั้น" จากความจริง (ปัจจุบัน → V2, อดีต → had + V3)

## Prepositions (คำบุพบท)

**Preposition** คือคำที่วางหน้านามหรือสรรพนาม เพื่อบอกความสัมพันธ์ด้านเวลา สถานที่ ทิศทาง วิธีการ หรือเหตุผล
EX: The book is **on** the table. / I was born **in** May.
หลัง preposition ถ้าเป็นกริยาต้องใช้ V-ing: She is good **at drawing**.

### 1. Preposition บ่งบอกเวลา

| คำ | ใช้กับ | ตัวอย่าง |
|---|---|---|
| in | เดือน ปี ฤดู ศตวรรษ ช่วงของวัน | in May, in 2014, in summer, in the morning |
| on | วัน วันที่ วันพิเศษ | on Monday, on 5 June, on my birthday, on Saturday evening |
| at | เวลาตามนาฬิกา จุดเวลา | at 8:30, at noon, at night, at midnight |
| since / for | ตั้งแต่ / เป็นเวลา | since 2020 / for two weeks |
| before / after / until / during | ก่อน / หลัง / จนกระทั่ง / ระหว่าง | during the holiday |

ไล่จากใหญ่ไปเล็ก: **in** (ช่วงใหญ่) → **on** (วัน) → **at** (จุดเวลา)
ระวัง: in the morning แต่ **on** Monday morning (มีวันเจาะจง → on)

### 2. Preposition บ่งบอกสถานที่

| คำ | ความหมาย | ตัวอย่าง |
|---|---|---|
| in | ข้างใน / เมือง ประเทศ | in the box, in Bangkok |
| on | บนพื้นผิว | on the table, on the wall |
| at | ณ จุด / สถานที่เฉพาะ | at home, at school, at the bus stop |
| under / above / over | ใต้ / เหนือ (ไม่สัมผัส) | under the bed, above the door |
| next to / beside | ข้าง ๆ | next to the bank |
| between ... and ... | ระหว่าง (2 สิ่ง) | between the bank and the park |
| behind / in front of | ข้างหลัง / ข้างหน้า | behind the school |
| opposite | ตรงข้าม | opposite the hospital |

### 3. Preposition บ่งบอกทิศทาง (การเคลื่อนที่)

| คำ | ความหมาย | ตัวอย่าง |
|---|---|---|
| to | ไปยัง | go to school |
| into / out of | เข้าไปใน / ออกจาก | walk into the room / run out of the house |
| onto | ขึ้นไปบน | jump onto the bed |
| across | ข้าม (ผ่านผิวหน้า) | walk across the road |
| through | ทะลุผ่าน | go through the tunnel |
| along | ไปตาม | walk along the river |
| up / down | ขึ้น / ลง | climb up the hill |
| towards | มุ่งไปทาง | run towards the gate |

### 4. Preposition บ่งบอกวิธีการ

| คำ | ตัวอย่าง |
|---|---|
| by + พาหนะ / วิธีสื่อสาร | by bus, by car, by email, by hand |
| on foot (เดิน) | I go to school on foot. (ไม่ใช่ by foot) |
| with + เครื่องมือ | cut it with a knife, write with a pen |
| in + ภาษา / สี / หมึก | write in English, written in pencil |

### 5. Preposition บ่งบอกเหตุผล

| คำ | ตัวอย่าง |
|---|---|
| because of + นาม | We stayed home because of the rain. |
| due to + นาม | The flight was late due to bad weather. |
| thanks to + นาม (ด้วยดี) | Thanks to your help, I passed. |
| for | Thank you for your help. / famous for its food |

ระวัง: because + ประโยค (because it rained) / **because of + นาม** (because of the rain)

## ตัวอย่างวิธีคิด

**ตัวอย่าง 1:** If I ______ a million baht, I would travel around the world.

1. main clause ใช้ would + Vinf → Type 2 (สมมติไม่จริงในปัจจุบัน)
2. If-clause ใช้ V2
3. คำตอบ: had

**ตัวอย่าง 2:** I didn't bring my umbrella, and now I'm wet. I wish I ______ my umbrella.

1. ความจริงในอดีต: ไม่ได้เอาร่มมา
2. wish เรื่องอดีต → S + wish + S + had + V3
3. คำตอบ: had brought

**ตัวอย่าง 3:** The concert starts ______ 7 p.m. ______ Friday.

1. 7 p.m. เป็นเวลาตามนาฬิกา → at
2. Friday เป็นวัน → on
3. คำตอบ: at / on

**ตัวอย่าง 4:** You will fail ______ you study harder.

1. ความหมาย: ถ้าไม่ขยัน จะสอบตก
2. "ถ้า...ไม่" = unless
3. คำตอบ: unless

## จุดที่มักสับสน

| สับสน | วิธีแยก |
|---|---|
| If it will rain | ห้าม will ใน If-clause → If it rains |
| Type 1 vs Type 2 | เป็นไปได้จริง (V1 / will) vs สมมติ (V2 / would) |
| If I was you | ในข้อสอบใช้ If I were you |
| would pass vs would have passed | ปัจจุบันสมมติ vs อดีตสมมติ (Type 3) |
| I wish I have | wish สิ่งไม่จริงต้องถอย tense → I wish I had |
| in / on Monday | วันใช้ on |
| in the morning / on Monday morning | ช่วงวันทั่วไปใช้ in แต่มีวันเจาะจงใช้ on |
| by foot | ผิด → on foot |
| because vs because of | + ประโยค vs + นาม |
| in vs into | อยู่ข้างใน (นิ่ง) vs เคลื่อนเข้าไป |

## ⭐ Key Takeaways

- Type 0: V1, V1 (ความจริง) / Type 1: V1, will + Vinf (เป็นไปได้)
- Type 2: V2/were, would + Vinf (สมมติปัจจุบัน) / Type 3: had + V3, would have + V3 (สมมติอดีต)
- unless = if ... not และห้ามใช้ will ใน If-clause
- wish to + Vinf = ต้องการ / wish + คน + สิ่งดี = อวยพร / wish + S + V2 หรือ had + V3 = เสียดาย
- in (เดือน ปี ช่วง) – on (วัน วันที่) – at (เวลา จุด)
- into = เข้าไปใน, across = ข้าม, on foot = เดิน, by bus = ด้วยรถบัส
- because of + นาม / because + ประโยค
