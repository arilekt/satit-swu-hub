## เป้าหมายของบทนี้

- แยกนามนับได้กับนับไม่ได้ เพื่อเลือก quantifier ให้ถูก
- ใช้ some / any ตามชนิดประโยค (บอกเล่า ปฏิเสธ คำถาม ข้อเสนอ)
- แยก a few / a little / few / little และ much / many / a lot of
- ใช้คำประสม everybody, something, anything, nothing ... และกริยาให้สอดคล้อง

## พื้นฐาน: นามนับได้ vs นามนับไม่ได้

| นามนับได้ (Countable) | นามนับไม่ได้ (Uncountable) |
|---|---|
| มีรูปเอกพจน์/พหูพจน์: an apple, two apples | ไม่เติม s ไม่ใช้ a/an: water, rice |
| book, egg, student, car, friend | water, milk, rice, sugar, money, time, information, homework, advice, bread, ice |
| ถามจำนวน How many ...? | ถามปริมาณ How much ...? |

กับดัก: money, information, homework, advice นับไม่ได้ (ไม่มี informations, homeworks)

## Quantifiers (คำบอกปริมาณ)

เอกสารแบ่งเป็น 3 กลุ่ม

| มีอยู่บ้าง | มีน้อย | มีมาก |
|---|---|---|
| some, any | a few, a little, few, little | many, much, a lot of, lots of |

## Some / Any

| คำ | ใช้กับ | ใช้ในประโยค | ตัวอย่าง |
|---|---|---|---|
| some | นามนับได้พหูพจน์ + นามนับไม่ได้ | บอกเล่า | There are some apples. / I need some water. |
| some | — | คำถามเชิงเสนอหรือขอ | Would you like some tea? / Can I have some water? |
| any | นามนับได้พหูพจน์ + นามนับไม่ได้ | ปฏิเสธ | I don't have any money. |
| any | — | คำถามทั่วไป | Are there any eggs? / Is there any milk? |
| any | — | บอกเล่า = "อันไหนก็ได้" | You can take any book you like. |

ทริก: **some = บอกเล่า + เสนอ/ขอ**, **any = ปฏิเสธ + คำถาม + อันไหนก็ได้**

## (a) Few / (a) Little

| คำ | ใช้กับ | ความหมาย | ตัวอย่าง |
|---|---|---|---|
| a few | นามนับได้พหูพจน์ | มีอยู่บ้าง (พอใช้ มองบวก) | I have a few friends here, so I'm happy. |
| few | นามนับได้พหูพจน์ | มีน้อยมาก แทบไม่มี (มองลบ) | Few people came. The room was nearly empty. |
| a little | นามนับไม่ได้ | มีอยู่บ้าง (พอใช้) | There is a little milk. Let's make tea. |
| little | นามนับไม่ได้ | มีน้อยมาก แทบไม่มี | We have little time. Hurry up! |

What is a few & a little? = "มีอยู่บ้างจำนวนหนึ่ง" ส่วนถ้า **ไม่มี a** ความหมายจะติดลบว่า "แทบไม่มี"
จำ: **มี a = มีบ้าง (ดี) / ไม่มี a = แทบไม่มี (แย่)**
very ใช้นำหน้า few/little ได้ (very little time) แต่ไม่ใช้กับ a few/a little (very a little ผิด)

## Much / Many / A lot of

| คำ | ใช้กับ | มักใช้ใน | ตัวอย่าง |
|---|---|---|---|
| many | นามนับได้พหูพจน์ | ทุกแบบ (นิยมปฏิเสธ/คำถาม) | There aren't many people here. / How many books? |
| much | นามนับไม่ได้ | ปฏิเสธ/คำถาม | I don't have much time. / How much money? |
| a lot of / lots of | ทั้งนับได้และนับไม่ได้ | บอกเล่า | She has a lot of friends. / He drinks a lot of water. |

ประโยคบอกเล่าทั่วไปนิยม a lot of มากกว่า much เช่น I have a lot of homework. (ฟังเป็นธรรมชาติกว่า I have much homework.)

## Every... / Some... / Any... / No...

| | -body / -one (คน) | -thing (สิ่ง) | -where (ที่) |
|---|---|---|---|
| every- (ทุก) | everybody / everyone | everything | everywhere |
| some- (บาง/ใครบางคน) | somebody / someone | something | somewhere |
| any- (ใคร/อะไร ใด ๆ) | anybody / anyone | anything | anywhere |
| no- (ไม่มี) | nobody / no one | nothing | nowhere |

### การใช้

| คำ | การใช้ | ตัวอย่าง |
|---|---|---|
| Every + นามเอกพจน์ / every- | ทุก ๆ คน/สิ่ง (มองทีละหน่วย) กริยาเอกพจน์ | Every student has a book. / Everyone is here. |
| Some + / some- | ประโยคบอกเล่า และคำถามเชิงเสนอ | Someone is at the door. / Would you like something to drink? |
| Any + / any- | ประโยคปฏิเสธและคำถาม | I didn't see anybody. / Is there anything I can do? |
| No + นาม / no- | มีความหมายปฏิเสธในตัว ใช้กับกริยาบอกเล่า | There is nothing in the box. / Nobody knows. / There is no milk. |

### กฎสำคัญ

- everyone, everybody, everything, nobody, nothing ใช้ **กริยาเอกพจน์**: Everybody **is** happy. / Nothing **is** impossible.
- **ห้ามปฏิเสธซ้อน**: I don't know nothing (ผิด) → I don't know anything. หรือ I know nothing.
- adjective วางหลังคำประสม: something **new**, nothing **special**, somewhere **quiet**

## ตัวอย่างวิธีคิด

**ตัวอย่าง 1:** There aren't ______ students in the library today.

1. ประโยคปฏิเสธ (aren't) + students นับได้พหูพจน์
2. ตัวเลือกที่เข้ากับปฏิเสธ + นับได้: any หรือ many
3. คำตอบ: any (หรือ many ถ้าตัวเลือกให้ความหมาย "ไม่มาก")

**ตัวอย่าง 2:** I have ______ money, so I can buy a snack.

1. money นับไม่ได้ → a little / little
2. "จึงซื้อขนมได้" = มีพอใช้ (มองบวก) → a little
3. คำตอบ: a little

**ตัวอย่าง 3:** I looked in the box, but there was ______ in it.

1. ประโยคบอกเล่า (was) แต่ความหมาย "ไม่มีอะไร"
2. no- + thing → nothing (กริยาบอกเล่าอยู่แล้ว ไม่ปฏิเสธซ้อน)
3. คำตอบ: nothing

**ตัวอย่าง 4:** Everyone in my family ______ fruit.

1. everyone ใช้กริยาเอกพจน์
2. Present Simple เอกพจน์ → likes
3. คำตอบ: likes

## จุดที่มักสับสน

| สับสน | วิธีแยก |
|---|---|
| some vs any | บอกเล่า/เสนอ vs ปฏิเสธ/คำถาม |
| a few vs a little | นับได้ vs นับไม่ได้ |
| a little vs little | มีบ้าง (บวก) vs แทบไม่มี (ลบ) |
| many vs much | นับได้ vs นับไม่ได้ |
| informations / homeworks | นามนับไม่ได้ไม่เติม s |
| Everyone are | everyone ใช้กริยาเอกพจน์ → is |
| I don't have nothing | ปฏิเสธซ้อน → I don't have anything |
| interesting something | something interesting |

## ⭐ Key Takeaways

- นามนับไม่ได้ (water, money, time, information, homework) ไม่เติม s และใช้ much / a little
- some = บอกเล่าและคำเสนอ, any = ปฏิเสธ คำถาม หรือ "อันไหนก็ได้"
- a few (นับได้) / a little (นับไม่ได้) = มีบ้าง; few / little = แทบไม่มี
- many + นับได้, much + นับไม่ได้, a lot of ใช้ได้ทั้งคู่ในประโยคบอกเล่า
- every- / no- ใช้กริยาเอกพจน์; some- บอกเล่า, any- ปฏิเสธ/คำถาม
- ห้ามปฏิเสธซ้อน: not ... anything = nothing
