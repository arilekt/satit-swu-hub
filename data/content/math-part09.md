## สรุปเนื้อหา PART 09: รูปวงกลม 🔵

### ส่วนประกอบของวงกลม

- **จุดศูนย์กลาง (Center):** จุด O ตรงกลางวงกลม
- **รัศมี (Radius):** เส้นจากจุด O ไปยังจุดใดๆ บนวงกลม แทนด้วย r
- **เส้นผ่านศูนย์กลาง (Diameter):** เส้นตรงผ่าน O ลากจากจุดบนวงกลมถึงจุดอื่นบนวงกลม d = 2r
- **คอร์ด (Chord):** เส้นตรงเชื่อม 2 จุดบนวงกลม
- **ส่วนโค้ง (Arc):** ส่วนของเส้นรอบวงกลม
- **ความยาวรอบวงกลม (Circumference):** เส้นรอบวงกลม C = 2πr = πd

### สูตรสำคัญ

| ส่วนประกอบ | สูตร |
|----------|------|
| เส้นรอบวงกลม | C = 2πr หรือ C = πd |
| พื้นที่ | A = πr² |
| เส้นผ่านศูนย์กลาง | d = 2r |
| รัศมี | r = d/2 |

### ตัวอย่างโจทย์

**ข้อที่ 1:** วงกลมมีรัศมี 7 ซม. จงหา
- เส้นรอบวงกลม: C = 2π(7) = 14π ≈ 44 ซม.
- พื้นที่: A = π(7)² = 49π ≈ 154 ตร.ซม.

**ข้อที่ 2:** วงกลมมีเส้นรอบวงกลม 44 ซม. จงหารัศมี
- 2πr = 44
- r = 44/(2π) = 44/6.28 ≈ 7 ซม.

**ข้อที่ 3:** วงกลม 2 วง มีรัศมี 3 ซม. และ 5 ซม. ต่างกันเท่าไหร่
- พื้นที่ 1: A₁ = π(3)² = 9π ตร.ซม.
- พื้นที่ 2: A₂ = π(5)² = 25π ตร.ซม.
- ต่างกัน: 25π - 9π = 16π ≈ 50 ตร.ซม.

### หมายเหตุสำคัญ

- ใช้ π ≈ 3.14 หรือ π ≈ 22/7 (ขึ้นอยู่โจทย์)
- เส้นผ่านศูนย์กลางเป็น 2 เท่าของรัศมี
- พื้นที่มีหน่วย ตร.หน่วย (เช่น ตร.ซม., ตร.ม.)
