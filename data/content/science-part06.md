## เป้าหมายของบทนี้

- ใช้กฎของโอห์ม V = I × R และอธิบายวงจรอนุกรม/ขนาน การต่อถ่านไฟฉาย และสัญลักษณ์ไฟฟ้าได้
- อธิบายการสะท้อน การหักเหของแสง การมองเห็นสี ภาพจริง/ภาพเสมือน กระจก เลนส์ และการแก้สายตาได้
- บอกสมบัติของเสียง แยกความดัง (แอมพลิจูด) กับระดับเสียงสูงต่ำ (ความถี่) และตอบโจทย์การทดลองเรื่องเสียงได้
- แยกการนำ การพา การแผ่รังสีความร้อน การเปลี่ยนสถานะ และคำนวณ Q = mcΔt, Q = mL และเปลี่ยนหน่วยอุณหภูมิได้
- บอกได้ว่าเมื่อใดเกิดงานและคำนวณ W = F × S ได้

## 1. ไฟฟ้า

### กฎของโอห์ม

**V = I × R** (ความต่างศักย์ = กระแส × ความต้านทาน)

ใช้สามเหลี่ยมช่วยจำ: V อยู่บน, I กับ R อยู่ล่าง → ปิดตัวที่อยากหา
- หา V → I × R
- หา I → V ÷ R
- หา R → V ÷ I

ความสัมพันธ์ที่ออกสอบ:
- ถ้า R คงที่ **V เพิ่ม → I เพิ่ม** (แปรผันตรง)
- ถ้า V คงที่ **R เพิ่ม → I ลดลง** (แปรผกผัน)

### แม่เหล็กไฟฟ้า

- พันขดลวดรอบแท่งเหล็ก (เช่น ตะปู) แล้วต่อกับถ่านไฟฉาย เมื่อมีกระแสไหล ตะปูจะกลายเป็นแม่เหล็กดูดลวดเสียบกระดาษได้ ตัดไฟ → อำนาจแม่เหล็กหายไป
- **แม่เหล็กไฟฟ้าแรงขึ้นเมื่อ** ① จำนวนถ่านไฟฉายมากขึ้น (กระแสมากขึ้น) ② จำนวนรอบของขดลวดมากขึ้น
- **กฎมือขวา:** กำมือขวารอบขดลวด ให้ **นิ้วทั้งสี่วนตามทิศทางของกระแสไฟฟ้า** แล้ว **นิ้วโป้งจะชี้ไปทางขั้วเหนือ (N)** ของแม่เหล็กไฟฟ้า ถ้ากลับขั้วถ่าน ขั้ว N-S ก็สลับกัน

### วงจรไฟฟ้า

มี 3 แบบ: **อนุกรม, ขนาน, ผสม (อนุกรม+ขนาน)**

| | ต่อแบบอนุกรม | ต่อแบบขนาน |
|---|---|---|
| ลักษณะ | หลอดเรียงต่อกันเป็นสายเดียว กระแสมีทางเดินทางเดียว | แต่ละหลอดมีทางแยกของตัวเอง |
| V และ I | **แบ่ง V กัน แต่ I เท่ากัน** ทุกหลอด | **V เท่ากัน** ทุกหลอด (กระแสแยกไหล) |
| หลอดหนึ่งเสีย | **ไฟดับทั้งวงจร** | หลอดอื่น **ยังสว่างอยู่** |
| ต่อหลอดเพิ่ม | ยิ่งต่อมาก **ยิ่งสว่างน้อยลง** | ความสว่างแต่ละหลอด **ไม่ลดลง** แบบอนุกรม |
| การใช้งาน | ไฟประดับแบบเก่า | **นิยมใช้ในบ้าน** |

### สัญลักษณ์ทางไฟฟ้าที่ควรรู้

| สิ่งของ | ลักษณะสัญลักษณ์ (บรรยาย) |
|---|---|
| เซลล์ไฟฟ้า/แบตเตอรี่ | เส้นยาว (ขั้วบวก +) คู่กับเส้นสั้นหนา (ขั้วลบ −) |
| สายไฟ | เส้นตรง |
| สวิตช์ | เส้นที่มีก้านยกขึ้น (เปิดวงจร) |
| หลอดไฟ | วงกลมมีกากบาท ⊗ |
| ตัวต้านทาน | เส้นซิกแซก หรือกล่องสี่เหลี่ยม |
| ฟิวส์ | กล่องยาวมีเส้นผ่ากลาง หรือเส้นหยัก |
| ไดโอด | สามเหลี่ยมชนขีด ให้กระแสไหลทางเดียว (Anode + → Cathode −) |
| แอมมิเตอร์ | วงกลมมีตัว **A** — วัดกระแส ต่อ **อนุกรม** |
| โวลต์มิเตอร์ | วงกลมมีตัว **V** — วัดความต่างศักย์ ต่อ **ขนาน** คร่อมอุปกรณ์ |
| มอเตอร์ | วงกลมมีตัว **M** |

### การต่อถ่านไฟฉาย

| | อนุกรม (ขั้ว + ต่อ −) | ขนาน (+ ต่อ +, − ต่อ −) |
|---|---|---|
| ความต่างศักย์รวม | **V รวม = V₁ + V₂ + V₃ + …** → ได้ความต่างศักย์มาก | **V รวม = V₁ = V₂ = V₃** → ได้ความต่างศักย์น้อย (เท่าก้อนเดียว) |
| อายุการใช้งาน | สั้น | ยาวนานกว่า |

ตัวอย่าง: ถ่าน 1.5 V จำนวน 3 ก้อน ต่ออนุกรม = 4.5 V ต่อขนาน = 1.5 V

## 2. แสง

### ตัวกลางของแสง

| ชนิด | แสงผ่านได้ | ตัวอย่าง |
|---|---|---|
| ตัวกลางโปร่งใส (Transparent) | ผ่านได้เกือบทั้งหมด มองทะลุเห็นชัด | กระจกใส พลาสติกใส แก้วน้ำ อากาศ |
| ตัวกลางโปร่งแสง (Translucent) | ผ่านได้บางส่วน มองเห็นไม่ชัด | กระจกฝ้า กระดาษไข กระดาษลอกลาย |
| ตัวกลางทึบแสง (Opaque) | ผ่านไม่ได้เลย **ทำให้เกิดเงา** | กระจกเงา ก้อนหิน โต๊ะ สมุด |

### การสะท้อนของแสง

- เกิดเมื่อแสงตกกระทบตัวกลางทึบแสง (เช่น กระจกเงา)
- กฎการสะท้อน: **มุมตกกระทบ = มุมสะท้อน** (วัดจากเส้นปกติที่ตั้งฉากกับผิว)
- **พื้นผิวเรียบ** → แสงสะท้อนเป็นระเบียบ (เห็นเงาสะท้อนชัด) / **พื้นผิวขรุขระ** → แสงสะท้อนไม่เป็นระเบียบ (สะท้อนกระจาย)
- อุปกรณ์ที่ใช้หลักการสะท้อนแสง: **กล้องเพริสโคป (กล้องดูแห่)** ใช้กระจกเงา 2 แผ่นเอียง 45° ให้มองข้ามสิ่งกีดขวางได้ (ใช้ในเรือดำน้ำ) และ **กล้องสลับลาย (kaleidoscope)** ใช้กระจกเงาหลายแผ่นสะท้อนซ้ำจนเกิดลวดลาย (ส่วนตาแมวประตูใช้ **เลนส์** ซึ่งเป็นเรื่องการหักเห)

### การมองเห็นสี

- **แม่สีของแสง: แดง เขียว น้ำเงิน** (RGB)
- แดง + เขียว = **เหลือง** / น้ำเงิน + เขียว = **น้ำเงินเขียว (ฟ้า, cyan)** / น้ำเงิน + แดง = **ม่วงแดง (magenta)** / แดง + เขียว + น้ำเงิน = **ขาว**
- เรามองเห็นวัตถุเป็นสีใด เพราะวัตถุ **สะท้อนแสงสีนั้น** เข้าตา แล้ว **ดูดกลืนแสงสีอื่น**
  - วัตถุสีน้ำเงินในแสงขาว → สะท้อนเฉพาะแสงน้ำเงิน → เห็นสีน้ำเงิน
  - วัตถุสีแดงในแสงขาว → เห็นสีแดง
  - **วัตถุสีขาว** สะท้อนทุกสี → ถ้าส่องด้วยแสงสีแดงอย่างเดียว จะเห็นเป็น **สีแดง**
  - **วัตถุสีดำ** ดูดกลืนทุกสี → เห็นเป็นสีดำ
- ระวัง: แม่สีของแสง (แดง เขียว น้ำเงิน) **ไม่เหมือน** แม่สีของสีวาดภาพ

### การหักเหของแสง

- **เกิดเมื่อแสงเดินทางผ่านตัวกลางที่มีความหนาแน่นต่างกัน** แสงจะเปลี่ยนทิศทางที่รอยต่อ
- จาก **d น้อย → d มาก** (เช่น อากาศ → น้ำ) แสง **เบนเข้าหาเส้นปกติ**
- จาก **d มาก → d น้อย** (เช่น น้ำ → อากาศ) แสง **เบนออกจากเส้นปกติ**
- ถ้าแสงตกตั้งฉากกับรอยต่อพอดี **แสงไม่เบน** เดินทางเป็นเส้นตรง
- ตัวอย่างปรากฏการณ์: แสงผ่านปริซึมแยกเป็นสีรุ้ง, รุ้งกินน้ำ, ดินสอในแก้วน้ำดูหักงอ, มองสระน้ำเห็นตื้นกว่าความจริง, ทรงกลดรอบดวงอาทิตย์, ดวงอาทิตย์ทรงกลด/พระอาทิตย์หลายดวง (ซันด็อก)

### มิราจ (Mirage) และการสะท้อนกลับหมด

- มิราจคือภาพลวงตา เช่น เห็นเหมือนมีน้ำบนถนนร้อน ๆ หรือกลางทะเลทราย
- อากาศใกล้ถนนร้อน (d น้อย) อากาศด้านบนเย็นกว่า (d มาก) แสงจากท้องฟ้าเดินทางจากอากาศเย็นลงสู่อากาศร้อนจะเบนออกเรื่อย ๆ จนเกิด **การสะท้อนกลับหมด** ย้อนขึ้นมาเข้าตาเรา เราจึงเห็นภาพท้องฟ้าปรากฏบนพื้นถนน คล้ายแอ่งน้ำ

### ภาพจริง vs ภาพเสมือน

| | ภาพจริง | ภาพเสมือน |
|---|---|---|
| เกิดจาก | รังสีของแสงตัดกันจริง | รังสีของแสงเสมือน (ต่อแนวรังสี) ตัดกัน |
| ต้องใช้ฉากรับ? | **ต้องมีฉากรับ** จึงเห็นภาพ | มองเห็นได้ **โดยไม่ต้องใช้ฉาก** |
| ลักษณะ | **หัวกลับ** | **หัวตั้ง** |
| ตัวอย่าง | ภาพบนจอภาพยนตร์ | ภาพจากแว่นขยาย ภาพในกระจกเงา |

### กระจกและเลนส์

| ชนิด | ทำอะไรกับแสง | ภาพที่เกิด | ตัวอย่างการใช้ |
|---|---|---|---|
| กระจกเงาราบ | สะท้อน | ภาพเสมือน หัวตั้ง **ขนาดเท่าวัตถุ** กลับซ้าย-ขวา (ภาพปรัศวภาควิโลม) ระยะภาพ = ระยะวัตถุ | กระจกส่องหน้า |
| กระจกนูน | **กระจายแสง** | ภาพเสมือน หัวตั้ง **เล็กกว่าวัตถุเสมอ** มุมมองกว้างขึ้น | กระจกโค้งตามทางแยก กระจกมองข้างรถ |
| กระจกเว้า | **รวมแสง** | ได้ทั้งภาพจริงและภาพเสมือน ใหญ่หรือเล็กแล้วแต่ตำแหน่งวัตถุ; **ภาพเสมือนหัวตั้งขยาย** เมื่อวางวัตถุใกล้กว่าระยะโฟกัส | กระจกส่องฟันของหมอฟัน กระจกแต่งหน้าขยาย ไฟฉาย กล้องโทรทรรศน์แบบสะท้อน |
| เลนส์นูน | **รวมแสง** | ได้ทั้งภาพจริงและภาพเสมือน; **ภาพเสมือนหัวตั้งขยาย** เมื่อวัตถุใกล้กว่าระยะโฟกัส | แว่นขยาย รวมแสงแดดจุดไฟ แว่นสายตายาว |
| เลนส์เว้า | **กระจายแสง** | ภาพเสมือน หัวตั้ง **เล็กกว่าวัตถุเสมอ** มุมมองกว้าง | ตาแมวประตู แว่นสายตาสั้น |

จำง่าย: **"นูน-เว้า สลับกันระหว่างกระจกกับเลนส์"** กระจกเว้ารวมแสง แต่เลนส์เว้ากระจายแสง / กระจกนูนกระจายแสง แต่เลนส์นูนรวมแสง
และ **ตัวที่กระจายแสง (กระจกนูน, เลนส์เว้า) ให้ภาพเสมือน หัวตั้ง เล็กกว่าวัตถุเสมอ**

### เลนส์กับสายตา

| สายตา | ภาพตกที่ไหน | อาการ | แก้ด้วย |
|---|---|---|---|
| สายตาปกติ | ตกที่เรตินาพอดี | มองชัด | — |
| **สายตาสั้น** | ตก **ก่อนถึง** เรตินา | มองใกล้ชัด มองไกลไม่ชัด | **เลนส์เว้า** |
| **สายตายาว** | ตก **เลย** เรตินา | มองไกลชัด มองใกล้ไม่ชัด | **เลนส์นูน** |

คาถา: **"สั้น-เว้า, ยาว-นูน"**

## 3. เสียง

### สมบัติของคลื่นเสียง

- เป็น **คลื่นตามยาว** และ **ต้องอาศัยตัวกลาง** ในการเคลื่อนที่ → **ไม่ได้ยินเสียงในสุญญากาศ** (เช่น ในอวกาศ)
- **เกิดจากการสั่นสะเทือน** ของวัตถุ
- เสียงเดินทางใน **ของแข็งได้ดีกว่าของเหลว และของเหลวดีกว่าแก๊ส** (แนบหูกับรางรถไฟได้ยินเสียงรถไฟก่อน)
- หน่วยวัด **ความถี่** = **เฮิรตซ์ (Hz)** (จำนวนรอบการสั่นต่อวินาที)
- มนุษย์ได้ยินเสียงความถี่ **20–20,000 Hz**
- หน่วยวัด **ความดัง** = **เดซิเบล (dB)**; เสียงที่เป็นอันตราย คือเสียงที่ดัง **เกิน 85 dB** (ฟังนาน ๆ ทำลายการได้ยิน)

### ความดัง vs ระดับเสียง (สูง-ต่ำ)

| เรื่อง | ขึ้นกับ | สรุป |
|---|---|---|
| ความดัง-เบา | **แอมพลิจูด** (ความสูงของคลื่น) | แอมพลิจูดมาก = เสียงดัง, น้อย = เสียงเบา |
| เสียงสูง-ต่ำ | **ความถี่** (จำนวนรอบต่อวินาที) | ถี่มาก = เสียงแหลม/สูง, ถี่น้อย = เสียงทุ้ม/ต่ำ |

### การทดลองเรื่องเสียงที่ออกสอบบ่อย

กฎทอง: **สิ่งที่สั่นมีขนาดเล็ก/สั้น/ตึง → สั่นเร็ว → เสียงสูง** และ **สิ่งที่สั่นใหญ่/ยาว/หย่อน → สั่นช้า → เสียงต่ำ** แต่ต้องดูให้ออกว่า "อะไรเป็นตัวสั่น"

| การทดลอง | อะไรสั่น | ผล |
|---|---|---|
| **เป่าลมเหนือปากขวด** ที่ใส่น้ำไม่เท่ากัน | **ลม (อากาศ) ในขวด** | ขวดน้ำมาก (อากาศน้อย) → **เสียงสูง** / ขวดน้ำน้อย (อากาศมาก) → **เสียงต่ำ** |
| **เคาะขวด** ที่ใส่น้ำไม่เท่ากัน | **ขวดแก้วและน้ำ** | ขวดน้ำมาก (หนัก สั่นช้า) → **เสียงต่ำ** / ขวดน้ำน้อย → **เสียงสูง** |
| สายกีตาร์ | สาย | **สายใหญ่ สายหย่อน → เสียงต่ำ / สายเล็ก สายตึง → เสียงสูง** |
| หนังกลอง | หนังกลอง | **หนังกลองหย่อน → เสียงต่ำ / หนังกลองตึง → เสียงสูง** |
| ระนาด กระดิ่งลม สามเหลี่ยม | แท่ง/ชิ้นโลหะ | **อันใหญ่ พื้นที่มาก → เสียงต่ำ / อันเล็ก พื้นที่น้อย → เสียงสูง** |

## 4. ความร้อน

### การถ่ายโอนความร้อน 3 แบบ

| แบบ | พบใน | กลไก | ตัวอย่าง |
|---|---|---|---|
| **การนำความร้อน** | ของแข็ง | อนุภาค **สั่น** แล้วส่งต่อพลังงานให้อนุภาคข้าง ๆ | ด้ามกระทะ/ช้อนโลหะร้อนขึ้น เหล็กเขี่ยไฟร้อนถึงมือ |
| **การพาความร้อน** | ของไหล (ของเหลวและแก๊ส) | อนุภาค **เคลื่อนที่** พาความร้อนไปด้วย (ร้อนลอยขึ้น เย็นจมลง) | น้ำในหม้อเดือดวนขึ้น-ลง มือที่อยู่เหนือกองไฟรู้สึกร้อน |
| **การแผ่รังสีความร้อน** | ไม่ต้องอาศัยตัวกลาง | ความร้อนส่งออกไปเป็นคลื่น | ความร้อนจากดวงอาทิตย์ถึงโลก นั่งข้างกองไฟแล้วรู้สึกอุ่น |

### การเปลี่ยนสถานะ

| การเปลี่ยน | ชื่อ | ความร้อน |
|---|---|---|
| ของแข็ง → ของเหลว | ละลาย (ที่จุดหลอมเหลว) | **ดูดความร้อน** |
| ของเหลว → แก๊ส | ระเหย/เดือด (ที่จุดเดือด) | **ดูดความร้อน** |
| ของแข็ง → แก๊ส | ระเหิด | **ดูดความร้อน** |
| ของเหลว → ของแข็ง | แข็งตัว (ที่จุดเยือกแข็ง) | **คายความร้อน** |
| แก๊ส → ของเหลว | ควบแน่น (ที่จุดควบแน่น) | **คายความร้อน** |
| แก๊ส → ของแข็ง | ระเหิดกลับ | **คายความร้อน** |

จำ: **อนุภาคแยกห่างขึ้น (แข็ง→เหลว→แก๊ส) = ดูดความร้อน, อนุภาคเข้าใกล้กัน = คายความร้อน**

### สูตรคำนวณปริมาณความร้อน

| สูตร | ใช้เมื่อ | ตัวแปร |
|---|---|---|
| **Q = m c Δt** | อุณหภูมิ **เปลี่ยน** (สถานะเดิม) | Q = ปริมาณความร้อน (cal), m = มวล (g), c ของน้ำ = 1 cal/g·°C, Δt = t ปลาย − t ต้น (°C) |
| **Q = m L** | สถานะ **เปลี่ยน** (อุณหภูมิคงที่) | L (แข็ง→เหลว ของน้ำ) = 80 cal/g, L (เหลว→แก๊ส ของน้ำ) = 540 cal/g |

ขั้นตอนเปลี่ยนน้ำแข็ง 0°C เป็นไอน้ำ 100°C มี 3 ช่วง:
1. น้ำแข็ง 0°C → น้ำ 0°C : Q = mL (L = 80)
2. น้ำ 0°C → น้ำ 100°C : Q = mcΔt
3. น้ำ 100°C → ไอน้ำ 100°C : Q = mL (L = 540)

### การเปลี่ยนหน่วยอุณหภูมิ

°C = องศาเซลเซียส, °R = องศาโรเมอร์, °F = องศาฟาเรนไฮต์, K = เคลวิน

**C/5 = R/4 = (F − 32)/9 = (K − 273)/5**

จุดเยือกแข็งของน้ำ: 0°C = 0°R = 32°F = 273 K / จุดเดือดของน้ำ: 100°C = 80°R = 212°F = 373 K

## 5. งาน (Work)

- **งาน = ผลของการออกแรงกระทำต่อวัตถุ แล้วทำให้วัตถุเคลื่อนที่ได้ระยะทางตามแนวแรง**
- **W = F × S** (งาน = แรง × ระยะทางตามแนวแรง) หน่วย **จูล (J)** = นิวตัน·เมตร
- **ไม่เกิดงาน** เมื่อ ① ไม่ออกแรง ② ออกแรงแต่ไม่เกิดระยะทาง (เช่น ดันกำแพงจนเหนื่อยแต่กำแพงไม่ขยับ) ③ **แนวการออกแรงตั้งฉากกับระยะทาง** (เช่น ถือกระเป๋าเดินไปข้างหน้าบนพื้นราบ แรงยกขึ้นแต่เคลื่อนที่ตามแนวนอน)
- ตัวอย่างที่เกิดงาน: ผลักกล่องให้เลื่อนไปตามพื้น, ยกกระเป๋าขึ้นจากพื้น (แรงขึ้น เคลื่อนที่ขึ้น)

## ตัวอย่างวิธีคิด

**ตัวอย่างที่ 1 (กฎของโอห์ม)** หลอดไฟมีความต้านทาน 6 Ω ต่อกับถ่าน 1.5 V จำนวน 4 ก้อนแบบอนุกรม กระแสไฟฟ้าเท่าใด

1. ต่ออนุกรม → V รวม = 1.5 × 4 = 6 V
2. I = V ÷ R = 6 ÷ 6 = **1 A**
3. ถ้าต่อขนาน V รวมจะเหลือ 1.5 V → I = 1.5 ÷ 6 = 0.25 A (หลอดสว่างน้อยกว่า แต่ถ่านใช้ได้นานกว่า)

**ตัวอย่างที่ 2 (ความร้อนหลายช่วง)** ต้องใช้ความร้อนเท่าใด เปลี่ยนน้ำแข็ง 0°C มวล 10 g ให้เป็นไอน้ำ 100°C

1. ละลาย: Q₁ = mL = 10 × 80 = 800 cal
2. ทำน้ำ 0 → 100°C: Q₂ = mcΔt = 10 × 1 × 100 = 1,000 cal
3. เดือดเป็นไอ: Q₃ = mL = 10 × 540 = 5,400 cal
4. รวม = 800 + 1,000 + 5,400 = **7,200 cal**

**ตัวอย่างที่ 3 (เปลี่ยนหน่วยอุณหภูมิ)** 25°C เท่ากับกี่ °F

1. C/5 = (F − 32)/9 → 25/5 = (F − 32)/9
2. 5 = (F − 32)/9 → F − 32 = 45
3. F = **77°F** (เทียบ K: 25/5 = (K − 273)/5 → K = 298 K)

**ตัวอย่างที่ 4 (งาน)** ออกแรง 20 N ผลักกล่องไปตามพื้นได้ไกล 5 m ในทิศเดียวกับแรง เกิดงานเท่าใด

1. W = F × S = 20 × 5 = **100 J**
2. ถ้าแบกกล่องเดินไปข้างหน้า 5 m บนพื้นราบ แรงแบก (ขึ้น) ตั้งฉากกับการเคลื่อนที่ (แนวนอน) → งานของแรงแบก = 0

**ตัวอย่างที่ 5 (เสียง)** ขวดเหมือนกัน 3 ใบ ใส่น้ำ น้อย-กลาง-มาก ถ้า "เป่า" ใบไหนเสียงสูงสุด ถ้า "เคาะ" ใบไหนเสียงสูงสุด

1. เป่า → อากาศในขวดสั่น ขวดน้ำมากมีอากาศน้อยที่สุด → **ขวดน้ำมากเสียงสูงสุด**
2. เคาะ → ขวดกับน้ำสั่น ขวดน้ำน้อยเบาที่สุดสั่นเร็วที่สุด → **ขวดน้ำน้อยเสียงสูงสุด**

## จุดที่มักสับสน

- **อนุกรม = I เท่ากัน แบ่ง V** / **ขนาน = V เท่ากัน** — บ้านต่อแบบขนาน
- **ถ่านต่ออนุกรม → V มาก อายุสั้น** / **ต่อขนาน → V เท่าก้อนเดียว อายุยาว**
- แอมมิเตอร์ต่ออนุกรม โวลต์มิเตอร์ต่อขนาน
- **กระจกเว้า = รวมแสง แต่เลนส์เว้า = กระจายแสง** (กลับกันกับนูน) อย่าจำว่า "เว้า = กระจาย" ทั้งหมด
- กระจกเงาราบให้ภาพ **กลับซ้าย-ขวา** แต่ **หัวตั้ง** (ไม่ใช่หัวกลับ)
- ภาพจริงต้องมีฉากรับและหัวกลับ / ภาพเสมือนไม่ต้องใช้ฉากและหัวตั้ง
- **สายตาสั้นใช้เลนส์เว้า** (ไม่ใช่เลนส์นูน) เพราะภาพตกก่อนเรตินาต้องกระจายแสงออก
- **ความดังขึ้นกับแอมพลิจูด / เสียงสูงต่ำขึ้นกับความถี่** อย่าสลับ
- เป่าขวดกับเคาะขวดให้ผล **ตรงข้ามกัน** เพราะตัวที่สั่นต่างกัน
- การพาความร้อนเกิดใน **ของไหล** (ทั้งของเหลวและแก๊ส) ไม่ใช่ในของแข็ง และการแผ่รังสี **ไม่ต้องใช้ตัวกลาง**
- ระเหิด (แข็ง→แก๊ส) **ดูด** ความร้อน / ระเหิดกลับ (แก๊ส→แข็ง) **คาย** ความร้อน
- ขณะเปลี่ยนสถานะ **อุณหภูมิคงที่** จึงใช้ Q = mL ไม่ใช่ mcΔt
- ถือของเดินบนพื้นราบ **ไม่เกิดงาน** (แรงตั้งฉากกับทิศการเคลื่อนที่) แม้จะรู้สึกเหนื่อย

## ⭐ ประเด็นสำคัญที่ได้จากบทเรียนนี้

- V = I × R; อนุกรมกระแสเท่ากันหลอดเสียดับหมด, ขนานแรงดันเท่ากันหลอดเสียหลอดอื่นยังติด (ใช้ในบ้าน)
- แม่เหล็กไฟฟ้าแรงขึ้นเมื่อเพิ่มถ่านหรือเพิ่มรอบขดลวด; กฎมือขวา: นิ้วตามกระแส นิ้วโป้งชี้ขั้วเหนือ
- มุมตกกระทบ = มุมสะท้อน; แม่สีแสง แดง-เขียว-น้ำเงิน; แสงหักเหเมื่อผ่านตัวกลางที่หนาแน่นต่างกัน
- กระจกนูนและเลนส์เว้ากระจายแสง ให้ภาพเสมือนหัวตั้งเล็กกว่าวัตถุเสมอ; สายตาสั้นใช้เลนส์เว้า สายตายาวใช้เลนส์นูน
- เสียงต้องมีตัวกลาง เดินทางในของแข็งดีที่สุด; มนุษย์ได้ยิน 20–20,000 Hz; เกิน 85 dB อันตราย; ดัง=แอมพลิจูด สูง=ความถี่
- นำ (ของแข็ง สั่น) / พา (ของไหล เคลื่อนที่) / แผ่รังสี (ไม่ใช้ตัวกลาง); Q = mcΔt เมื่ออุณหภูมิเปลี่ยน, Q = mL เมื่อสถานะเปลี่ยน
- C/5 = R/4 = (F−32)/9 = (K−273)/5; งาน W = F × S เกิดเมื่อวัตถุเคลื่อนที่ตามแนวแรงเท่านั้น
