## เป้าหมายของบทนี้

- แบ่งยุคก่อนประวัติศาสตร์กับยุคประวัติศาสตร์ได้ และบอกได้ว่า "ตัวอักษร" คือเกณฑ์สำคัญ
- เรียงยุคหิน ยุคโลหะ และยุคประวัติศาสตร์แบบสากล/แบบไทยได้ถูกต้อง
- แยกการนับเวลาแบบสุริยคติกับจันทรคติ และเทียบศักราช พ.ศ. ค.ศ. จ.ศ. ร.ศ. ม.ศ. ฮ.ศ. ได้อย่างแม่นยำ
- อธิบายวิธีการทางประวัติศาสตร์ 5 ขั้น และจำแนกหลักฐานชั้นต้น/ชั้นรอง ลายลักษณ์อักษร/ไม่ใช่ลายลักษณ์อักษร
- บอกที่ตั้งของรัฐโบราณในดินแดนไทย และชื่อที่ปรากฏในเอกสารจีน

## 1. การแบ่งยุคประวัติศาสตร์ (#50)

นักประวัติศาสตร์แบ่งเวลาในอดีตออกเป็น **2 ยุคใหญ่** โดยใช้ **"ตัวอักษร" (การมีบันทึกเป็นลายลักษณ์อักษร)** เป็นเกณฑ์

| ยุค | ความหมาย | เรารู้เรื่องราวจากอะไร |
|---|---|---|
| ยุคก่อนประวัติศาสตร์ | ช่วงที่มนุษย์ยังไม่มีตัวอักษรใช้ | หลักฐานโบราณคดี เช่น เครื่องมือหิน โครงกระดูก ภาชนะดินเผา ภาพเขียนสี |
| ยุคประวัติศาสตร์ | ช่วงที่มนุษย์มีตัวอักษรบันทึกเรื่องราวแล้ว | จารึก เอกสาร บันทึก รวมทั้งหลักฐานโบราณคดี |

ตัวอย่างในเอกสารคือ **ตัวอักษรรูปลิ่ม (คูนิฟอร์ม)** ของชาวสุเมเรียนในดินแดนเมโสโปเตเมีย ซึ่งเป็นอักษรที่เก่าแก่มากของโลก (ราว 5,000 ปีก่อน) การเกิดตัวอักษรแบบนี้จึงเป็น "ประตู" เข้าสู่ยุคประวัติศาสตร์

> จำง่าย ๆ: **มีตัวอักษร = มีประวัติศาสตร์** ถ้ายังไม่มีตัวอักษร เรียกว่า "ก่อนประวัติศาสตร์"

ข้อควรรู้: แต่ละดินแดนเข้าสู่ยุคประวัติศาสตร์ไม่พร้อมกัน เพราะเริ่มใช้ตัวอักษรไม่พร้อมกัน เช่น เมโสโปเตเมียมีตัวอักษรก่อนดินแดนไทยหลายพันปี

### 1.1 ยุคก่อนประวัติศาสตร์: ยุคหิน

แบ่งตามลักษณะ "เครื่องมือหิน" และวิถีชีวิต

| ยุคหิน | วิถีชีวิตตามเอกสาร | เครื่องมือ (เสริมความเข้าใจ) |
|---|---|---|
| หินเก่า | เร่ร่อน ล่าสัตว์ เก็บของป่า | หินกะเทาะหยาบ ๆ (กะเทาะด้านเดียว) |
| หินกลาง | เริ่มเพาะปลูก เลี้ยงสัตว์ ใช้ไฟ | หินกะเทาะที่ประณีตขึ้น |
| หินใหม่ | ตั้งถิ่นฐานเป็นหลักแหล่ง มีเสื้อผ้า มีเครื่องปั้นดินเผา | หินขัดผิวเรียบ |

ลำดับความคิด: **เร่ร่อน → เริ่มอยู่กับที่ → ตั้งหมู่บ้านถาวร** ยิ่งยุคหลัง มนุษย์ยิ่งควบคุมธรรมชาติได้มากขึ้น

หมายเหตุ: มนุษย์รู้จักใช้ไฟมาตั้งแต่ยุคหินเก่าแล้ว (เช่น ใช้ให้ความอบอุ่นและไล่สัตว์) ตำราแต่ละเล่มจึงอาจเขียนเรื่องไฟไว้ต่างยุคกัน ให้จำ "จุดเด่น" ของแต่ละยุคเป็นหลัก คือ หินเก่า = เร่ร่อนล่าสัตว์, หินใหม่ = ตั้งถิ่นฐาน ทำเครื่องปั้นดินเผา

### 1.2 ยุคก่อนประวัติศาสตร์: ยุคโลหะ

แบ่งเป็น 2 ยุค

1. **ยุคสำริด** — สำริดเป็น "โลหะผสม" (ทองแดง + ดีบุก) มนุษย์เริ่มรวมกลุ่มใหญ่ขึ้นและเริ่มสร้างอารยธรรม
2. **ยุคเหล็ก** — เหล็กแข็งแรงกว่า ทำอาวุธและเครื่องมือได้ดี จึงขยายอาณาเขตและปกป้องดินแดนได้

ตัวอย่างในไทย: **แหล่งโบราณคดีบ้านเชียง จ.อุดรธานี** มีชื่อเสียงเรื่องภาชนะดินเผาลายเขียนสีและเครื่องมือสำริด (จะเรียนต่อใน PART 10 เรื่องมรดกโลก)

### 1.3 การแบ่งยุคประวัติศาสตร์แบบสากล

ยุคประวัติศาสตร์สากล (ตะวันตก) เรียงเป็น 4 ยุค

| ยุค | เหตุการณ์เด่น (ตามเอกสาร) |
|---|---|
| ยุคโบราณ | อารยธรรมเมโสโปเตเมีย กรีก โรมัน สิ้นสุดเมื่อจักรวรรดิโรมันตะวันตกล่มสลาย |
| ยุคกลาง | "ยุคมืด" คริสตจักรและพระสันตะปาปามีอำนาจมาก ใช้ระบบฟิวดัล (ระบบเจ้าขุนมูลนาย) |
| ยุคใหม่ | ค้นพบทวีปอเมริกา ปฏิวัติอุตสาหกรรม สงครามโลก |
| ยุคปัจจุบัน | สงครามเย็น โลกาภิวัตน์ โลกไร้พรมแดน |

**ยุคเรอเนสซองซ์ (ฟื้นฟูศิลปวิทยาการ)** เป็น "รอยต่อ" ระหว่างยุคกลางกับยุคใหม่ เป็นช่วงที่ฟื้นฟูศิลปะและความรู้แบบกรีก–โรมันขึ้นมาอีกครั้ง

เทคนิคจำ: **โบ–กลาง–ใหม่–ปัจจุบัน** (โบราณ → กลาง → ใหม่ → ปัจจุบัน) และจำคู่ "โรมันล่ม = จบยุคโบราณ"

### 1.4 การแบ่งยุคประวัติศาสตร์แบบไทย

แบ่งได้หลายแบบ เช่น แบ่งตามอาณาจักร (ราชธานี) หรือแบ่งตามราชวงศ์ แบบที่นิยมที่สุดคือแบ่งตาม **ราชธานี** เรียงดังนี้

**สุโขทัย → อยุธยา → ธนบุรี → รัตนโกสินทร์**

(ภาพในเอกสารเรียงจากโบราณสถานสุโขทัย วัดในอยุธยา วัดอรุณฯ ฝั่งธนบุรี ไปจนถึงวัดพระแก้ว)

## 2. การนับเวลา (#51)

มี 2 แบบ

| | สุริยคติ (ตามดวงอาทิตย์) | จันทรคติ (ตามดวงจันทร์) |
|---|---|---|
| จำนวนวันใน 1 ปี | 365 วัน (ปีอธิกสุรทินมี 366 วัน) | 354 วัน |
| จำนวนเดือน | 12 เดือน | 12 เดือน |
| ชื่อเดือน | มกราคม–ธันวาคม | เดือนอ้าย เดือนยี่ เดือนสาม … เดือนสิบสอง |
| วิธีจำ | เดือนลงท้าย **-คม** มี 31 วัน, **-ยน** มี 30 วัน, **-พันธ์** มี 28/29 วัน | เดือน 1 = "อ้าย", เดือน 2 = "ยี่" ที่เหลือเรียกเป็นตัวเลข |

วันสำคัญทางพุทธศาสนา เช่น วิสาขบูชา (ขึ้น 15 ค่ำ เดือน 6) ใช้จันทรคติ จึงตรงกับวันที่ตามปฏิทินสากลไม่เหมือนกันทุกปี

## 3. การนับศักราช (#52)

**ศักราช** คือการนับปีโดยเริ่มจากเหตุการณ์สำคัญเหตุการณ์หนึ่ง

| ศักราช | เริ่มนับจาก (ความรู้เสริม) | ใช้ที่ไหน/เมื่อไร |
|---|---|---|
| พ.ศ. (พุทธศักราช) | การปรินิพพานของพระพุทธเจ้า | ไทยใช้เป็นทางการตั้งแต่สมัยรัชกาลที่ 6 |
| ม.ศ. (มหาศักราช) | ศักราชที่มาจากอินเดีย | พบมากในจารึกสมัยสุโขทัย |
| จ.ศ. (จุลศักราช) | ศักราชที่มาจากพม่า | ใช้มากในสมัยอยุธยา–รัตนโกสินทร์ตอนต้น |
| ร.ศ. (รัตนโกสินทรศก) | ปีสถาปนากรุงรัตนโกสินทร์ (ร.ศ. 1 = พ.ศ. 2325) | รัชกาลที่ 5 ทรงเริ่มใช้ |
| ค.ศ. (คริสต์ศักราช) | ปีที่เชื่อว่าพระเยซูประสูติ | สากล |
| ฮ.ศ. (ฮิจเราะห์ศักราช) | ปีที่ท่านนบีมุฮัมมัดอพยพจากมักกะฮ์ไปมะดีนะฮ์ | ศาสนาอิสลาม |

เอกสารแบ่ง: แบบไทย = พ.ศ. ร.ศ. ม.ศ. จ.ศ. / แบบสากล = ค.ศ. ฮ.ศ.

### การเทียบศักราช

ทุกสูตรเขียนในรูป **พ.ศ. = ศักราชอื่น + ตัวเลข**

| สูตร | ตัวเลข |
|---|---|
| พ.ศ. = ฮ.ศ. + 1122 | 1122 |
| พ.ศ. = ร.ศ. + 2324 | 2324 |
| พ.ศ. = ค.ศ. + 543 | 543 |
| พ.ศ. = จ.ศ. + 1181 | 1181 |
| พ.ศ. = ม.ศ. + 621 | 621 |

**คาถาจำ: "เฮีย ร้อง ครับ จน มึน"** = ฮ.ศ. / ร.ศ. / ค.ศ. / จ.ศ. / ม.ศ. คู่กับ **1122 / 2324 / 543 / 1181 / 621**

กติกาสำคัญ
- จาก **พ.ศ. ไปศักราชอื่น → ลบ** ตัวเลข
- จาก **ศักราชอื่นมาเป็น พ.ศ. → บวก** ตัวเลข
- ถ้าเทียบระหว่างศักราชอื่นสองแบบ (เช่น ค.ศ. ↔ ร.ศ.) ให้ **แปลงเป็น พ.ศ. ก่อน** แล้วค่อยแปลงต่อ

ตัวอย่างในเอกสาร: พ.ศ. 2570 ตรงกับ ค.ศ. ใด → 2570 = ค.ศ. + 543 → ค.ศ. = 2570 − 543 = **2027**

หมายเหตุ: ฮ.ศ. นับแบบจันทรคติ ปีจึงสั้นกว่าปีสุริยคติ การบวก 1122 เป็นค่าประมาณที่ใช้ในบทเรียนระดับนี้

## 4. วิธีการทางประวัติศาสตร์ (#53)

คือ "ขั้นตอนการสืบค้นอดีตอย่างเป็นระบบ" เหมือนนักสืบ มี 5 ขั้น

1. **กำหนดหัวข้อ** — อยากรู้เรื่องอะไร ตั้งคำถาม
2. **รวบรวมหลักฐาน** — ค้นหาหลักฐานทั้งชั้นต้นและชั้นรอง
3. **ประเมินหลักฐาน** (วิพากษ์หลักฐาน) — ตรวจว่าหลักฐานเป็นของจริงไหม (ภายนอก) และเนื้อหาน่าเชื่อถือแค่ไหน (ภายใน)
4. **วิเคราะห์ ตีความ** — จัดข้อมูล หาความสัมพันธ์ เหตุและผล
5. **นำเสนอ** — เรียบเรียงเป็นรายงาน นิทรรศการ ฯลฯ

คาถาจำ: **"ตั้ง–รวม–ประเมิน–ตีความ–เสนอ"**

## 5. หลักฐานทางประวัติศาสตร์ (#54)

### แบ่งตามความสำคัญ

| ประเภท | ความหมาย | ตัวอย่าง |
|---|---|---|
| หลักฐานชั้นต้น | เกิดร่วมสมัยกับเหตุการณ์ หรือเขียนโดยคนที่อยู่ในเหตุการณ์โดยตรง | ศิลาจารึก จดหมายเหตุ บันทึกของผู้เห็นเหตุการณ์ ภาพถ่ายในเหตุการณ์ |
| หลักฐานชั้นรอง | เขียนภายหลังโดยอาศัยหลักฐานชั้นต้น | หนังสือเรียน บทความ งานค้นคว้าที่เรียบเรียงภายหลัง |

### แบ่งตามลักษณะ

| ประเภท | ตัวอย่าง |
|---|---|
| หลักฐานลายลักษณ์อักษร (เป็นตัวหนังสือ) | จารึก พงศาวดาร จดหมายเหตุ |
| หลักฐานไม่ใช่ลายลักษณ์อักษร | หม้อ ไห อาวุธหิน โบราณสถาน โบราณวัตถุ |

### ตัวอย่างหลักฐานในเอกสาร

| หลักฐาน | คืออะไร (อธิบายสั้น ๆ) |
|---|---|
| ศิลาจารึก | ตัวอักษรที่สลักบนแผ่นหิน เช่น จารึกพ่อขุนรามคำแหง |
| พงศาวดาร | บันทึกเรื่องราวของกษัตริย์และบ้านเมืองเรียงตามเวลา |
| จดหมายเหตุ | บันทึกเหตุการณ์ที่เกิดขึ้นในขณะนั้น |
| ตำนาน | เรื่องเล่าอดีตที่ผสมความเชื่อ เช่น ตำนานพื้นเมืองเชียงใหม่ |
| ใบบอก | หนังสือรายงานจากหัวเมืองส่งมาถึงเมืองหลวง |
| สารตรา | หนังสือคำสั่งจากเมืองหลวงส่งไปหัวเมือง |
| ศุภอักษร | หนังสือราชการสำคัญที่มีไปถึงต่างประเทศหรือเจ้าประเทศราช |
| ราชกิจจานุเบกษา | หนังสือประกาศของทางราชการ (เริ่มในสมัยรัชกาลที่ 4) |

จำคู่ทิศทาง: **ใบบอก = ขึ้นไปหาเมืองหลวง** / **สารตรา = ลงจากเมืองหลวง**

## 6. รัฐโบราณในดินแดนไทย (#55)

ก่อนจะมีสุโขทัย ดินแดนไทยมีรัฐโบราณหลายแห่ง (เติมที่ตั้งตามความรู้มาตรฐาน)

| รัฐโบราณ | ที่ตั้งสำคัญ (จังหวัดปัจจุบัน) | จุดเด่น |
|---|---|---|
| ทวารวดี | ภาคกลาง ศูนย์กลางสำคัญที่นครปฐม | พระปฐมเจดีย์ รับพุทธศาสนาเถรวาท |
| หริภุญชัย | ลำพูน | พระนางจามเทวีเป็นปฐมกษัตริย์ |
| ล้านนา | เชียงใหม่ | พญามังรายสร้างเมืองเชียงใหม่ |
| โยนกเชียงแสน | เชียงราย (เชียงแสน) | ลุ่มแม่น้ำโขงตอนบน |
| ศรีโคตรบูรณ์ | นครพนม | พระธาตุพนม |
| ตามพรลิงค์ | นครศรีธรรมราช | พระบรมธาตุเจดีย์นครศรีธรรมราช |
| ศรีวิชัย | สุราษฎร์ธานี (ไชยา) | พระบรมธาตุไชยา ค้าขายทางทะเล |

### ชื่อรัฐโบราณใน "เอกสารจีน"

ชาวจีนบันทึกชื่อรัฐเหล่านี้ด้วยเสียงภาษาจีน จึงฟังแปลกหู

| ชื่อในเอกสารจีน | คือรัฐ |
|---|---|
| โตโลโปตี้ | ทวารวดี |
| ตันหม่าลิ่ง | ตามพรลิงค์ |
| ชิลิโฟชิ | ศรีวิชัย |
| หลอหู | ละโว้ (ลพบุรี) |
| หนี่หวังก๊ก ("เมืองที่มีผู้หญิงเป็นกษัตริย์") | หริภุญชัย |
| เจนลีฟู | รัฐโบราณในภาคกลาง (ตำแหน่งแน่ชัดยังถกเถียงกัน) |

เทคนิคจำ: ฟังเสียงพ้องกัน — **โต-โล-โป-ตี้ ≈ ท-วา-ร-วดี**, **ตัน-หม่า-ลิ่ง ≈ ตาม-พร-ลิงค์**, **ชิ-ลิ-โฟ-ชิ ≈ ศรี-วิ-ชัย**, หนี่หวัง = "นางพญา" → พระนางจามเทวี → หริภุญชัย

## ตัวอย่างวิธีคิด

**ตัวอย่างที่ 1 (เทียบศักราช 2 ต่อ):** ร.ศ. 112 ตรงกับ ค.ศ. ใด
1. แปลงเป็น พ.ศ. ก่อน: พ.ศ. = ร.ศ. + 2324 = 112 + 2324 = 2436
2. แปลงเป็น ค.ศ.: ค.ศ. = พ.ศ. − 543 = 2436 − 543 = 1893
3. ตอบ ค.ศ. 1893 (ตรวจย้อน: 1893 + 543 = 2436 ✔)

**ตัวอย่างที่ 2 (นับระยะเวลา):** เหตุการณ์ A เกิด จ.ศ. 1150 เหตุการณ์ B เกิด ค.ศ. 1800 ห่างกันกี่ปี
1. A: พ.ศ. = 1150 + 1181 = 2331
2. B: พ.ศ. = 1800 + 543 = 2343
3. ห่างกัน 2343 − 2331 = 12 ปี

**ตัวอย่างที่ 3 (จำแนกหลักฐาน):** "หนังสือเรียนประวัติศาสตร์ที่ครูเขียนปี พ.ศ. 2560 เรื่องสงครามเก้าทัพ" เป็นหลักฐานแบบใด
1. เป็นตัวหนังสือ → ลายลักษณ์อักษร
2. ผู้เขียนไม่ได้อยู่ในเหตุการณ์ (เกิด พ.ศ. 2328) เขียนจากหลักฐานอื่น → ชั้นรอง
3. ตอบ หลักฐานชั้นรอง ลายลักษณ์อักษร

**ตัวอย่างที่ 4 (ขั้นตอนวิธีการทางประวัติศาสตร์):** นักเรียนพบจารึกสองหลักบอกปีสร้างวัดไม่ตรงกัน จึงตรวจว่าจารึกหลักใดเป็นของแท้และน่าเชื่อถือกว่า → เป็นขั้น **ประเมินหลักฐาน** (ขั้นที่ 3) ไม่ใช่ขั้นรวบรวม เพราะหลักฐานได้มาแล้ว กำลัง "ตรวจคุณภาพ"

## จุดที่มักสับสน

- **บวกหรือลบ?** ไปหา พ.ศ. ให้บวก ออกจาก พ.ศ. ให้ลบ — ถ้าคำตอบ ค.ศ. มากกว่า พ.ศ. แปลว่าคิดผิดแน่นอน
- **ร.ศ. กับ ค.ศ. เทียบตรงกันไม่ได้** ต้องผ่าน พ.ศ. ก่อนเสมอ
- **ม.ศ. (621) กับ จ.ศ. (1181)** สลับกันบ่อย จำ "จน มึน" ตามลำดับ → จ.ศ. 1181, ม.ศ. 621 (ม.ศ. เก่ากว่า จ.ศ. ตัวเลขบวกจึงน้อยกว่า)
- **สุริยคติ 365 วัน / จันทรคติ 354 วัน** ตัวเลขคล้ายกัน อย่าสลับ — "ดวงจันทร์ปีสั้นกว่า"
- **พงศาวดาร ≠ หลักฐานชั้นต้นเสมอไป** ขึ้นอยู่กับว่าเขียนร่วมสมัยหรือเขียนภายหลัง แต่ในด้าน "ลักษณะ" เป็นลายลักษณ์อักษรแน่นอน
- **ยุคหินเก่า vs หินใหม่**: เครื่องปั้นดินเผาและการตั้งถิ่นฐาน = หินใหม่
- **ยุคกลาง** คือยุคที่คริสตจักรมีอำนาจ (ไม่ใช่ยุคกรีก–โรมัน ซึ่งเป็นยุคโบราณ)
- **หนี่หวังก๊ก = หริภุญชัย** ไม่ใช่ทวารวดี (ทวารวดี = โตโลโปตี้)

## ⭐ Key Takeaways

- ใช้ **ตัวอักษร** แบ่งยุคก่อนประวัติศาสตร์กับยุคประวัติศาสตร์
- ยุคหิน: เก่า (เร่ร่อน) → กลาง → ใหม่ (ตั้งถิ่นฐาน เครื่องปั้นดินเผา) / ยุคโลหะ: สำริด → เหล็ก
- สากล: โบราณ → กลาง → ใหม่ → ปัจจุบัน (เรอเนสซองซ์อยู่ระหว่างกลางกับใหม่) / ไทย: สุโขทัย → อยุธยา → ธนบุรี → รัตนโกสินทร์
- สุริยคติ 365 วัน, จันทรคติ 354 วัน
- **เฮีย ร้อง ครับ จน มึน = 1122 / 2324 / 543 / 1181 / 621** (ไป พ.ศ. บวก, ออกจาก พ.ศ. ลบ)
- วิธีการทางประวัติศาสตร์ 5 ขั้น: กำหนดหัวข้อ → รวบรวม → ประเมิน → วิเคราะห์ตีความ → นำเสนอ
- หลักฐานชั้นต้น = ร่วมสมัย/คนในเหตุการณ์, ชั้นรอง = เขียนภายหลังจากชั้นต้น
- ชื่อจีน: โตโลโปตี้ = ทวารวดี, ตันหม่าลิ่ง = ตามพรลิงค์, ชิลิโฟชิ = ศรีวิชัย, หลอหู = ละโว้, หนี่หวังก๊ก = หริภุญชัย

## แผนทบทวน

- **วันนี้:** ดูคลิปแล้วเติมช่องว่างในเอกสารหน้า 63–67 (ช่องการแบ่ง 2 ยุค, ชื่อยุคสากล/ไทย, ชื่อการนับเวลา, ที่ตั้งรัฐโบราณ) แล้วท่อง "เฮีย ร้อง ครับ จน มึน" 5 รอบ
- **พรุ่งนี้:** ฝึกเทียบศักราช 10 ข้อ (สุ่มปีเอง เช่น ค.ศ. 2000, ร.ศ. 130, จ.ศ. 1200) ตรวจคำตอบด้วยการแปลงย้อนกลับ
- **อีก 3 วัน:** วาดเส้นเวลา ยุคหิน → ยุคโลหะ → ยุคประวัติศาสตร์สากล 4 ยุค โดยไม่ดูเอกสาร และจับคู่ชื่อจีนของรัฐโบราณ
- **อีก 1 สัปดาห์:** ทำแบบทดสอบท้ายบท ข้อที่ผิดให้กลับมาอ่านหัวข้อนั้นอีกครั้ง และอธิบายวิธีการทางประวัติศาสตร์ 5 ขั้นให้คุณพ่อฟัง
