## เป้าหมายของบทนี้

- บอกแหล่งมรดกโลกทางธรรมชาติและอุทยานธรณีโลกของไทย พร้อมจังหวัดที่ตั้งและจุดเด่น
- แยก "สัตว์ป่าสงวน" กับ "สัตว์ป่าคุ้มครอง" และยกตัวอย่างสัตว์ป่าสงวนได้
- อธิบายภัยธรรมชาติ ประเภทของพายุ ("ดี โซน ไต้") และลมมรสุม/ลมประจำถิ่น ("เหนือหนาว ตกใต้")
- จับคู่อนุสัญญา/องค์กรสิ่งแวดล้อมกับเรื่องที่ดูแล และอธิบายหลัก 7R

## 1. แหล่งมรดกโลกทางธรรมชาติของไทย (#78 ต่อ)

ไทยมีมรดกโลกทางธรรมชาติ 3 แห่ง

| แหล่ง | ที่ตั้ง | จุดเด่น |
|---|---|---|
| ทุ่งใหญ่นเรศวร–ห้วยขาแข้ง (2534) | อุทัยธานี ตาก กาญจนบุรี | ป่าอนุรักษ์กว้างที่สุด "ผู้ยิ่งใหญ่ทั้ง 7" (ทบทวนจาก PART 11) |
| ผืนป่าดงพญาเย็น–เขาใหญ่ (2548) | อุทยานแห่งชาติเขาใหญ่ครอบคลุม 4 จังหวัด: **สระบุรี นครราชสีมา ปราจีนบุรี นครนายก** | เป็นทั้งมรดกโลกทางธรรมชาติและ **อุทยานมรดกแห่งอาเซียน (ASEAN Heritage Park)** |
| กลุ่มป่าแก่งกระจาน (2564) | บน **เทือกเขาตะนาวศรี** ครอบคลุม **ราชบุรี เพชรบุรี ประจวบคีรีขันธ์** | "บ้านหลังใหญ่ของสัตว์ป่า" พบสัตว์ป่า 459 ชนิด มีสัตว์ใกล้สูญพันธุ์ขั้นวิกฤต 4 ชนิด: จระเข้น้ำจืด ลิ่นชวา เต่าเหลือง เต่าหก |

หมายเหตุ: เอกสารเรียกว่า "อุทยานแห่งชาติเขาใหญ่" ซึ่งเป็นส่วนสำคัญที่สุดของมรดกโลก "กลุ่มป่าดงพญาเย็น–เขาใหญ่" (กลุ่มป่าทั้งหมดกว้างกว่าอุทยานเขาใหญ่)

### อุทยานธรณีโลกของยูเนสโก (UNESCO Global Geopark)

อุทยานธรณี = พื้นที่ที่มีลักษณะทางธรณีวิทยา (หิน ฟอสซิล ภูมิประเทศ) โดดเด่น ใช้เพื่อการอนุรักษ์ การศึกษา และการท่องเที่ยว

| อุทยานธรณีโลก | จุดเด่น |
|---|---|
| **สตูล** (แห่งแรกของไทย) | ลำดับที่ 36 ของโลก (ตามเอกสาร) และแห่งที่ 5 ของอาเซียน ครอบคลุม 4 อำเภอ (ทุ่งหว้า มะนัง ละงู เมือง) เป็นเทือกเขาหินปูน มีหลักฐานพื้นทะเลเก่าราว 500 ล้านปี |
| **โคราช** | ลุ่มน้ำลำตะคอง 5 อำเภอของนครราชสีมา ภูมิประเทศ **เขาเควสตา (เขารูปอีโต้)** และฟอสซิล 3 ยุค (ครีเทเชียส นีโอจีน ควอเทอร์นารี) → "ดินแดนแห่งเควสตาและฟอสซิล" |

**นครราชสีมา = เมือง 3 มงกุฎ** ของยูเนสโก (แห่งเดียวในไทย และเป็นเมืองที่ 4 ของโลก ต่อจากอิตาลี เกาหลีใต้ จีน) ได้แก่ มรดกโลก (เขาใหญ่) + พื้นที่สงวนชีวมณฑล (สะแกราช) + อุทยานธรณีโลก (โคราช)

## 2. สัตว์ป่าสงวน และสัตว์ป่าคุ้มครอง (#79)

| | สัตว์ป่าสงวน | สัตว์ป่าคุ้มครอง |
|---|---|---|
| ความหมาย | สัตว์หายากหรือใกล้สูญพันธุ์ กฎหมายกำหนดรายชื่อไว้เฉพาะ | สัตว์ที่กฎหมายกำหนดให้คุ้มครองเพื่อไม่ให้ลดจำนวนลง |
| จำนวน | น้อย (ราว 20 ชนิด) | มาก (หลายร้อยชนิด) |
| ตัวอย่าง | ดูด้านล่าง | ช้างป่า เสือโคร่ง นกเงือกหลายชนิด ชะนี |

### ตัวอย่างสัตว์ป่าสงวนของไทย (ภาพในเอกสารมี 20 ชนิด)

- **สัตว์บก**: แรด กระซู่ กูปรี (โคไพร) ควายป่า ละองหรือละมั่ง สมัน (สูญพันธุ์ไปแล้ว) เก้งหม้อ เลียงผา กวางผา สมเสร็จ แมวลายหินอ่อน
- **นก**: นกเจ้าฟ้าหญิงสิรินธร นกแต้วแล้วท้องดำ นกกระเรียนพันธุ์ไทย นกชนหิน
- **สัตว์ทะเล**: พะยูน วาฬบรูด้า วาฬโอมูระ ฉลามวาฬ เต่ามะเฟือง

จุดหลอกในข้อสอบ: **ช้างป่า และเสือโคร่ง เป็นสัตว์ป่าคุ้มครอง ไม่ใช่สัตว์ป่าสงวน**

## 3. ภัยธรรมชาติ (#80)

| ภัย | สาเหตุ / ลักษณะ |
|---|---|
| น้ำท่วม | ฝนตกหนักต่อเนื่อง พายุ ป่าถูกทำลาย ระบายน้ำไม่ทัน |
| แผ่นดินไหว | การเคลื่อนตัวของเปลือกโลก (รอยเลื่อน) |
| สึนามิ | คลื่นยักษ์จากแผ่นดินไหวใต้ทะเล เช่น เหตุการณ์ 26 ธันวาคม 2547 ฝั่งทะเลอันดามัน |
| พายุ | ความกดอากาศต่ำ ลมแรง ฝนตกหนัก |
| เอลนีโญ | น้ำทะเลแปซิฟิกตะวันออกอุ่นผิดปกติ → ไทยและเอเชียตะวันออกเฉียงใต้ **ฝนน้อย แห้งแล้ง** |
| ลานีญา | ตรงข้ามเอลนีโญ → ไทย **ฝนมากกว่าปกติ** เสี่ยงน้ำท่วม |

จำ: **เอลนีโญ = แล้ง, ลานีญา = ฝนชุก** ("ญา" น้ำมา)

### ประเภทของพายุ (#81)

**แบ่งตามความเร็วลม — คาถา "ดี โซน ไต้"** (อ่อน → แรง)

| พายุ | ความเร็วลมใกล้ศูนย์กลาง (โดยประมาณ) |
|---|---|
| **ดี**เปรสชัน | ต่ำกว่า 63 กม./ชม. |
| พายุ**โซน**ร้อน | 63–117 กม./ชม. |
| พายุ**ไต้**ฝุ่น (เมื่อเกิดแถบแปซิฟิกตะวันตก) | 118 กม./ชม. ขึ้นไป |

**แบ่งตามแหล่งที่เกิด** — พายุหมุนเขตร้อนกำลังแรง แต่เรียกชื่อต่างกันตามพื้นที่

| ชื่อ | เกิดที่ |
|---|---|
| ไต้ฝุ่น | มหาสมุทรแปซิฟิกตะวันตก ทะเลจีนใต้ (ใกล้จีน ญี่ปุ่น ฟิลิปปินส์) |
| ไซโคลน | มหาสมุทรอินเดีย อ่าวเบงกอล |
| วิลลี–วิลลี | บริเวณทวีปออสเตรเลีย |
| เฮอริเคน | มหาสมุทรแอตแลนติก ทะเลแคริบเบียน และแปซิฟิกตะวันออก (ใกล้ทวีปอเมริกา) |

### ประเภทของลม

**ลมมรสุม — คาถา "เหนือหนาว ตกใต้"**

| ลมมรสุม | ช่วงเวลา (ประมาณ) | ผล |
|---|---|---|
| มรสุมตะวันออก**เฉียงเหนือ** | กลาง ต.ค. – ก.พ. | นำความ **หนาว** และแห้งมาจากจีน (ภาคใต้ฝั่งอ่าวไทยยังมีฝน) |
| มรสุม**ตะวันตกเฉียงใต้** | กลาง พ.ค. – กลาง ต.ค. | นำความชื้นจากมหาสมุทรอินเดีย ทำให้ **ฝนตก** ทั่วประเทศ |

**ลมประจำถิ่น** ที่เอกสารยกมา

| ลม | ความรู้เสริม |
|---|---|
| ลมข้าวเบา / ลมว่าว | ลมจากทิศเหนือช่วงต้นฤดูหนาว ตรงกับช่วงข้าวเบาออกรวง และเด็ก ๆ เล่นว่าว |
| ลมตะเภา | ลมจากทิศใต้พัดจากอ่าวไทยเข้าภาคกลางช่วงฤดูร้อน สมัยก่อนเรือสำเภาอาศัยลมนี้แล่นเข้ามาค้าขาย |
| ลมสลาตัน | ลมแรงจากทางตะวันตกเฉียงใต้ ที่ชาวเรือรู้จักว่าทำให้คลื่นลมแรง |
| ลมพัทธยา | ลมจากทิศตะวันตกเฉียงใต้ |
| ลมอุตรา | ลมจากทิศเหนือ |

## 4. ความร่วมมือด้านสิ่งแวดล้อม (#82)

| ชื่อ | ดูแลเรื่อง |
|---|---|
| **ไซเตส (CITES)** | การค้าระหว่างประเทศของสัตว์ป่าและพืชป่าที่ใกล้สูญพันธุ์ |
| **แรมซาร์ (Ramsar)** | การอนุรักษ์ **พื้นที่ชุ่มน้ำ** (เช่น พรุควนขี้เสียน จ.พัทลุง เป็นแรมซาร์ไซต์แห่งแรกของไทย) |
| **พิธีสารเกียวโต** | ลดการปล่อย **ก๊าซเรือนกระจก** แก้ภาวะโลกร้อน |
| **พิธีสารมอนทรีออล** | ลด/เลิกสารที่ **ทำลายชั้นโอโซน** เช่น สาร CFC |
| **UNFCCC** | อนุสัญญาสหประชาชาติว่าด้วยการเปลี่ยนแปลงสภาพภูมิอากาศ (เป็นกรอบใหญ่ของพิธีสารเกียวโต) |
| **กรีนพีซ (Greenpeace)** | องค์กรเอกชน (NGO) ระหว่างประเทศ รณรงค์ปกป้องสิ่งแวดล้อม — ไม่ใช่สนธิสัญญา |

คาถาจำ: **เกียวโต = โลกร้อน, มอนทรีออล = โอโซน** ("มอน–โอ" มี "โอ" เหมือนกัน), **แรมซาร์ = ชุ่มน้ำ, ไซเตส = ค้าสัตว์/พืช**

### พืชและสัตว์ป่าในบัญชีไซเตส (#83)

ตัวอย่างที่มีชื่อในเอกสาร: **จระเข้น้ำจืด, เต่ามะเฟือง, เอื้องปากนกแก้ว (กล้วยไม้), เมื่อยขาว** — ภาพอื่นในเอกสารที่ยังไม่มีชื่อ (เช่น ไม้ยืนต้น ดอกไม้สีม่วง งู ปลา และตัวลิ่น) ให้เติมชื่อจากคลิป

## 5. การแก้ไขปัญหาสิ่งแวดล้อม: หลัก 7R (#84)

| R | ความหมาย | ตัวอย่าง |
|---|---|---|
| Rethink | คิดใหม่ก่อนซื้อหรือใช้ | ถามตัวเองว่า "จำเป็นจริงไหม" |
| Reduce | ลดการใช้ | ใช้กระดาษสองหน้า |
| Reuse | ใช้ซ้ำ | ใช้ขวดแก้วใส่น้ำซ้ำ |
| Recycle | นำกลับมาแปรรูปใหม่ | แยกขวดพลาสติก กระป๋อง ส่งรีไซเคิล |
| Refuse | ปฏิเสธสิ่งที่ทำลายสิ่งแวดล้อม | ไม่รับถุงพลาสติก ไม่รับหลอด |
| Repair | ซ่อมแซมให้ใช้ต่อได้ | ซ่อมรองเท้า เย็บกระเป๋า |
| Return | ส่งคืนผู้ผลิต | คืนขวดหรือบรรจุภัณฑ์ให้ร้าน/ผู้ผลิตนำไปจัดการ |

แยกให้ออก: **Reuse = ใช้ของเดิมซ้ำโดยไม่แปรรูป** / **Recycle = ต้องแปรรูปผ่านกระบวนการ** / **Refuse = ไม่รับตั้งแต่แรก**

## ตัวอย่างวิธีคิด

**ตัวอย่างที่ 1 (จัดประเภทพายุ):** พายุลูกหนึ่งมีความเร็วลม 90 กม./ชม. อยู่ในทะเลจีนใต้ จัดเป็นอะไร
1. เทียบ "ดี โซน ไต้": 90 อยู่ในช่วง 63–117 → **พายุโซนร้อน**
2. ถ้าแรงขึ้นจนเกิน 118 กม./ชม. ในบริเวณนี้จะเรียกว่า "ไต้ฝุ่น"

**ตัวอย่างที่ 2 (เลือกอนุสัญญา):** ประเทศหนึ่งต้องการลดการใช้สารทำความเย็นที่ทำให้ชั้นโอโซนบางลง ควรเข้าร่วมอะไร → สารทำลายโอโซน = **พิธีสารมอนทรีออล** (ไม่ใช่เกียวโต ซึ่งเป็นเรื่องก๊าซเรือนกระจก)

**ตัวอย่างที่ 3 (7R):** น้องนำกล่องนมมาตัดเป็นกระถางปลูกต้นไม้ → ใช้ของเดิมซ้ำโดยไม่ส่งไปแปรรูปที่โรงงาน = **Reuse**; ถ้าส่งกล่องนมไปโรงงานทำเป็นแผ่นหลังคา = **Recycle**

**ตัวอย่างที่ 4 (ลมมรสุม):** เดือนกรกฎาคมกรุงเทพฯ ฝนตกบ่อยเพราะลมใด → ช่วง พ.ค.–ต.ค. = **มรสุมตะวันตกเฉียงใต้** ("ตกใต้")

## จุดที่มักสับสน

- **สัตว์ป่าสงวน vs คุ้มครอง**: ช้าง/เสือโคร่ง = คุ้มครอง; พะยูน/สมเสร็จ/เต่ามะเฟือง = สงวน
- **เอลนีโญ (แล้ง) vs ลานีญา (ฝนมาก)**
- **ไต้ฝุ่น/ไซโคลน/เฮอริเคน/วิลลี–วิลลี** คือพายุชนิดเดียวกัน ต่างกันที่ "ที่เกิด"
- **มรสุมตะวันออกเฉียงเหนือ = หนาว / ตะวันตกเฉียงใต้ = ฝน**
- **กรีนพีซเป็นองค์กรเอกชน** ไม่ใช่อนุสัญญา
- **อุทยานธรณีโลกแห่งแรกของไทย = สตูล** (ไม่ใช่โคราช)
- **แก่งกระจานอยู่บนเทือกเขาตะนาวศรี** (ตะวันตก) ส่วน **เขาใหญ่อยู่ระหว่างภาคกลาง–อีสาน–ตะวันออก**

## ⭐ ประเด็นสำคัญที่ได้จากบทเรียนนี้

- มรดกโลกธรรมชาติ: ทุ่งใหญ่–ห้วยขาแข้ง, ดงพญาเย็น–เขาใหญ่ (4 จังหวัด), แก่งกระจาน (ราชบุรี เพชรบุรี ประจวบฯ)
- อุทยานธรณีโลก: สตูล (แห่งแรก) และโคราช (เขาเควสตา); นครราชสีมา = เมือง 3 มงกุฎ
- สัตว์ป่าสงวน ราว 20 ชนิด เช่น พะยูน สมเสร็จ กูปรี เต่ามะเฟือง ฉลามวาฬ นกชนหิน
- พายุ "ดี โซน ไต้" ตามความเร็วลม; ไต้ฝุ่น/ไซโคลน/วิลลี–วิลลี/เฮอริเคน ตามแหล่งเกิด
- มรสุม "เหนือหนาว ตกใต้"
- ไซเตส = ค้าสัตว์พืชป่า, แรมซาร์ = ชุ่มน้ำ, เกียวโต = เรือนกระจก, มอนทรีออล = โอโซน
- 7R: Rethink Reduce Reuse Recycle Refuse Repair Return

## แผนทบทวน

- **วันนี้:** ดูคลิปแล้วเติมช่องว่างในเอกสารหน้า 89–92 (ชื่อสัตว์ป่าสงวน 20 ภาพ, ตารางพายุ, ความหมายอนุสัญญา, ชื่อพืช/สัตว์ในบัญชีไซเตส, ความหมาย 7R)
- **พรุ่งนี้:** ท่อง "ดี โซน ไต้" และ "เหนือหนาว ตกใต้" แล้วอธิบายให้คนในบ้านฟังพร้อมตัวอย่าง
- **อีก 3 วัน:** ทำบัตรคำจับคู่ อนุสัญญา ↔ เรื่องที่ดูแล และ สัตว์ ↔ สงวน/คุ้มครอง
- **อีก 1 สัปดาห์:** ทำแบบทดสอบท้ายบท แล้วสำรวจขยะในบ้านว่าใช้ R ข้อไหนได้บ้าง
