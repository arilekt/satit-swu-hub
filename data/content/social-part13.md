## เป้าหมายของบทนี้

- อธิบายความเป็นมา สัญลักษณ์ และสมาชิก 11 ประเทศของอาเซียน พร้อมเมืองหลวงและสกุลเงิน
- บอก 3 เสาหลักของประชาคมอาเซียน และ 8 อาชีพที่เคลื่อนย้ายแรงงานได้เสรี
- แยกกลุ่มอาเซียน +3 / +6 / +8 ได้
- บอกทวีปทั้ง 7 (ใหญ่สุด/เล็กสุด) และเข้าใจว่าทำไมอาร์กติกไม่ใช่ทวีป
- อธิบายสัญลักษณ์โอลิมปิกและสัญลักษณ์สำคัญที่ควรรู้

## 1. อาเซียน (#85)

**ASEAN = Association of Southeast Asian Nations** หรือ **สมาคมประชาชาติแห่งเอเชียตะวันออกเฉียงใต้**

- ก่อตั้งโดย **ปฏิญญากรุงเทพ (Bangkok Declaration)** เมื่อ 8 สิงหาคม 2510 ที่กรุงเทพฯ (วันที่ 8 สิงหาคมจึงเป็น "วันอาเซียน")
- ผู้ก่อตั้ง 5 ประเทศ: **ไทย อินโดนีเซีย มาเลเซีย ฟิลิปปินส์ สิงคโปร์**
- สำนักงานเลขาธิการอาเซียนอยู่ที่ **กรุงจาการ์ตา อินโดนีเซีย**
- คำขวัญ: "One Vision, One Identity, One Community" (หนึ่งวิสัยทัศน์ หนึ่งอัตลักษณ์ หนึ่งประชาคม)

### ความหมายของสีในสัญลักษณ์อาเซียน

| สี | ความหมาย |
|---|---|
| เหลือง | ความเจริญรุ่งเรือง |
| แดง | ความกล้าหาญและความก้าวหน้า |
| ขาว | ความบริสุทธิ์ |
| น้ำเงิน | สันติภาพและความมั่นคง |

รวงข้าวที่มัดรวมกันหมายถึงประเทศสมาชิกที่ผูกพันเป็นหนึ่งเดียว (โลโก้ออกแบบสมัยมีสมาชิก 10 ประเทศ)

### สมาชิก 11 ประเทศ

| ประเทศ | เมืองหลวง | สกุลเงิน | เข้าร่วม |
|---|---|---|---|
| ไทย | กรุงเทพฯ | บาท | ผู้ก่อตั้ง (2510) |
| อินโดนีเซีย | จาการ์ตา (กำลังย้ายไปนูซันตารา) | รูเปียห์ | ผู้ก่อตั้ง |
| มาเลเซีย | กัวลาลัมเปอร์ (ศูนย์ราชการที่ปุตราจายา) | ริงกิต | ผู้ก่อตั้ง |
| ฟิลิปปินส์ | มะนิลา | เปโซ | ผู้ก่อตั้ง |
| สิงคโปร์ | สิงคโปร์ | ดอลลาร์สิงคโปร์ | ผู้ก่อตั้ง |
| บรูไนดารุสซาลาม | บันดาร์เสรีเบกาวัน | ดอลลาร์บรูไน | 2527 |
| เวียดนาม | ฮานอย | ด่ง | 2538 |
| ลาว | เวียงจันทน์ | กีบ | 2540 |
| เมียนมา | เนปยีดอ | จ๊าด | 2540 |
| กัมพูชา | พนมเปญ | เรียล | 2542 |
| ติมอร์-เลสเต | ดิลี | ดอลลาร์สหรัฐ | สมาชิกลำดับที่ 11 (ตุลาคม 2568) |

เทคนิคจำลำดับเข้าร่วม: **"ห้าผู้ก่อตั้ง → บรู → เวียด → ลาว-พม่า → เขมร → ติมอร์"**

### 3 เสาหลักของประชาคมอาเซียน

| เสาหลัก | ตัวย่อ | เน้น |
|---|---|---|
| ประชาคมการเมืองและความมั่นคงอาเซียน | APSC | สันติภาพ แก้ข้อขัดแย้งอย่างสันติ |
| ประชาคมเศรษฐกิจอาเซียน | AEC | ตลาดและฐานการผลิตเดียว ค้าขายสะดวก |
| ประชาคมสังคมและวัฒนธรรมอาเซียน | ASCC | คุณภาพชีวิต การศึกษา สาธารณสุข วัฒนธรรม |

จำ: **"การเมือง–เศรษฐกิจ–สังคมวัฒนธรรม" = P-E-SC**

### 8 อาชีพเคลื่อนย้ายแรงงานเสรีในอาเซียน

วิศวกร · พยาบาล · สถาปนิก · นักสำรวจ · แพทย์ · ทันตแพทย์ · นักบัญชี · มัคคุเทศก์ (การท่องเที่ยว)

### ผู้นำประเทศในอาเซียน (กิจกรรมจับคู่ในเอกสาร)

เอกสารให้จับคู่ประเทศกับผู้นำ (คอลัมน์ในเอกสารสลับกันโดยตั้งใจ) คู่ที่ถูกต้องตามข้อมูลในเอกสาร:

| ประเทศ | ผู้นำ |
|---|---|
| เมียนมา | พลเอกอาวุโส มิน อ่อง หล่าย |
| มาเลเซีย | นายอันวาร์ อิบราฮิม |
| อินโดนีเซีย | นายปราโบโว ซูเบียนโต |
| ฟิลิปปินส์ | นายเฟอร์ดินานด์ มาร์กอส จูเนียร์ |
| สิงคโปร์ | นายลอว์เรนซ์ หว่อง |
| ติมอร์-เลสเต | นายโชเซ ราโมส-ออร์ตา (ประธานาธิบดี) |

ข้อควรระวัง: ผู้นำประเทศเปลี่ยนได้ตามการเลือกตั้ง ก่อนสอบควรตรวจข้อมูลล่าสุดอีกครั้ง

### อาเซียนกับประเทศคู่เจรจา

| กลุ่ม | ประเทศที่เพิ่มเข้ามา |
|---|---|
| อาเซียน **+3** | จีน ญี่ปุ่น เกาหลีใต้ |
| อาเซียน **+6** | +3 และ ออสเตรเลีย นิวซีแลนด์ อินเดีย |
| อาเซียน **+8** | +6 และ รัสเซีย สหรัฐอเมริกา |
| +9 (ตามเอกสาร) | +8 และ แคนาดา |

จำ: **+3 = เอเชียตะวันออก (จีน ญี่ปุ่น เกาหลีใต้)** → **+6 เติม "ออส นิว อินเดีย"** → **+8 เติม "รัสเซีย อเมริกา"**

## 2. ทวีปของโลก

โลกมี **7 ทวีป**: เอเชีย · แอฟริกา · อเมริกาเหนือ · อเมริกาใต้ · แอนตาร์กติกา · ยุโรป · ออสเตรเลีย

- **ใหญ่ที่สุด: เอเชีย** (ไทยอยู่ในทวีปนี้)
- **เล็กที่สุด: ออสเตรเลีย**
- **แอนตาร์กติกา** อยู่ขั้วโลกใต้ เป็นแผ่นดินจริงที่มีน้ำแข็งปกคลุม (มีเพนกวิน)
- **อาร์กติก (ขั้วโลกเหนือ) ไม่ใช่ทวีป** เพราะเป็นมหาสมุทรอาร์กติกที่มีน้ำแข็งลอยอยู่ ไม่มีแผ่นดินรองรับ (มีหมีขั้วโลก)

เทคนิคจำ: **"เพนกวินอยู่ใต้บนทวีป หมีขาวอยู่เหนือบนน้ำแข็ง"**

## 3. โอลิมปิก

- สัญลักษณ์ **5 ห่วงคล้องกัน** (น้ำเงิน เหลือง ดำ เขียว แดง บนพื้นขาว) หมายถึงความสามัคคีของ 5 ทวีปที่มีผู้คนอาศัย และสีของห่วงรวมกับพื้นขาวสามารถประกอบเป็นสีธงชาติทั่วโลกได้ (เอกสารสรุปว่า "5 ห่วงมาจาก 5 สีในธงชาติทั่วโลก")
- จัดทุก ๆ **4 ปี**
- แบ่งเป็น **โอลิมปิกฤดูร้อน** และ **โอลิมปิกฤดูหนาว** (จัดสลับกัน ห่างกัน 2 ปี)
- **คบเพลิงโอลิมปิกจุดที่ "โอลิมเปีย" ประเทศกรีซ** (แหล่งกำเนิดกีฬาโอลิมปิกโบราณ) โดยรวมแสงอาทิตย์ด้วยกระจกโค้ง แล้ววิ่งส่งต่อไปยังประเทศเจ้าภาพ — เอกสารเขียนว่า "ภูเขา Olympus" แต่สถานที่จุดไฟจริงคือเมืองโบราณโอลิมเปีย ไม่ใช่ภูเขาโอลิมปัส (ภูเขาโอลิมปัสเป็นภูเขาในตำนานเทพเจ้ากรีก คนละที่กัน)

## 4. สัญลักษณ์ควรรู้

| สัญลักษณ์ | ความหมาย |
|---|---|
| สวัสติกะ (กากบาทหักมุม) | เดิมเป็นเครื่องหมายมงคลในศาสนาฮินดูและพุทธ แต่แบบเอียงในวงกลมบนพื้นแดงเป็นสัญลักษณ์ของพรรคนาซีเยอรมนีในสงครามโลกครั้งที่ 2 |
| องค์การอนามัยโลก (WHO) | ไม้เท้ามีงูพัน (สัญลักษณ์การแพทย์) วางบนแผนที่โลกล้อมด้วยช่อมะกอกแบบสหประชาชาติ |
| ค้อนเคียว | สัญลักษณ์ลัทธิคอมมิวนิสต์ ค้อน = กรรมกร เคียว = ชาวนา |
| เพนตาแกรม (ดาวห้าแฉกในวงกลม) | สัญลักษณ์ที่ใช้ในความเชื่อเรื่องเวทมนตร์และลัทธิลึกลับบางกลุ่ม |

## ตัวอย่างวิธีคิด

**ตัวอย่างที่ 1 (อาเซียน +):** ประเทศใดอยู่ในอาเซียน +6 แต่ไม่อยู่ในอาเซียน +3
1. +3 = จีน ญี่ปุ่น เกาหลีใต้
2. +6 เพิ่ม ออสเตรเลีย นิวซีแลนด์ อินเดีย
3. ตอบได้ 3 ประเทศนี้ เช่น อินเดีย (ถ้าตัวเลือกมีรัสเซีย ต้องตัดออก เพราะรัสเซียเข้ามาใน +8)

**ตัวอย่างที่ 2 (นับปี):** จากปีก่อตั้งอาเซียน (2510) ถึงปีที่ติมอร์-เลสเตเข้าร่วม (2568) ห่างกันกี่ปี → 2568 − 2510 = 58 ปี; ถ้าถามเป็น ค.ศ. ก่อตั้ง = 2510 − 543 = 1967

**ตัวอย่างที่ 3 (เสาหลัก):** การลดภาษีนำเข้าสินค้าระหว่างไทยกับเวียดนาม อยู่ในเสาหลักใด → เรื่องการค้า = **AEC (ประชาคมเศรษฐกิจ)** ไม่ใช่ ASCC ซึ่งเป็นเรื่องสังคม การศึกษา วัฒนธรรม

**ตัวอย่างที่ 4 (ทวีป):** "ทวีปนี้อยู่ขั้วโลก มีแผ่นดินและน้ำแข็งหนา" → **แอนตาร์กติกา** (อาร์กติกไม่มีแผ่นดิน จึงไม่ใช่ทวีป)

## จุดที่มักสับสน

- **ปฏิญญากรุงเทพ** (ก่อตั้งอาเซียน) ≠ กฎบัตรอาเซียน (ธรรมนูญของอาเซียน ทำภายหลัง)
- **ผู้ก่อตั้ง 5 ประเทศไม่มีบรูไน** (บรูไนเข้า 2527)
- **เมืองหลวงเมียนมา = เนปยีดอ** (ไม่ใช่ย่างกุ้ง), **เวียดนาม = ฮานอย** (ไม่ใช่โฮจิมินห์)
- **ติมอร์-เลสเตใช้ดอลลาร์สหรัฐ**
- **สีแดง = กล้าหาญ ก้าวหน้า / น้ำเงิน = สันติภาพ มั่นคง** อย่าสลับ
- **ใหญ่สุดเอเชีย เล็กสุดออสเตรเลีย** / **อาร์กติกไม่ใช่ทวีป**
- **คบเพลิงจุดที่โอลิมเปีย** ไม่ใช่ภูเขาโอลิมปัส

## ⭐ Key Takeaways

- อาเซียนก่อตั้งด้วยปฏิญญากรุงเทพ 8 ส.ค. 2510 ผู้ก่อตั้ง 5 ประเทศ ปัจจุบัน 11 ประเทศ (ติมอร์-เลสเตล่าสุด)
- สีโลโก้: เหลือง = รุ่งเรือง แดง = กล้าหาญก้าวหน้า ขาว = บริสุทธิ์ น้ำเงิน = สันติภาพมั่นคง
- 3 เสาหลัก: APSC การเมือง-ความมั่นคง / AEC เศรษฐกิจ / ASCC สังคม-วัฒนธรรม
- 8 อาชีพเสรี: วิศวกร พยาบาล สถาปนิก นักสำรวจ แพทย์ ทันตแพทย์ นักบัญชี มัคคุเทศก์
- +3 จีน ญี่ปุ่น เกาหลีใต้ / +6 เพิ่ม ออสเตรเลีย นิวซีแลนด์ อินเดีย / +8 เพิ่ม รัสเซีย สหรัฐฯ
- 7 ทวีป ใหญ่สุดเอเชีย เล็กสุดออสเตรเลีย อาร์กติกไม่ใช่ทวีป
- โอลิมปิก 5 ห่วง ทุก 4 ปี ฤดูร้อน/ฤดูหนาว คบเพลิงจุดที่โอลิมเปีย กรีซ
