## จัดสรุปให้อ่านง่ายเป็น 5 กลุ่ม

| สาระ | คำถามที่ช่วยจำ |
| --- | --- |
| ศาสนา ศีลธรรม จริยธรรม | เราจะใช้ชีวิตอย่างมีสติและทำดีอย่างไร |
| หน้าที่พลเมือง วัฒนธรรม และการดำเนินชีวิตในสังคม | เราอยู่ร่วมกันอย่างเคารพสิทธิได้อย่างไร |
| เศรษฐศาสตร์ | เราเลือกใช้ทรัพยากรที่มีจำกัดอย่างไร |
| ประวัติศาสตร์ | เราใช้หลักฐานเรียนรู้เรื่องราวในอดีตอย่างไร |
| ภูมิศาสตร์ | พื้นที่ ธรรมชาติ และมนุษย์เกี่ยวข้องกันอย่างไร |

### ถ้ามีเอกสารสรุปหรือ PDF

อ่านเอกสารที่คุณพ่อเตรียมไว้ แล้วแยกจดสรุปตาม 5 กลุ่มนี้ **เว็บไม่เก็บ PDF ฉบับเต็มใน repository** และหน้านี้ยังไม่ได้สรุปจาก PDF ที่อัปโหลด

> หลังอ่านแต่ละกลุ่ม ลองสร้างคำถามหนึ่งข้อ พร้อมเหตุผลของคำตอบ

สามารถใส่ลิงก์เอกสารภายนอกใน Markdown ได้ภายหลัง โดยเลือกเอกสารที่มีสิทธิ์เผยแพร่
