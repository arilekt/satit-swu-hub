## เป้าหมายของบทนี้

- แยกส่วนประกอบของพยางค์ (3 ส่วน 4 ส่วน 4 ส่วนพิเศษ 5 ส่วน) และนับพยางค์ได้
- แยกคำเป็น/คำตาย และพยางค์เปิด/พยางค์ปิด
- เข้าใจความหมายของคำแบบต่าง ๆ และคำที่มักใช้สลับกันผิด
- แยกคำพ้อง 4 แบบ และคำมูล คำประสม คำประสาน คำซ้อน คำซ้ำ ได้

## 1. พยางค์

### พยางค์คืออะไร

**พยางค์** คือเสียงที่เปล่งออกมาหนึ่งครั้ง จะมีความหมายหรือไม่มีก็ได้
- พยางค์ที่มีความหมาย = เป็น "คำ" ได้ด้วย เช่น มา กิน นอน
- พยางค์ที่ไม่มีความหมาย เช่น "ฬิ" ใน นาฬิกา หรือ "ละ" ใน มะละกอ แยกออกมาเดี่ยว ๆ ไม่มีความหมาย

คำหนึ่งคำอาจมีหลายพยางค์ เช่น นาฬิกา (3 พยางค์), ประวัติศาสตร์ อ่านว่า ประ-หวัด-ติ-สาด (4 พยางค์) **นับพยางค์ตามเสียงที่อ่าน ไม่ใช่ตามตัวเขียน**

### ส่วนประกอบของพยางค์

| แบบ | พยัญชนะต้น | สระ | วรรณยุกต์ | ตัวสะกด | ตัวการันต์ | ตัวอย่าง |
|---|---|---|---|---|---|---|
| 3 ส่วน | ✔ | ✔ | ✔ | | | ปลา มา ดู |
| 4 ส่วน | ✔ | ✔ | ✔ | ✔ | | กิน ข้าว นก |
| 4 ส่วนพิเศษ | ✔ | ✔ | ✔ | | ✔ | เล่ห์ |
| 5 ส่วน | ✔ | ✔ | ✔ | ✔ | ✔ | จันทร์ สัตว์ ยักษ์ สิงห์ |

ทุกพยางค์มี 3 ส่วนพื้นฐานเสมอ (แม้ไม่มีรูปวรรณยุกต์ก็ยังมี "เสียง" วรรณยุกต์) ส่วนตัวสะกดกับการันต์เป็นส่วนเพิ่ม

### คำเป็น / คำตาย

| คำเป็น | คำตาย |
|---|---|
| สระเสียงยาว ไม่มีตัวสะกด (มา ดี ปู) | สระเสียงสั้น ไม่มีตัวสะกด (จะ ติ ดุ) |
| สระ อำ ใอ ไอ เอา (จำ ใจ ไป เขา) | สะกดด้วย ก บ ด (แม่กก กบ กด) เช่น นก บาป มีด |
| สะกดด้วย น ม ย ว ง (แม่กน กม เกย เกอว กง) | |

> จำ: คำตาย "สั้นเปล่า หรือ ก บ ด" — คำเป็น "ยาวเปล่า อำใอไอเอา หรือ น ม ย ว ง"

### พยางค์เปิด / พยางค์ปิด

- **พยางค์เปิด** ไม่มีตัวสะกด เช่น ตา ปู มือ
- **พยางค์ปิด** มีตัวสะกด เช่น ตาก ตาม ตัก

## 2. ความหมายของคำ

### ความหมายเฉพาะ

- **ความหมายตรงตามตัว** เช่น เสือ = สัตว์ป่าชนิดหนึ่ง
- **ความหมายนัยประหวัด / เชิงอุปมา** คือความหมายแฝงที่คนนึกถึง เช่น เสือ = ดุร้าย, หมู = ง่าย ("ข้อสอบหมูมาก")

### ความหมายเทียบเคียง

| แบบ | ตัวอย่าง |
|---|---|
| เหมือนกัน | บุปผา / ผกา / มาลี (ดอกไม้) |
| คล้ายกัน / ใกล้เคียง | ตัด / หั่น / ผ่า |
| ตรงข้าม | ดี–ชั่ว, สูง–ต่ำ |
| ครอบคลุมคำอื่น | ญาติ ครอบคลุม พี่ ป้า น้า อา |

### คำที่มีความหมายใกล้เคียงกัน (ใช้ให้ถูก)

| คำ | ใช้กับ |
|---|---|
| สมรรถภาพ | ความสามารถของคน เช่น สมรรถภาพทางกาย |
| สมรรถนะ | ความสามารถของเครื่องยนต์/ระบบ เช่น สมรรถนะของรถยนต์ |
| จักรวรรดิ | ดินแดน/อาณาจักรใหญ่ (Empire) |
| จักรพรรดิ | ผู้ปกครองจักรวรรดิ (Emperor) |
| คร่ำคร่า | เก่าแก่จนชำรุดทรุดโทรม ใช้กับสิ่งของ สิ่งปลูกสร้าง |
| คร่ำครึ | เก่าเกินไป ไม่ทันสมัย ใช้กับคน ความคิด |

(เอกสารพิมพ์ "จักวรรดิ / จักพรรดิ" ตกตัว ร ที่ถูกคือ **จักรวรรดิ / จักรพรรดิ**)

### คำที่มีความหมายตรงข้ามกัน

| คำ | คำตรงข้าม |
|---|---|
| มงคล | อวมงคล (เรื่องเศร้า เช่น งานศพ) |
| ทักษิณาวรรต (เวียนขวา ตามเข็มนาฬิกา) | อุตราวรรต (เวียนซ้าย) |
| นางฟ้า | เทวดา |
| สวรรค์ | นรก |
| สุริยัน (ดวงอาทิตย์) | จันทรา (ดวงจันทร์) |

## 3. การเพิ่มคำ

### คำพ้อง 4 แบบ

| แบบ | เสียง | รูปเขียน | ความหมาย | ตัวอย่าง |
|---|---|---|---|---|
| พ้องเสียง | เหมือน | ต่าง | ต่าง | การ / กาล / กาฬ, จัน / จันทร์ / จันทน์, ศรี / สี |
| พ้องรูป | ต่าง | เหมือน | ต่าง | เพลา (เพ-ลา = เวลา / เพลา = แกนล้อ), เสลา (สะ-เหลา = ต้นไม้ / เส-ลา = หิน) |
| พ้องทั้งรูปทั้งเสียง | เหมือน | เหมือน | ต่าง | ฉัน (สรรพนาม / พระกิน), ขัน (ไก่ขัน / ภาชนะ / ตลก), กา (นก / ภาชนะ) |
| พ้องความ (ไวพจน์) | ต่าง | ต่าง | เหมือน | ดอกไม้ = บุปผา ผกา มาลี, น้ำ = ชล อุทก วารี, ช้าง = คช หัตถี กุญชร |

### คำมูล

- เป็นคำพยางค์เดียว เช่น พ่อ แม่ กิน
- ถ้ามีหลายพยางค์ **แยกพยางค์แล้วไม่มีความหมายครบ** เช่น นาฬิกา มะละกอ ทะเล กระดาษ
- มาจากภาษาอะไรก็ได้ เช่น ฟุตบอล (อังกฤษ) ก็เป็นคำมูล

### คำประสม

นำ **คำมูลที่มีความหมาย ตั้งแต่ 2 คำขึ้นไป** มารวมกัน เกิดความหมายใหม่ แต่ยังมีเค้าความหมายเดิม

- แมว + น้ำ = แมวน้ำ (สัตว์ทะเล ไม่ใช่แมว)
- แม่ + บ้าน = แม่บ้าน
- น้ำ + อัด + ลม = น้ำอัดลม

**โครงสร้างตามภาษาที่มา**: ไทย+ไทย (ไฟฟ้า), ไทย+เขมร (นายตรวจ), บาลี+ไทย (ผลไม้)

**โครงสร้างตามชนิดคำ**: นาม+นาม (กล้วยแขก), นาม+บุพบท (คนกลาง), กริยา+กริยา (ต้มยำ), กริยา+นาม (ตั้งใจ)

**หน้าที่ของคำประสม**: เป็นนาม (แม่บ้าน บ้านนอก), กริยา (บาดตา อวดดี), วิเศษณ์ (เผาขน เช่น ยิงในระยะเผาขน)

**ความหมาย**: ตรงตัว (รถไฟ น้ำแข็ง) หรือเชิงอุปมา
- หัวอ่อน = ว่าง่าย สอนง่าย
- ตีนแมว = ขโมย
- หักหน้า = ทำให้คนอื่นได้รับความอับอาย
- ปากมาก = ชอบว่าคนอื่นซ้ำ ๆ ซาก ๆ

### คำประสาน (ตามเอกสาร)

เอกสารนิยามว่า คำที่สร้างขึ้นด้วยการรวม **หน่วยคำเติม** กับ **หน่วยฐาน** เป็นคำใหม่ และยกหน่วยคำเติมไว้ ได้แก่ การ- ความ- ภาวะ- ผู้- นัก- ช่าง- ที่- เครื่อง- พระ- ทรง- บรม- อย่าง- เช่น การเรียน ความรัก ผู้ใหญ่ นักร้อง ช่างไม้ ที่นอน เครื่องบิน อย่างดี (ช่องว่างในเอกสารให้เติมตัวอย่างระหว่างดูคลิป)

> หมายเหตุ: หนังสือบางเล่มเรียกคำกลุ่ม นัก- ช่าง- ผู้- ว่า "คำประสม" ให้ตอบตามนิยามที่ครูใช้ในห้องเรียน

### คำซ้อน

นำคำที่ความหมายหรือเสียงสัมพันธ์กันมาซ้อนกัน

**ซ้อนเพื่อความหมาย** (คำที่ความหมายเหมือน/คล้าย/ใกล้เคียง/ตรงข้าม)

| ผลที่เกิด | ตัวอย่าง |
|---|---|
| ความหมายเหมือนเดิม | กาลเวลา ก่อสร้าง ทรัพย์สิน |
| ความหมายเจาะจงที่คำใดคำหนึ่ง | ใจคอ หน้าตา หลับนอน |
| ความหมายกว้างกว่าเดิม | ถ้วยชาม (ภาชนะทั้งหมด) ลูกหลาน เสื้อผ้า |
| ความหมายเปลี่ยนไป | อบรม ดูแล กดขี่ ดูดดื่ม |
| ความหมายตรงข้ามกัน | ผิดชอบ ชั่วดี |

**ซ้อนเพื่อเสียง** มักใช้พยัญชนะต้นตัวเดียวกัน เปลี่ยนสระ เช่น เตาะแตะ มอมแมม อ้อนแอ้น ออดแอด ร่อแร่ งอแง ท้อแท้

### คำซ้ำ

ใช้ไม้ยมก (ๆ) เขียนแทนคำซ้ำได้ เช่น เด็ก ๆ ช้า ๆ

**ข้อยกเว้น (ห้ามใช้ ๆ)**
1. ในบทร้อยกรอง ให้เขียนคำเต็ม
2. คำที่เป็นคำเดียวอยู่แล้ว เช่น **นานา จะจะ**
3. คำที่เขียนเหมือนกันแต่คนละหน้าที่/ความหมาย เช่น "ของของใครทิ้งไว้เกะกะ" (ของ นาม + ของ บุพบท), "คนคนนี้ไม่น่าคบ" (คน นาม + คน ลักษณนาม) — ข้อสอบชอบออก

## ตัวอย่างวิธีคิด

**ตัวอย่างที่ 1: "สัตว์" มีส่วนประกอบกี่ส่วน**
1. ส = พยัญชนะต้น, สระอะ (เปลี่ยนรูปเป็นไม้หันอากาศ), วรรณยุกต์เสียงเอก
2. ต = ตัวสะกด (แม่กด)
3. ว์ = ตัวการันต์
ตอบ **5 ส่วน**

**ตัวอย่างที่ 2: "เด็ก ๆ ช่วยกันล้างถ้วยชามในห้องครัว" มีคำชนิดใด**
- เด็ก ๆ = คำซ้ำ
- ถ้วยชาม = คำซ้อน (ความหมายกว้างกว่าเดิม)
- ห้องครัว = คำประสม (ห้อง + ครัว เกิดความหมายใหม่)

**ตัวอย่างที่ 3: "คนคนนี้" เขียนเป็น "คน ๆ นี้" ได้ไหม**
1. คนตัวแรกเป็นคำนาม คนตัวที่สองเป็นลักษณนาม
2. ทำหน้าที่ต่างกัน จึงไม่ใช่คำซ้ำ
3. ตอบ **ไม่ได้** ต้องเขียนเต็ม "คนคนนี้"

**ตัวอย่างที่ 4: "ข้อสอบวันนี้หมูมาก" คำว่าหมูมีความหมายแบบใด**
หมูในที่นี้ไม่ใช่สัตว์ แต่หมายถึง "ง่าย" จึงเป็น **ความหมายนัยประหวัด/เชิงอุปมา**

## จุดที่มักสับสน

- **นับพยางค์ตามเสียงอ่าน**: ประวัติศาสตร์ มี 4 พยางค์ ไม่ใช่ 3
- **4 ส่วนพิเศษ vs 5 ส่วน**: เล่ห์ ไม่มีตัวสะกด (4 พิเศษ) ส่วน จันทร์ มีทั้งสะกดและการันต์ (5 ส่วน)
- **อำ ใอ ไอ เอา** เป็นสระเสียงสั้นแต่นับเป็น **คำเป็น**
- **พ้องรูป vs พ้องเสียง**: พ้องรูป "เขียนเหมือน อ่านต่าง" พ้องเสียง "อ่านเหมือน เขียนต่าง"
- **คำมูลหลายพยางค์** (นาฬิกา) กับ **คำประสม** (นาฬิกาปลุก): คำประสมแยกแล้วแต่ละส่วนยังมีความหมาย
- **คำซ้อน vs คำประสม**: คำซ้อนเอาคำความหมายใกล้กันมาซ้อน (เสื้อผ้า) คำประสมเกิดความหมายใหม่ (แมวน้ำ)
- **คร่ำคร่า (ของ) vs คร่ำครึ (คน/ความคิด)**

## ⭐ Key Takeaways

- พยางค์ = เสียงที่เปล่งครั้งเดียว มี 3 / 4 / 4 พิเศษ / 5 ส่วน
- คำตาย = สระสั้นไม่มีตัวสะกด หรือสะกดด้วย ก บ ด
- คำพ้อง 4 แบบ: พ้องเสียง พ้องรูป พ้องทั้งรูปทั้งเสียง พ้องความ
- คำประสม = คำมูล 2 คำขึ้นไป เกิดความหมายใหม่ เช่น แมวน้ำ หัวอ่อน
- คำซ้อนเพื่อความหมาย 5 แบบ และซ้อนเพื่อเสียง (งอแง ท้อแท้)
- ห้ามใช้ ๆ ในร้อยกรอง, นานา จะจะ, และคำต่างหน้าที่ (คนคนนี้)
