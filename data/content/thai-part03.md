## เป้าหมายของบทนี้

- บอกลักษณะคำสมาส แปลความหมายและอ่านออกเสียงคำสมาสได้ถูก
- แยกสมาสแบบไม่มีสนธิ กับสนธิ 3 แบบ (สระ พยัญชนะ นิคหิต)
- บอกลักษณะคำไทยแท้ และสังเกตคำยืมภาษาเขมร บาลี สันสกฤต อังกฤษ จีน ญี่ปุ่น ชวา
- เขียนคำทับศัพท์ที่พบบ่อยให้ถูกตามหลักราชบัณฑิตยสถาน

## 1. คำสมาส

### ลักษณะสำคัญ

1. **มาจากภาษาบาลีและสันสกฤตเท่านั้น** ถ้ามีคำไทยหรือภาษาอื่นปน ไม่ใช่สมาส
   - มัจจุราช = บาลี + บาลี
   - มิตรภาพ = สันสกฤต + บาลี
   - มนุษยธรรม = สันสกฤต + สันสกฤต
   - ราชวัง (วัง เป็นคำไทย) → **ไม่ใช่สมาส** เป็นคำประสม, ผลไม้ (ไม้ เป็นคำไทย) ก็ไม่ใช่สมาส
2. **แปลความหมายจากหลังมาหน้า**
   - ธนบัตร = บัตร (กระดาษ) ที่ใช้แทน ธน (เงิน) → กระดาษที่ใช้แทนเงิน
   - มัจจุราช = ราชา แห่ง มัจจุ (ความตาย) → เจ้าแห่งความตาย
3. **อ่านเชื่อมเสียงระหว่างคำ** (มักมีเสียง อะ อิ อุ เชื่อม) หรืออ่านเรียงพยางค์
   - เอกราช อ่านว่า เอก-กะ-ราด
   - อุบัติเหตุ อ่านว่า อุ-บัด-ติ-เหด
   - ประวัติศาสตร์ อ่านว่า ประ-หวัด-ติ-สาด
   - ภูมิศาสตร์ อ่านว่า พู-มิ-สาด
4. คำหน้าไม่ใส่ไม้หันอากาศหรือสระอะที่พยางค์ท้าย เช่น ราชการ (ไม่ใช่ "ราชะการ")

> ข้อควรระวัง (เอกสารเว้นบรรทัดไว้ให้จดเพิ่มระหว่างดูคลิป): คำที่ขึ้นต้นด้วย "พระ" เช่น พระกรรณ ไม่นับเป็นสมาส และคำสมาสบางคำอ่านไม่เชื่อมเสียง เช่น ชลบุรี อ่านว่า ชน-บุ-รี

## 2. คำสมาสแบบมีสนธิ

**สมาส = "ชน"** คำต่อคำเฉย ๆ ไม่เปลี่ยนเสียง
**สนธิ = "เชื่อม"** หลอมเสียงท้ายคำหน้ากับเสียงต้นคำหลังให้กลมกลืน

### 1) สระสนธิ

| คำหน้า | คำหลัง | ผลการสนธิ |
|---|---|---|
| วิทยา | อาลัย | วิทยาลัย |
| ชิน | โอรส | ชิโนรส |
| ราช | อุปถัมภ์ | ราชูปถัมภ์ |
| ธนู | อาคม | ธนาคม |
| นร | อินทร์ | นรินทร์ |

หลักคิด: ตัดสระท้ายคำหน้า แล้วใช้สระของคำหลัง (บางคู่เปลี่ยนเสียง เช่น อะ + อุ → อู ใน ราชูปถัมภ์)

### 2) พยัญชนะสนธิ

พบกับคำว่า **นิร / ทุร** (เอกสารยก นิร เนร นร ทร ทุร) เช่น
- นิร + ภัย = นิรภัย, นิร + โทษ = นิรโทษ, นิร + อันดร = นิรันดร
- ทุร + ชน = ทุรชน, ทุร + กันดาร = ทุรกันดาร

### 3) นิคหิตสนธิ

คำหน้าเป็น **สํ** (สัง) มาเชื่อมกับคำหลัง
- ถ้าคำหลังขึ้นต้นด้วย **พยัญชนะ** → นิคหิตเปลี่ยนเป็นพยัญชนะตัวท้ายวรรคของตัวนั้น ได้รูป **สัง สัญ สัณ สัน สัม (หรือ สง)**
  - สํ + เกต = สังเกต, สํ + ญา = สัญญา, สํ + ฐาน = สัณฐาน, สํ + นิษฐาน = สันนิษฐาน, สํ + พันธ์ = สัมพันธ์, สํ + ผัส = สัมผัส, สํ + เคราะห์ = สงเคราะห์
- ถ้าคำหลังขึ้นต้นด้วย **สระ** → นิคหิตเปลี่ยนเป็น ม ได้รูป **สมา สมุ สโม**
  - สํ + อาคม = สมาคม, สํ + อุทัย = สมุทัย, สํ + โอสร = สโมสร

> สรุป: สมาสมี 2 แบบ คือ สมาสธรรมดา (ชน) และสมาสแบบมีสนธิ (เชื่อม)

## 3. คำยืมภาษาต่างประเทศ

### ลักษณะคำไทยแท้

1. **ไม่มีตัวการันต์** (มีการันต์มักเป็นคำยืม เช่น จันทร์ สัตว์)
2. **ตัวสะกดตรงตามมาตรา** เช่น กิน นอน ลม ปาก (ถ้าสะกดด้วย ญ ณ ร ล ฬ ศ ษ ฯลฯ มักเป็นคำยืม)
3. ส่วนมากเป็นคำโดด พยางค์เดียว และไม่เปลี่ยนรูปคำเมื่อเปลี่ยนหน้าที่ (เอกสารเขียนสั้น ๆ ว่า "ไม่เพิ่ม/ไม่เติม" เติมรายละเอียดจากคลิป)

ตัวอย่างคำไทยแท้: พ่อ แม่ กิน นอน ดิน ฟ้า ปลา

### ภาษาเขมร

1. สะกดด้วย **จ ญ ร ล** เช่น เสด็จ เจริญ ขจร กังวล
2. นิยมใช้คำควบกล้ำ เช่น กราบ ตรวจ ขลาด
3. มักเป็นคำ 2 พยางค์ที่อ่านแบบอักษรนำ เช่น ขนม ถนน จมูก ฉลาด
4. **แผลงคำได้** เช่น เกิด → กำเนิด, เดิน → ดำเนิน, จ่าย → จำหน่าย, ตรวจ → ตำรวจ
5. ขึ้นต้นด้วย **บัง บำ บัน บรร** เช่น บังคม บำเพ็ญ บันได บรรทม บรรจุ
   - ดอกจัน (*) ที่ "บรร" เตือนว่า บางคำที่ขึ้นต้น บรร มาจากสันสกฤต เช่น บรรพต (ภูเขา) บรรณ
6. มักขึ้นต้นด้วย **สระอำ** เช่น อำนาจ อำนวย สำราญ ดำริ
7. มักเป็นคำราชาศัพท์ เช่น เสวย ถวาย บรรทม ตรัส

### ภาษาบาลี

1. นิยมใช้ **ฬ** เช่น กีฬา จุฬา
2. ใช้รูปพยัญชนะซ้อน **ญห ณห มห** เช่น ปัญหา ตัณหา
3. มักขึ้นต้นด้วย **ปฏิ** เช่น ปฏิบัติ ปฏิเสธ ปฏิทิน
4. มี **หลักตัวสะกดตัวตาม** ตามวรรค: ตัวที่ 1 ตามด้วยตัวที่ 1–2, ตัวที่ 3 ตามด้วยตัวที่ 3–4, ตัวที่ 5 ตามด้วยตัวในวรรคเดียวกัน เช่น
   - ทุกข์ (กข) อัคคี (คค) สัจจะ (จจ) วิชชา (ชช) เมตตา (ตต) หัตถ์ (ตถ) พุทธ (ทธ) บุปผา (ปผ)
   - พยัญชนะเศษวรรค (ย ร ล ว ส ห ฬ) ซ้อนกันเองได้ เช่น ลล ในคำ วัลลภ

### ภาษาสันสกฤต

1. นิยมใช้ **ฑ** (คู่กับบาลีที่ใช้ ฬ) เช่น จุฑา (บาลี จุฬา), กรีฑา (บาลี กีฬา)
2. ใช้ **ศ ษ ฤ** เช่น ศึกษา ศิลปะ ภาษา ฤดู ทฤษฎี
3. ใช้ **รร** เช่น ธรรม กรรม พรรค สวรรค์
4. ใช้ ห (ตามเอกสาร เติมตัวอย่างจากคลิป)
5. มักซ้อนรูปพยัญชนะ **ส+ด ส+ต ส+ถ** เช่น พัสดุ สตรี สถาน
6. นิยมใช้ **ร** ควบกล้ำ / หลังตัวสะกด / เป็นตัวการันต์ เช่น จักร บุตร ศาสตร์ เกษตร

**คู่คำบาลี–สันสกฤต ที่ควรจำ**

| บาลี | สันสกฤต |
|---|---|
| กีฬา | กรีฑา |
| ปัญญา | ปรัชญา |
| สัจจะ | สัตย์ |
| อัคคี | อัคนี |
| วิชา | วิทยา |
| ภิกขุ | ภิกษุ |
| ธัมมะ | ธรรม |

### ภาษาอังกฤษ: คำทับศัพท์

คำทับศัพท์คือการเขียนคำภาษาต่างประเทศด้วยตัวอักษรไทย ควรเขียนตามหลักราชบัณฑิตยสถาน

| เขียนถูก | ที่มักเขียนผิด |
|---|---|
| เฟซบุ๊ก | เฟสบุ๊ค |
| โควตา | โควต้า |
| ฟิล์ม | ฟีล์ม |
| อัปเดต | อัพเดท |

(ในเอกสารทั้ง 2 คอลัมน์มีทั้งแบบถูกและผิดปนกัน ใช้ตารางนี้เป็นหลัก) คำอื่นที่พบบ่อย: คอมพิวเตอร์ อินเทอร์เน็ต ฟุตบอล คลินิก

### ภาษาจีน ญี่ปุ่น ชวา

- **จีน**: เก๊กฮวย บะหมี่ ก๋วยเตี๋ยว เก้าอี้ เต้าหู้ (ส่วนใหญ่เป็นชื่ออาหารและของใช้)
- **ญี่ปุ่น**: เทมปุระ ซามูไร กิโมโน โมจิ
- **ชวา** (พบในวรรณคดีเรื่องอิเหนา): บุหงา = ดอกไม้, ยิหวา = ดวงใจ, บุหลัน = ดวงจันทร์, ปะหนัน = ดอกลำเจียก, บุหรง = นก

## ตัวอย่างวิธีคิด

**ตัวอย่างที่ 1: "ราชวัง" เป็นคำสมาสหรือไม่**
1. ราช มาจากบาลี/สันสกฤต
2. วัง เป็นคำไทย
3. สมาสต้องเป็นบาลี/สันสกฤตทั้งคู่ → **ไม่ใช่สมาส** (เป็นคำประสม)

**ตัวอย่างที่ 2: สํ + อาคม ได้คำใด**
1. คำหลังขึ้นต้นด้วยสระ อา
2. นิคหิตเปลี่ยนเป็น ม แล้วประสมกับ อา → สมา
3. ได้ **สมาคม** (ระวังสับกับ สังคม ซึ่งมาจาก สํ + คม)

**ตัวอย่างที่ 3: "เสด็จ" มาจากภาษาใด**
1. สะกดด้วย จ ซึ่งไม่ตรงมาตราแบบไทย
2. เป็นคำราชาศัพท์
3. ลักษณะตรงกับภาษา **เขมร**

**ตัวอย่างที่ 4: "วิทยา" กับ "วิชา" ต่างกันอย่างไร**
ความหมายใกล้กัน แต่ วิทยา ใช้ ท+ย แบบสันสกฤต ส่วน วิชา เป็นรูปบาลี

## จุดที่มักสับสน

- **คำประสมที่มีคำบาลี–สันสกฤตปนคำไทย** (ราชวัง ผลไม้ ทหารเรือ) ไม่ใช่สมาส
- **สังคม vs สมาคม**: สังคม = สํ+คม (พยัญชนะ), สมาคม = สํ+อาคม (สระ)
- **บรร ไม่ได้เป็นเขมรเสมอ**: บรรพต เป็นสันสกฤต
- **ฬ (บาลี) vs ฑ (สันสกฤต)**: กีฬา/กรีฑา, จุฬา/จุฑา
- **อ่านสมาสต้องเชื่อมเสียง**: อุบัติเหตุ ไม่ใช่ อุ-บัด-เหด
- **ทับศัพท์**: อัปเดต โควตา เฟซบุ๊ก

## ⭐ Key Takeaways

- สมาส = บาลี/สันสกฤตเท่านั้น แปลหลังไปหน้า อ่านเชื่อมเสียง
- สนธิ 3 แบบ: สระ (วิทยาลัย) พยัญชนะ (นิรภัย) นิคหิต (สัมพันธ์ สมาคม)
- คำไทยแท้: ไม่มีการันต์ สะกดตรงมาตรา ส่วนมากเป็นคำโดด
- เขมร: สะกด จ ญ ร ล, แผลงคำ, บัง บำ บัน บรร, อำ, ราชาศัพท์
- บาลี: ฬ, ปฏิ, ตัวสะกดตัวตาม · สันสกฤต: ศ ษ ฤ รร ส+ด/ต/ถ
- จีน/ญี่ปุ่น/ชวา จำจากตัวอย่าง เช่น บุหงา = ดอกไม้
