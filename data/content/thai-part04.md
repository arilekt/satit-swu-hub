## เป้าหมายของบทนี้

- ใช้คำนำหน้า พระบรม / พระราช / พระ / ทรง ได้ถูกหลัก
- เลือกคำราชาศัพท์ที่มักใช้ผิดได้ถูก เช่น ทูลเกล้าฯ / น้อมเกล้าฯ, พระราชอาคันตุกะ, คำอวยพรวันเกิด
- แยกวัจนภาษา/อวัจนภาษา ภาษาพูด/ภาษาเขียน
- บอกระดับภาษา 5 ระดับ และแยกข้อเท็จจริงกับข้อคิดเห็นได้

## 1. คำราชาศัพท์: คำนำหน้า

| คำ | การใช้ตามเอกสาร | ตัวอย่าง |
|---|---|---|
| พระบรม | นำหน้าคำนาม ใช้กับพระมหากษัตริย์ | พระบรมราโชวาท พระบรมราชโองการ |
| พระราช | นำหน้าคำนาม ใช้กับพระมหากษัตริย์ พระราชินี และสมเด็จพระกนิษฐาธิราชเจ้าฯ | พระราชดำรัส พระราชหัตถเลขา |
| พระ | นำหน้าคำนามสามัญ เพื่อให้ต่างจากสามัญชน | พระเก้าอี้ พระหัตถ์ พระเนตร |
| ทรง | ดูหัวข้อถัดไป | |

### การใช้ "ทรง"

1. **ทรง + กริยาสามัญ** → เป็นกริยาราชาศัพท์ เช่น ทรงวิ่ง ทรงยินดี ทรงขับรถ
2. **ทรง + นามสามัญ** → เป็นกริยาราชาศัพท์ เช่น ทรงม้า (ขี่ม้า) ทรงดนตรี (เล่นดนตรี) ทรงกีฬา
3. **ทรง + นามราชาศัพท์** → เช่น ทรงพระอักษร (อ่าน เขียน เรียนหนังสือ) ทรงพระสำราญ
4. **ทรงมี / ทรงเป็น** ใช้หน้าคำนามสามัญ เช่น ทรงเป็นนักดนตรี ทรงมีความรู้
5. **ห้าม** ใช้ ทรง หน้ากริยาที่เป็นราชาศัพท์อยู่แล้ว: ~~ทรงเสด็จ~~ ~~ทรงประทับ~~ ~~ทรงเสวย~~ ~~ทรงตรัส~~

## 2. คำราชาศัพท์ที่ควรใช้ให้ถูกต้อง

### พระบรมราชูปถัมภ์ vs พระบรมราชานุเคราะห์

| คำ | ใช้เมื่อ | ระดับอื่น |
|---|---|---|
| พระบรมราชูปถัมภ์ | ช่วยเหลือ/ดูแล **สถานที่ องค์กร** (เช่น โรงเรียน มูลนิธิ) | พระบรมราชินูปถัมภ์ / พระราชูปถัมภ์ / พระอุปถัมภ์ |
| พระบรมราชานุเคราะห์ | ช่วยเหลือ/อนุเคราะห์ **บุคคล** | พระราชานุเคราะห์ / พระอนุเคราะห์ |

> จำ: "อุปถัมภ์ = สถานที่, อนุเคราะห์ = คน"

### อาคันตุกะ vs พระราชอาคันตุกะ

เอกสารเน้นว่า "แขก" ให้ดู **เจ้าของบ้านเป็นหลัก**
- ถ้าเป็นแขกของ **พระมหากษัตริย์** ใช้ **พระราชอาคันตุกะ** (เช่น ประธานาธิบดี หรือกษัตริย์ต่างประเทศที่มาเยือนในฐานะแขกของในหลวง)
- ถ้าเป็นแขกของบุคคลทั่วไป รัฐบาล หรือนายกรัฐมนตรี ใช้ **อาคันตุกะ**

(ตารางในเอกสารเขียนแยกตามตัวแขก คือ อาคันตุกะ = คนธรรมดา/นายกฯ/ประธานาธิบดี และ พระราชอาคันตุกะ = กษัตริย์ แต่หลักที่ถูกคือดูว่าใครเป็นเจ้าภาพตามที่เอกสารเน้นไว้ด้านบน)

### คำอวยพรวันเกิด

| คำ | ใช้กับ |
|---|---|
| ทรงเจริญพระชนมพรรษา | พระมหากษัตริย์ และสมเด็จพระราชินี |
| ทรงเจริญพระชนมายุ | สมเด็จพระบรมราชชนก / พระบรมราชชนนี, สมเด็จพระกนิษฐาธิราชเจ้าฯ (ตามเอกสาร) |
| ทรงเจริญพระชันษา | พระราชวงศ์ชั้นสมเด็จเจ้าฟ้า / พระองค์เจ้า |
| เจริญชันษา | หม่อมเจ้า |

### การให้ของแด่พระมหากษัตริย์

| คำ | ใช้กับ | ตัวอย่าง |
|---|---|---|
| ทูลเกล้าฯ ถวาย (ทูลเกล้าทูลกระหม่อมถวาย) | ของที่ **ยกได้** | พวงมาลัย หนังสือ เงิน |
| น้อมเกล้าฯ ถวาย (น้อมเกล้าน้อมกระหม่อมถวาย) | ของที่ **ยกไม่ได้** | รถยนต์ ที่ดิน อาคาร |
| ถวาย | สิ่งที่เป็น **นามธรรม** | ถวายชีวิต ถวายความคิดเห็น ถวายพระพร |

### คำว่า "เสด็จ"

| คำ | ความหมาย |
|---|---|
| เสด็จ | ไป (เสด็จออก เสด็จไป เสด็จประพาส) |
| เสด็จพระราชดำเนิน | เดินทางโดยยานพาหนะ (ของพระมหากษัตริย์/พระราชินี) |
| เสด็จพระราชดำเนินแปรพระราชฐาน | ไปประทับแรมนอกพระราชวัง |
| เสด็จนิวัติพระนคร | เดินทางกลับเข้าสู่กรุงเทพมหานคร |

ส่วนการ "เดินด้วยพระบาท" ใช้ว่า ทรงพระดำเนิน

## 3. คำราชาศัพท์ที่มักใช้ผิด

### พระที่นั่ง / พระที่ / พระราชอาสน์

| คำ | หมายถึง |
|---|---|
| พระที่นั่ง | ปราสาท อาคารที่ประทับ (และใช้กับยานพาหนะ เช่น รถยนต์พระที่นั่ง) |
| พระที่ | พระแท่นบรรทม (เตียงนอน) |
| พระราชอาสน์ | ที่นั่ง |

เอกสารเตือนว่า "แสดงหน้าพระที่นั่ง" มักใช้ไม่ตรงความหมาย (พระที่นั่งคืออาคาร) การแสดงถวายทอดพระเนตรเอกสารแนะนำให้ใช้ "แสดงหน้าที่นั่ง" หรือ "แสดงเฉพาะพระพักตร์"

### ประทับ / ยืน

- **ประทับ** = นั่ง หรืออยู่ เช่น ประทับพระเก้าอี้ ประทับพระราชอาสน์ (ไม่ต้องเติม "ทรง" เป็น ~~ทรงประทับ~~)
- **พลับพลาที่ประทับ** = พลับพลาที่พระบาทสมเด็จพระเจ้าอยู่หัวประทับ ✔
- **ยืน** ใช้ว่า **ทรงยืน** ✔ (เอกสารให้ "ประทับยืน" เป็นแบบที่ไม่ควรใช้ เพราะประทับแปลว่านั่ง/อยู่)

## 4. การใช้ภาษาและระดับภาษา

### วัจนภาษา / อวัจนภาษา

- **วัจนภาษา** = ภาษาที่เป็นถ้อยคำ ทั้งคำพูดและตัวอักษร (ภาษาพูด ภาษาเขียน)
- **อวัจนภาษา** = ภาษาที่ **ไม่ใช่** ถ้อยคำ เช่น สัญลักษณ์ สีหน้า ท่าทาง น้ำเสียงแสดงอารมณ์ การแต่งกาย การพยักหน้า

### ภาษาพูด / ภาษาเขียน

| ภาษาพูด | ภาษาเขียน |
|---|---|
| ใช้พูดจากันทั่วไป | ใช้ถ้อยคำสุภาพ |
| เป็นกันเอง บ้างก็สุภาพ | เหมาะสมกับบุคคลและกาลเทศะ |
| ใช้กับเพื่อน คนในครอบครัว | ใช้ในพิธีการ ทางการ |
| สื่อสารกันได้โดยตรง | บันทึกการฟัง การแสดงความคิดเห็น |
| เช่น บทสนทนา สัมภาษณ์ | เช่น บทความ สารคดี จดหมาย เรียงความ |

### ระดับภาษา 5 ระดับ

| ระดับ | ลักษณะ | โอกาสที่ใช้ |
|---|---|---|
| 1) พิธีการ | ไพเราะ สละสลวย จริงจัง ใช้นาน ๆ ครั้ง กับบุคคลสำคัญ | กล่าวถวายพระพร กล่าวเปิดงานพิธี |
| 2) ทางการ | จริงจัง เป็นภาษาเขียน | หนังสือราชการ ตำรา การบรรยายของนักวิชาการ |
| 3) กึ่งทางการ | ไม่จริงจังมาก ความสัมพันธ์ใกล้ขึ้น ใช้ได้ทั้งพูดและเขียน | การประชุมกลุ่ม บทความในนิตยสาร |
| 4) ไม่เป็นทางการ | ทั่วไป ภาษาพูด ไม่เป็นเรื่องส่วนตัว | คุยกับคนรู้จักทั่วไป |
| 5) กันเอง (ภาษาปาก) | สนิท เฉพาะกลุ่ม ส่วนตัว อาจมีคำไม่สุภาพ | คุยกับเพื่อนสนิท |

### ข้อคิดเห็น / ข้อเท็จจริง

| ข้อคิดเห็น | ข้อเท็จจริง |
|---|---|
| แสดงความรู้สึก (สวยมาก น่ากลัว) | มีความเป็นไปได้ |
| คาดคะเน (น่าจะ คง อาจ) | มีความสมจริง |
| เปรียบเทียบหรืออุปมา | มีหลักฐานเชื่อถือได้ ตรวจสอบได้ |
| มักเป็นข้อเสนอแนะ (ควร) | มีความสมเหตุสมผล |
| เป็นความคิดเห็นของผู้พูด/ผู้เขียน | |

## ตัวอย่างวิธีคิด

**ตัวอย่างที่ 1: ประชาชนมอบที่ดิน 10 ไร่แด่พระมหากษัตริย์ ใช้คำใด**
1. ที่ดินเป็นของที่ยกไม่ได้
2. ของยกไม่ได้ใช้ "น้อมเกล้าฯ ถวาย"
3. ตอบ **น้อมเกล้าฯ ถวายที่ดิน**

**ตัวอย่างที่ 2: "พระเจ้าอยู่หัวทรงเสด็จไปเปิดสะพาน" ผิดตรงไหน**
1. เสด็จ เป็นกริยาราชาศัพท์อยู่แล้ว
2. ห้ามเติม ทรง ซ้อน
3. แก้เป็น **เสด็จพระราชดำเนินไปทรงเปิดสะพาน** (ทรง + เปิด ซึ่งเป็นกริยาสามัญ จึงถูก)

**ตัวอย่างที่ 3: "พรุ่งนี้ฝนน่าจะตกหนัก" เป็นข้อเท็จจริงหรือข้อคิดเห็น**
มีคำว่า "น่าจะ" เป็นการคาดคะเน ยังตรวจสอบไม่ได้ → **ข้อคิดเห็น**

**ตัวอย่างที่ 4: "เมื่อวานแกไปไหนมาวะ" เป็นภาษาระดับใด**
ใช้สรรพนาม "แก" และคำลงท้าย "วะ" แสดงความสนิท → **ภาษากันเอง (ภาษาปาก)**

## จุดที่มักสับสน

- **ทรง + คำราชาศัพท์** ผิด (ทรงเสด็จ ทรงประทับ) แต่ **ทรง + คำสามัญ** ถูก (ทรงวิ่ง ทรงม้า)
- **ทูลเกล้าฯ (ยกได้) vs น้อมเกล้าฯ (ยกไม่ได้)** — นามธรรมใช้ "ถวาย"
- **ราชูปถัมภ์ (สถานที่) vs ราชานุเคราะห์ (บุคคล)**
- **พระที่ = เตียง** ไม่ใช่ที่นั่ง ส่วน **พระราชอาสน์ = ที่นั่ง**
- **อวัจนภาษา** รวมสีหน้า ท่าทาง การแต่งกาย ไม่ใช่แค่ "ท่ามือ"
- **ข้อคิดเห็นที่ดูเหมือนข้อเท็จจริง**: "ทุเรียนอร่อยที่สุด" เป็นความรู้สึก ไม่ใช่ข้อเท็จจริง

## ⭐ Key Takeaways

- พระบรม (กษัตริย์) > พระราช > พระ; ทรง ใช้หน้าคำสามัญเท่านั้น
- ทูลเกล้าฯ = ของยกได้, น้อมเกล้าฯ = ของยกไม่ได้, ถวาย = นามธรรม
- ทรงเจริญพระชนมพรรษา = กษัตริย์/ราชินี; เจริญชันษา = หม่อมเจ้า
- พระราชอาคันตุกะ = แขกของพระมหากษัตริย์ (ดูเจ้าภาพ)
- วัจนภาษา = ถ้อยคำ, อวัจนภาษา = ไม่ใช่ถ้อยคำ
- ระดับภาษา 5 ระดับ: พิธีการ ทางการ กึ่งทางการ ไม่เป็นทางการ กันเอง
- ข้อเท็จจริงตรวจสอบได้ ข้อคิดเห็นมีความรู้สึก คาดคะเน หรือข้อเสนอแนะ

## แผนทบทวน

- **วันนี้**: ดูคลิปแล้วเติมช่องว่างในเอกสารหน้า 18–21 (PDF) และทำบัตรคำราชาศัพท์ 15 คำ
- **พรุ่งนี้**: แต่งประโยคราชาศัพท์ 5 ประโยค (ทูลเกล้าฯ น้อมเกล้าฯ เสด็จพระราชดำเนิน ทรง+สามัญ ประทับ) ให้คุณพ่อตรวจ
- **อีก 3 วัน**: อ่านข่าวในพระราชสำนัก 1 ข่าว ขีดเส้นใต้คำราชาศัพท์ และฝึกแยกข้อเท็จจริง/ข้อคิดเห็นจากบทความ 1 เรื่อง
- **อีก 1 สัปดาห์**: ทำแบบทดสอบท้ายบท แล้วทบทวนข้อที่ผิด
