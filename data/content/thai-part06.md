## เป้าหมายของบทนี้

- แยกสำนวน สุภาษิต คำพังเพย และใช้ให้ถูกความหมาย
- เรียงคำตามลำดับพจนานุกรมได้
- บอกชื่อและหน้าที่ของเครื่องหมายวรรคตอนที่ออกสอบบ่อย
- อ่านออกเสียงคำยาก คำที่มี ฤ ฑ และตัวเลขได้ถูกต้อง

## 1. สำนวน สุภาษิต และคำพังเพย

| ประเภท | หน้าที่ | ตัวอย่าง |
|---|---|---|
| **สำนวน** | ถ้อยคำที่มีความหมายไม่ตรงตัว ใช้ **เปรียบ** | ซนเหมือนลิง, น้ำลดตอผุด, กระต่ายตื่นตูม |
| **สุภาษิต** | ถ้อยคำที่ **สั่งสอน** ให้ทำดี | ทำดีได้ดี ทำชั่วได้ชั่ว, น้ำขึ้นให้รีบตัก, ช้า ๆ ได้พร้าเล่มงาม |
| **คำพังเพย** | กล่าวเปรียบเชิง **เสียดสี/ประชดประชัน** หรือติชม | งมเข็มในมหาสมุทร, ทำนาบนหลังคน, รำไม่ดีโทษปี่โทษกลอง |

(การแก้ไขจากเอกสาร: หน้า 25 ใช้หัวข้อ "สุภาษิต" ซ้ำสองกล่อง แต่กล่องที่สอง "เอาไว้เสียดสี ประชดประชัน" คือ **คำพังเพย** ตามชื่อหัวข้อ "สำนวน สุภาษิต และคำพังเพย")

เอกสารสรุปเน้นว่า สำคัญที่สุดคือ **รู้ความหมาย และใช้ให้ถูกสถานการณ์**

### สำนวนที่ควรรู้ความหมาย

| สำนวน | ความหมาย |
|---|---|
| งมเข็มในมหาสมุทร | หาสิ่งที่หายากมาก แทบเป็นไปไม่ได้ |
| ทำนาบนหลังคน | หาประโยชน์จากความเหนื่อยยากของผู้อื่น |
| น้ำขึ้นให้รีบตัก | มีโอกาสควรรีบทำ |
| น้ำลดตอผุด | เมื่อหมดอำนาจ ความผิดที่ซ่อนไว้ก็ปรากฏ |
| กระต่ายตื่นตูม | ตกใจง่ายโดยไม่ไตร่ตรอง |
| ปิดทองหลังพระ | ทำความดีโดยไม่หวังให้ใครเห็น |
| ชี้โพรงให้กระรอก | แนะช่องทางให้คนทำสิ่งไม่ดี |
| รำไม่ดีโทษปี่โทษกลอง | ทำผิดเองแต่โทษผู้อื่นหรือสิ่งอื่น |
| น้ำพึ่งเรือ เสือพึ่งป่า | ต่างฝ่ายต่างพึ่งพาอาศัยกัน |
| ช้า ๆ ได้พร้าเล่มงาม | ทำอย่างรอบคอบจะได้ผลดี |

## 2. การเรียงลำดับคำในพจนานุกรม

1. เรียงตาม **รูปพยัญชนะก่อนรูปสระ** ตั้งแต่ ก ถึง ฮ
2. เรียงตามรูปพยัญชนะ โดย **ฤ ฤๅ อยู่หลัง ร** และ **ฦ ฦๅ อยู่หลัง ล**
3. คำที่ **พยัญชนะต้นตามด้วยพยัญชนะ** (ไม่มีรูปสระ) มาก่อนคำที่ตามด้วยสระ เช่น กรม มาก่อน กะทิ
4. คำที่ตามด้วยสระ เรียงตามรูปสระ ตามตัวอย่างในเอกสาร:
   - จะ → จับ → (ผัวะ) → ตา → ดำ → ดิน → ดี → ถึง → มือ → คุณ → ครู → เต → เตะ → เงา → เงาะ → เงิน → เฮีย → เฮียะ → เรือ → เบือะ → แก → แทะ → โด → โซะ → ใน → ไห
   - สรุปลำดับหลัก: ะ ั า ำ ิ ี ึ ื ุ ู เ แ โ ใ ไ
5. คำที่เหมือนกันหมดยกเว้นวรรณยุกต์ เรียงตามรูปวรรณยุกต์: ไม่มีรูป → ่ → ้ → ๊ → ๋ เช่น ขา → ข่า → ข้า

ตัวอย่างเรียงถูก: **กรม → กะทิ → กา → กิน**

## 3. เครื่องหมายวรรคตอน

| เครื่องหมาย | ชื่อ | การใช้ |
|---|---|---|
| , | จุลภาค | คั่นคำหรือกลุ่มคำ, คั่นตัวเลขตั้งแต่ 4 หลัก (1,000) |
| . | มหัพภาค / จุด / พินทุ | หลังอักษรย่อ (พ.ศ.), หลังตัวเลขหรืออักษรกำกับข้อ, ทศนิยม, แบ่งชั่วโมงกับนาที (10.30 น.) |
| ? | ปรัศนี | ท้ายประโยคคำถาม |
| ! | อัศเจรีย์ | กำกับคำอุทาน หรือข้อความแสดงอารมณ์ |
| ( ) | นขลิขิต / วงเล็บ | อธิบายเพิ่มให้แจ่มแจ้ง, กำกับเพื่อเตือนความจำ |
| ___ | สัญประกาศ / ขีดเส้นใต้ | เน้นข้อความสำคัญให้เด่น |
| ” | บุพสัญญา | แทนข้อความที่ตรงกับบรรทัดบน ไม่ต้องเขียนซ้ำ |
| ๆ | ไม้ยมก | ซ้ำคำ กลุ่มคำ หรือประโยค |
| ฯลฯ | ไปยาลใหญ่ | ละข้อความยาว ๆ ที่ยังมีอีกมาก (อ่านว่า "ละ" หรือ "และอื่น ๆ") |
| ฯ | ไปยาลน้อย | ละคำยาว ๆ ที่รู้กันดี เช่น กรุงเทพฯ โปรดเกล้าฯ ทูลเกล้าฯ (อ่านเต็มคำ) |
| “ ” | อัญประกาศ | ยกข้อความอ้างอิง, กำกับคำพูด, เน้นคำ |
| / | ทับ | แบ่งวัน/เดือน/ปี, ใช้แทน "หรือ", แบ่งเลขที่บ้าน (99/12) |
| - | ยัติภังค์ | ต่อคำเมื่อเขียนไม่จบบรรทัด, ใช้แทน "ถึง" (จันทร์-ศุกร์), แยกพยางค์ |
| ... | จุดไข่ปลา / เส้นปะ | ช่องว่างให้เติมในแบบฝึกหัด, แสดงว่าละคำไว้, แสดงว่าข้อความตัดตอนมา |

**ระวังไปยาลน้อย**: เอกสารเตือนว่า "ธนาคารกรุงเทพ ฯ" ✗ เพราะชื่อธนาคารคือ "ธนาคารกรุงเทพ" ครบอยู่แล้ว ไม่ได้ย่อ ส่วน กรุงเทพฯ ใช้ได้เพราะย่อจากชื่อเต็มที่ยาวมาก

## 4. การอ่านออกเสียง

### หลักทั่วไป

| หลัก | ตัวอย่าง |
|---|---|
| พยางค์ที่ไม่มีสระกำกับ อ่านเติมเสียง อะ (บางคำออกเสียง ออ) | ปรโลก = ปะ-ระ-โลก / ปอ-ระ-โลก |
| สระที่อยู่กับตัวสะกดท้ายคำ ไม่อ่านออกเสียงสระ | เหตุ = เหด, ธาตุ = ทาด |
| ข้อยกเว้นที่เอกสารยกไว้ | โรคาพยาธิ (เอกสารให้อ่าน โร-คา-พะ-ยา-ทิ ควรเปิดพจนานุกรมตรวจซ้ำ) |
| ตัวการันต์ไม่ออกเสียง บางคำไม่มีทัณฑฆาตแต่ไม่อ่านตัวท้าย | มิตร = มิด, บัตร = บัด |
| คำหลายพยางค์ มักออกเสียง อะ ท้ายพยางค์แรก | วิทยา = วิด-ทะ-ยา |
| พยางค์แรกเป็นสระเสียงยาว อ่านเรียงพยางค์ | กาลเทศะ = กา-ละ-เท-สะ |
| ตัวสะกดพยางค์แรกเป็นอักษรสูง + พยางค์หลังเป็นอักษรต่ำเดี่ยว มักอ่านแบบอักษรนำ | วาสนา = วาด-สะ-หนา |

### การอ่านคำสมาส และคำไทยบางคำ

- อ่านเรียงพยางค์: พลศึกษา = พะ-ละ-สึก-สา
- ตัวสะกดของคำหน้าเป็นอักษรควบแท้ อ่านออกเสียงควบด้วย: มาตรฐาน = มาด-ตระ-ถาน
- ตัวสะกดอ่านซ้ำเป็นพยางค์ใหม่: รัชกาล = รัด-ชะ-กาน
- คำไทยหลายพยางค์ส่วนมากอ่านตรงตัว: บากบั่น = บาก-บั่น แต่บางคำออกเสียงตัวสะกดซ้ำ: ตุ๊กตา = ตุ๊ก-กะ-ตา

### คำพ้องรูป และคำที่มี ฤ ฑ

- คำพ้องรูป ดูจาก **บริบทของประโยค** เช่น เพลา (เพ-ลา = เวลา / เพลา = แกนล้อ)
- **ฤ** อ่านได้ 3 แบบ: รึ (ฤดู, พฤษภาคม), ริ (ฤทธิ์, อังกฤษ, ทฤษฎี), เรอ (ฤกษ์ = เริก)
- **ฑ** อ่านได้ 2 แบบ: /ด/ (บัณฑิต = บัน-ดิด, มณฑป = มน-ดบ) และ /ท/ (มณฑล = มน-ทน, มณฑา = มน-ทา, กรีฑา)

### การอ่านตัวเลข

| ประเภท | หลัก | ตัวอย่าง |
|---|---|---|
| เลข 1 และ 2 ในหลักหน่วย/สิบ | 1 ท้ายหลักสิบอ่าน "เอ็ด", 2 ในหลักสิบอ่าน "ยี่" | 21 = ยี่สิบเอ็ด |
| ทศนิยม | หน้าจุดอ่านเต็ม หลังจุดอ่านเรียงตัว | 12.75 = สิบสองจุดเจ็ดห้า |
| เวลา | อ่านจากหน่วยใหญ่ไปย่อย | 09.30 น. = เก้านาฬิกาสามสิบนาที |
| มาตราส่วน/อัตราส่วน | ใช้คำว่า "ต่อ" | 1:50,000 = หนึ่งต่อห้าหมื่น |
| รหัสไปรษณีย์ | อ่านเรียงตัว | 10330 = หนึ่ง-ศูนย์-สาม-สาม-ศูนย์ |
| หมายเลขทางหลวง | อ่านเรียงตัว | ทางหลวง 304 = สาม-ศูนย์-สี่ |
| บ้านเลขที่ | หน้าทับ 2 ตัวอ่านเต็ม (3 ตัวอ่านเต็มหรือเรียงก็ได้) หลังทับอ่านเรียง; กลุ่มที่มี 0 นำหน้าอ่านเรียง | 99/45 = เก้าสิบเก้า ทับ สี่-ห้า |

## ตัวอย่างวิธีคิด

**ตัวอย่างที่ 1: เรียงคำ กิน กะทิ กรม กา**
1. ทุกคำขึ้นต้น ก → ดูตัวถัดไป
2. กรม: ก ตามด้วยพยัญชนะ → มาก่อน
3. ที่เหลือดูรูปสระ ะ → า → ิ
4. ตอบ **กรม กะทิ กา กิน**

**ตัวอย่างที่ 2: "ฤกษ์" อ่านว่าอะไร**
ฤ ในคำนี้ออกเสียง "เรอ" รวมกับ ก สะกด (ษ์ เป็นการันต์) → **เริก**

**ตัวอย่างที่ 3: "รัชกาล" อ่านว่าอะไร**
1. ช เป็นตัวสะกดของพยางค์แรก → รัด
2. ช ถูกอ่านซ้ำเป็นพยางค์ใหม่ประสมสระอะ → ชะ
3. ตอบ **รัด-ชะ-กาน**

**ตัวอย่างที่ 4: เลือกสำนวนให้เหมาะกับ "หาต่างหูที่หล่นในสนามหญ้ากว้าง"**
สถานการณ์คือหาของชิ้นเล็กในที่กว้างมาก → **งมเข็มในมหาสมุทร**

## จุดที่มักสับสน

- **สุภาษิตสอน, คำพังเพยเสียดสี, สำนวนเปรียบ** — ดูเจตนาของข้อความ
- **ฤ อยู่หลัง ร** ไม่ใช่หลัง ฤ ไปท้ายสุด
- **ฯ vs ฯลฯ**: ฯ ละคำยาวที่รู้กัน, ฯลฯ ละรายการที่ยังมีอีก
- **ยัติภังค์ (-) vs สัญประกาศ (_)**: ขีดกลางบรรทัดกับขีดใต้ข้อความ
- **ฑ** อาจเป็น ด หรือ ท ต้องจำเป็นคำ (บัณฑิต ด / มณฑล ท)
- **ทศนิยม** หลังจุดอ่านเรียงตัว: 12.75 ไม่ใช่ "สิบสองจุดเจ็ดสิบห้า"
- **รหัสไปรษณีย์** อ่านเรียงตัวเสมอ

## ⭐ ประเด็นสำคัญที่ได้จากบทเรียนนี้

- สำนวนเปรียบ สุภาษิตสอน คำพังเพยเสียดสี — จำความหมายเป็นหลัก
- พจนานุกรม: พยัญชนะก่อนสระ, ฤ หลัง ร / ฦ หลัง ล, พยัญชนะตามพยัญชนะมาก่อน
- ฯ = ไปยาลน้อย, ฯลฯ = ไปยาลใหญ่, “ ” = อัญประกาศ, ( ) = นขลิขิต
- ฤ อ่าน รึ/ริ/เรอ, ฑ อ่าน ด/ท
- ทศนิยมหลังจุดอ่านเรียง, เวลาอ่านใหญ่ไปเล็ก, รหัสไปรษณีย์อ่านเรียงตัว
