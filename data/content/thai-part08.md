## เป้าหมายของบทนี้

- บอกชนิดของคำ 7 ชนิด: นาม สรรพนาม กริยา วิเศษณ์ บุพบท สันธาน อุทาน
- แยกชนิดย่อยของคำนาม สรรพนาม กริยา วิเศษณ์ได้
- ใช้ลักษณนาม บุพบท และสันธานได้ถูกต้อง
- ระบุชนิดของคำจาก "หน้าที่ในประโยค" ไม่ใช่จากการจำคำอย่างเดียว

> หลักทอง: คำเดียวกันอาจเป็นคนละชนิดได้ ขึ้นกับ **หน้าที่ในประโยค**

## 1. คำนาม

คำที่เป็นชื่อของ คน สัตว์ สิ่งของ สถานที่ สภาพ อาการ

| ชนิด | ความหมาย | ตัวอย่าง |
|---|---|---|
| สามานยนาม (นามทั่วไป) | ชื่อเรียกทั่วไป | พ่อ แม่ โรงพยาบาล โรงเรียน ช้าง |
| วิสามานยนาม (นามเฉพาะ) | ชื่อเฉพาะเจาะจง | กรุงเทพมหานคร ประเทศไทย ลิซ่า สุนทรภู่ |
| ลักษณนาม | บอกลักษณะของนามข้างหน้า | ตัว ใบ ด้าม คัน รูป องค์ |
| อาการนาม | การ / ความ + กริยา หรือ วิเศษณ์ | การพูด การเรียน ความรู้ ความรัก ความสวย ความดี |
| สมุหนาม (เพิ่มเติม) | บอกหมวดหมู่ | ฝูง โขลง คณะ กอง |

**ระวังอาการนาม**: "การ" + **คำนาม** ไม่ใช่อาการนาม เช่น การบ้าน การเมือง การไฟฟ้า การประปา เป็นนามทั่วไป

### ลักษณนามที่ควรจำ

| นาม | ลักษณนาม |
|---|---|
| พระสงฆ์ | รูป |
| พระพุทธรูป | องค์ |
| ช้างบ้าน | เชือก |
| ร่ม ช้อน รถ | คัน |
| ปากกา | ด้าม |
| ขลุ่ย ปี่ | เลา |
| บ้าน | หลัง |
| ภูเขา | ลูก |
| ฟัน | ซี่ |
| จดหมาย | ฉบับ |
| ยักษ์ | ตน |
| แห | ปาก |

เอกสารยกตัวอย่าง "มงกุฎ" ที่ใช้ลักษณนามต่างกันตามชนิด (มงกุฎนางงาม มงกุฎของพระมหากษัตริย์ มงกุฎโขน/ละคร) และแนะให้ตรวจกับบัญชีลักษณนามของราชบัณฑิตยสถาน (QR ในเอกสาร)

## 2. คำสรรพนาม

แนวคิด: **ใช้แทนคำนาม**

| ชนิด | หน้าที่ | ตัวอย่าง |
|---|---|---|
| 1. บุรุษสรรพนาม | แทนผู้พูด (1) ผู้ฟัง (2) ผู้ที่กล่าวถึง (3) | ฉัน ผม / เธอ คุณ / เขา ท่าน มัน |
| 2. ปฤจฉาสรรพนาม | แทนนามที่เป็น **คำถาม** | ใคร อะไร ไหน — "น้องกำลังทำอะไรอยู่" |
| 3. นิยมสรรพนาม | ชี้เฉพาะ | นี่ นั่น โน่น — "นั่นสถานีรถไฟ" |
| 4. อนิยมสรรพนาม | ไม่ชี้เฉพาะ (ใคร อะไร ไหน ที่ **ไม่ใช่คำถาม**) | "เขาพูดอะไร ก็เรื่องของเขา" |
| 5. วิภาคสรรพนาม | แยกฝ่าย | บ้าง ต่าง กัน — "เราต่างคนต่างอยู่", "ชาวบ้านบ้างก็ทำนา บ้างก็เลี้ยงสัตว์" |
| 6. ประพันธสรรพนาม (เพิ่มเติม) | แทนนามข้างหน้าและเชื่อมประโยค | ที่ ซึ่ง อัน — "คนที่ยืนอยู่คือครู" |

**ระวัง นี่ vs นี้**: เอกสารรวม นี่ นี้ นั่น นั้น โน่น โน้น ไว้ในกลุ่มสรรพนามชี้เฉพาะ แต่ตามหลักไวยากรณ์
- **นี่ นั่น โน่น** อยู่ลำพังแทนนาม = **สรรพนาม** (นี่คือบ้านของฉัน)
- **นี้ นั้น โน้น** ตามหลังนามเพื่อขยาย = **วิเศษณ์** (บ้านหลังนี้สวย)

## 3. คำกริยา

| ชนิด | ลักษณะ | ตัวอย่าง |
|---|---|---|
| สกรรมกริยา | ต้องมีกรรมมารับ | แม่ **ซื้อ** ผลไม้, ฉัน **เขียน** จดหมาย |
| อกรรมกริยา | ไม่ต้องมีกรรม ใจความสมบูรณ์ | น้อง **นอน**, ฝน **ตก** |
| วิกตรรถกริยา | ต้องมีส่วนเติมเต็มมาเติม | เป็น เหมือน คือ เท่า คล้าย ดุจ — "ลูกหน้า **เหมือน** แม่" |
| กริยานุเคราะห์ (กริยาช่วย) | ช่วยกริยาหลักบอกกาล/ความตั้งใจ | คง พึง กำลัง ย่อม น่าจะ จะ โปรด ได้ ต้อง — "ฉัน **คงจะ** ไป" |

## 4. คำวิเศษณ์

ขยาย นาม สรรพนาม กริยา หรือวิเศษณ์ด้วยกัน

| ชนิด | หน้าที่ | ตัวอย่าง |
|---|---|---|
| ลักษณวิเศษณ์ | บอกลักษณะ ขนาด รูปร่าง กลิ่น สี | ใหญ่ เล็ก กลม หอม แดง เร็ว |
| กาลวิเศษณ์ | บอกเวลา | เช้า สาย บ่าย เย็น ก่อน หลัง |
| สถานวิเศษณ์ | บอกตำแหน่ง/สถานที่ | ใกล้ ไกล บน ล่าง (เมื่อไม่มีนามตาม) |
| ประมาณวิเศษณ์ | บอกปริมาณ | มาก น้อย หลาย ทั้งหมด |
| ประติชญาวิเศษณ์ | คำขานรับ | ครับ ค่ะ จ๊ะ ขา |
| ปฏิเสธวิเศษณ์ | บอกการปฏิเสธ | ไม่ ไม่ได้ มิได้ |

## 5. คำบุพบท

เชื่อมคำ/กลุ่มคำ เพื่อบอกความสัมพันธ์ **และต้องมีคำนามหรือสรรพนามตามหลังเสมอ**

| บุพบท | การใช้ | ตัวอย่าง |
|---|---|---|
| กับ | อาการร่วมกัน คู่กัน อยู่ด้วยกัน | ไปกับแม่ |
| แก่ | ให้สิ่งของแก่ผู้น้อยหรือคนทั่วไป | ครูให้รางวัลแก่นักเรียน |
| แด่ | ให้สิ่งของแด่ผู้ใหญ่ ผู้ที่เคารพ | มอบดอกไม้แด่คุณครู |
| แต่ | แปลว่า จาก / เฉพาะ / ตั้งแต่ | มาแต่เช้า |
| ต่อ | เกี่ยวข้อง ติดต่อ เฉพาะหน้า | รายงานต่อครู |
| ด้วย | ใช้ประกอบกริยาที่ทำร่วมกัน (และบอกเครื่องมือ) | เขียนด้วยปากกา |
| โดย | แปลว่า ตาม / บอกวิธี | เดินทางโดยรถไฟ |
| ของ | แสดงความเป็นเจ้าของ | หนังสือของฉัน |
| แห่ง | ความเป็นส่วนประกอบหรือเครื่องประดับ (ภาษาทางการ) | ธนาคารแห่งประเทศไทย |

**ทดสอบบุพบท vs วิเศษณ์**: "บ้านอยู่ **ใกล้** โรงเรียน" (มีนามตาม = บุพบท) แต่ "บ้านอยู่ **ใกล้ ๆ**" (ไม่มีนามตาม = วิเศษณ์)

## 6. คำสันธาน

เชื่อมประโยค (ทำให้เป็นประโยครวม) หรือเชื่อมคำ

| ความสัมพันธ์ | คำสันธาน | ตัวอย่าง |
|---|---|---|
| คล้อยตามกัน | กับ และ ทั้ง...และ ทั้ง...ก็ ครั้น...ก็ ครั้น...จึง พอ...ก็ | พ่อและแม่รักฉันมาก |
| ขัดแย้งกัน | แต่ แต่ทว่า ถึง...ก็ กว่า...ก็ | น้องอ่านหนังสือแต่พี่ฟังเพลง |
| เลือกอย่างใดอย่างหนึ่ง | หรือ หรือไม่ก็ มิฉะนั้น ไม่เช่นนั้น ไม่...ก็ | เธอจะฟังเพลงหรืออ่านหนังสือ |
| เป็นเหตุเป็นผล | จึง เพราะ เพราะว่า เพราะ...จึง ฉะนั้น...จึง | นักเรียนไม่ตั้งใจเรียนจึงสอบไม่ผ่าน |

## 7. คำอุทาน

| ชนิด | ลักษณะ | ตัวอย่าง |
|---|---|---|
| อุทานบอกอาการ | แสดงอารมณ์ ต้องมีเครื่องหมาย ! ใช้ให้ถูกอารมณ์ | โอ๊ย! อุ๊ย! ว้าว! เฮ้อ! |
| อุทานเสริมบท | เติมคำให้คล้องจอง ไม่มีความหมาย | อาหงอาหาร ไปทงไปเที่ยว หนังสือหนังหา |

## ตัวอย่างวิธีคิด

**ตัวอย่างที่ 1: "น้องสาวของฉันร้องเพลงไพเราะมาก" ระบุชนิดคำ**
- น้องสาว = นาม, ของ = บุพบท, ฉัน = สรรพนาม
- ร้อง = กริยา, เพลง = นาม
- ไพเราะ = วิเศษณ์ (ขยายกริยา), มาก = วิเศษณ์ (ประมาณ ขยายไพเราะ)

**ตัวอย่างที่ 2: "อะไร" ใน "เขาพูดอะไรฉันก็ไม่เชื่อ" เป็นสรรพนามชนิดใด**
1. ประโยคนี้ไม่ได้ถามเพื่อต้องการคำตอบ
2. "อะไร" หมายถึงสิ่งใดก็ได้ ไม่ชี้เฉพาะ
3. ตอบ **อนิยมสรรพนาม**

**ตัวอย่างที่ 3: "การบ้าน" เป็นอาการนามไหม**
1. การ + บ้าน (บ้าน เป็นคำนาม)
2. อาการนามต้องเป็น การ/ความ + กริยา/วิเศษณ์
3. ตอบ **ไม่ใช่** เป็นนามทั่วไป

**ตัวอย่างที่ 4: เลือก แก่ หรือ แด่ ใน "นักเรียนมอบดอกไม้___คุณครู"**
ผู้รับเป็นผู้ใหญ่ที่เคารพ → **แด่**

## จุดที่มักสับสน

- **การ + นาม** (การบ้าน) ไม่ใช่อาการนาม
- **นี่ (สรรพนาม) vs นี้ (วิเศษณ์)**
- **ปฤจฉา vs อนิยมสรรพนาม**: ถามจริงหรือไม่
- **บุพบท vs วิเศษณ์**: บุพบทต้องมีนามตาม
- **สันธาน "และ" vs บุพบท "กับ"**: และ เชื่อมประโยค/คำที่เท่ากัน, กับ บอกการร่วมกัน
- **แก่ (ผู้น้อย) vs แด่ (ผู้ใหญ่)**
- **"เพราะ" ที่แปลว่าไพเราะ** เป็นวิเศษณ์ ไม่ใช่สันธาน เช่น ร้องเพลงเพราะ

## ⭐ Key Takeaways

- คำ 7 ชนิด: นาม สรรพนาม กริยา วิเศษณ์ บุพบท สันธาน อุทาน
- อาการนาม = การ/ความ + กริยา/วิเศษณ์
- สรรพนาม: บุรุษ ปฤจฉา นิยม อนิยม วิภาค (และประพันธ)
- กริยา: สกรรม อกรรม วิกตรรถ กริยานุเคราะห์
- วิเศษณ์: ลักษณ กาล สถาน ประมาณ ประติชญา ปฏิเสธ
- บุพบทต้องมีนามตาม; สันธานเชื่อมประโยค 4 ความสัมพันธ์
- ดูหน้าที่ในประโยคเสมอ
