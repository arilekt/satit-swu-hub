## เป้าหมายของบทนี้

- แยกกลุ่มคำ (วลี) 7 ชนิด และแยกวลีออกจากประโยค
- แยกภาคประธาน ภาคแสดง ประธาน กริยา กรรม และส่วนขยาย
- จำแนกประโยคตามโครงสร้าง: ความเดียว ความรวม ความซ้อน (และระบบ ประโยคสามัญ/รวม/ซ้อน)
- จำแนกประโยคตามเจตนา และตามรูปแบบการเน้น (ประธาน กรรม กริยา)

## 1. กลุ่มคำ / วลี

**วลี** คือคำตั้งแต่ 2 คำขึ้นไปเรียงกัน มีความหมาย แต่ **ยังไม่ครบเป็นประโยค** (ขาดประธานหรือกริยา)

KW: **ดูคำแรก** ว่าเป็นคำชนิดใด และดูว่า **ขาดองค์ประกอบ** ของประโยคหรือไม่

| วลี | คำแรก/หน้าที่ | ตัวอย่าง |
|---|---|---|
| นามวลี | ขึ้นต้นด้วยนาม | ผ้าทอพื้นบ้าน, นักเรียนชั้นประถมศึกษาปีที่หก |
| สรรพนามวลี | ขึ้นต้นด้วยสรรพนาม | เราทุกคน, ข้าพระพุทธเจ้า |
| กริยาวลี | ขึ้นต้นด้วยกริยา | โต้แย้ง, เหน็ดเหนื่อยเมื่อยล้า |
| วิเศษณ์วลี | ขยายแบบวิเศษณ์ | ก้องกังวาน, สุดที่จะพรรณนา |
| บุพบทวลี | ขึ้นต้นด้วยบุพบท | ท่ามกลางฝูงชน, ตามคำสั่งสอน |
| สันธานวลี | ทำหน้าที่เชื่อมแบบสันธาน | ถึงอย่างไรก็ตาม, ในระหว่างที่ |
| อุทานวลี | แสดงอารมณ์ | พุทโธ่เอ๋ย!, ตาเถรตกน้ำ! |

## 2. ส่วนประกอบของประโยค

ตัวอย่างในเอกสาร: **"น้องของฉันสวมเสื้อตัวใหญ่เป็นประจำ"**

| ภาคประธาน | | ภาคแสดง | | | |
|---|---|---|---|---|---|
| ประธาน | ขยายประธาน | กริยา | ขยายกริยา | กรรม | ขยายกรรม |
| น้อง | ของฉัน | สวม | เป็นประจำ | เสื้อ | ตัวใหญ่ |

มองเป็นกลุ่มใหญ่: **นามวลี/สรรพนามวลี** = ภาคประธาน ("น้องของฉัน") + **กริยาวลี** = ภาคแสดง ("สวมเสื้อตัวใหญ่เป็นประจำ")

## 3. ชนิดของประโยคตามโครงสร้าง

### ประโยคความเดียว

มีใจความสำคัญใจความเดียว: **ประธาน 1 + กริยาหลัก 1** (S + V)

| แบบ | ตัวอย่าง |
|---|---|
| ไม่มีกรรม | ฉัน / วิ่ง |
| มีกรรม | น้อง / สวม / รองเท้า |
| ใช้กริยาอาศัยส่วนเติมเต็ม | กีฬา / คือ / ยาวิเศษ |
| ใช้กริยาช่วย | นักเรียน / ต้อง / มี / ความรู้ |

### ประโยคสามัญ (ระบบที่หนังสือเรียนใหม่ใช้)

เอกสารเทียบ "ประโยคความเดียว VS ประโยคสามัญ": ประโยคสามัญมี **กริยาวลีเดียว** ซึ่งอาจมีกริยาหลายตัวเรียงกันเป็นกลุ่มเดียว
- พ่อกำลังรดน้ำต้นไม้, นิสัยของเขาเหมือนแม่มาก, ง่วงเหลือเกิน, หิวจังเลย
- กริยาเรียง: สมชายโบกมือลาพวกเรา, เราแวะไปเยี่ยมคุณตาที่บ้าน, คลื่นซัดบ้านพังหมด, ลมพัดสังกะสีปลิว

### ประโยคความซ้อน (ประโยคซ้อน)

**ประโยคหลัก + ประโยคย่อย (อนุประโยค)** ที่ทำหน้าที่เป็นส่วนหนึ่งของประโยคหลัก KW: S + V (ส่วนขยายมี V)

ตัวอย่างประโยคหลักที่มีอนุประโยคขยาย: ฉันมีหนังสือที่เขาไม่มี, สมบัติอันมีค่ามหาศาลถูกฝังอยู่ตรงนี้, พ่อซื้อบ้านที่มีขนาดใหญ่มาก, ฉันเห็นกระต่ายที่มีสีขาว

| อนุประโยค | หน้าที่ | ตัวอย่าง |
|---|---|---|
| นามานุประโยค | เป็นประธาน กรรม หรือส่วนเติมเต็ม (ทำหน้าที่แบบนาม) | คุณยายไม่ชอบ **คนรับประทานอาหารมูมมาม**, **คนขาดมารยาท** เป็นคนน่ารังเกียจ, ฉันรู้ **ว่าเขาไม่มา** |
| คุณานุประโยค | ขยายนาม/สรรพนาม มักตามหลัง ที่ ซึ่ง อัน | แม่ **ที่อยู่ต่างจังหวัด** จะเดินทางกลับมาวันนี้, เรารักแผ่นดินไทย **อันเป็นบ้านเกิดเมืองนอน** |
| วิเศษณานุประโยค | ขยายกริยา/วิเศษณ์ มักตามหลัง เมื่อ จน ตาม ขณะที่ | เขากลับไป **เมื่อฝนหยุดตก**, เขาทำงานหนัก **จนป่วยไปหลายวัน** |

### ประโยคความรวม (ประโยครวม)

นำ **ประโยคความเดียว 2 ประโยคขึ้นไปมารวมกัน โดยมีคำสันธานเชื่อม**

| โครงสร้าง | ตัวอย่าง |
|---|---|
| ประธาน 2 + กริยา 2 | ฉันกินข้าวแต่เธอกินขนม |
| ประธาน 2 + กริยา 1 | ฉันและเธอรักกัน (ตามเอกสาร) |
| ประธาน 1 + กริยา 2 | ฉันล้างหน้าแล้วไปนอน |

**ความสัมพันธ์ 4 แบบ** (ตรงกับคำสันธาน)

| แบบ | ตัวอย่าง |
|---|---|
| คล้อยตามกัน | คุณพ่อและคุณแม่รักฉันมาก |
| ขัดแย้งกัน | พี่เป็นคนขยันแต่น้องเกียจคร้าน |
| เป็นเหตุเป็นผล | เพราะเขาขยันจึงสอบได้โรงเรียนสาธิต |
| เลือกอย่างใดอย่างหนึ่ง | เธอจะกินหรือจะไปนอน |

**ประโยครวม** (ระบบใหม่) อาจรวมประโยคชนิดต่าง ๆ เข้าด้วยกัน
- สามัญ + สามัญ: วีรพลออกแบบและตัดเย็บเสื้อผ้าเอง
- ซ้อน + ซ้อน: เขากินอาหารที่มีประโยชน์และเขาดื่มน้ำที่มีคุณค่า
- สามัญ + ซ้อน: ชาวนาทำนาและเลี้ยงปลาที่กินวัชพืชในนา
- ซ้อน + สามัญ: ครูสั่งให้นักเรียนเงียบและตั้งใจเรียน

## 4. ชนิดของประโยคตามเจตนา

| เจตนา | ประโยค | สังเกต / ตัวอย่าง |
|---|---|---|
| แจ้งให้ทราบ | บอกเล่า / ปฏิเสธ | ฉันไปโรงเรียน / ฉันไม่ไปโรงเรียน |
| ถามให้ตอบ | คำถาม | เธอชื่ออะไร |
| บอกให้ทำ | คำสั่ง / ขอร้อง | ปิดประตูด้วย / กรุณาเงียบ |
| | เสนอแนะ | ลอง ควร นะ ซิ — "เธอควรพักผ่อนนะ" |
| | ห้าม | ห้าม อย่า — "ห้ามเด็กเล่นใกล้สระน้ำ" |
| | ชักชวน | "เราไปเที่ยวกันดีไหม" |
| | ขู่ | "เดี๋ยวโดนตี" |
| | คาดคะเน | คง อาจ น่าจะ — "พรุ่งนี้ฝนอาจจะตก" |

## 5. ชนิดของประโยคตามรูปแบบ (การเน้น)

| แบบ | ลักษณะ | ตัวอย่าง |
|---|---|---|
| เน้นประธาน | ประธานขึ้นก่อน (แบบไทยปกติ) | นายแดงกินข้าว, ฉันวิ่งออกกำลังกาย |
| เน้นกรรม | กรรม (ผู้ถูกกระทำ) ขึ้นก่อน | แมวถูกสุนัขกัด, ขนมถ้วยนี้แม่ทำ |
| เน้นกริยา | กริยาขึ้นก่อน ใช้กับ เกิด มี ปรากฏ เท่านั้น | เกิดเหตุการณ์ไม่คาดฝัน, มีคนมาหา |

(หน้า 44 หัวกล่องพิมพ์ว่า "ชนิดของประโยคตามเจตนา" แต่เนื้อหาเป็น "ตามรูปแบบ" ตามหัวกระดาษ และตัวอย่าง "เกิดเหตุการณ์ไม่คาดฝันเกิดขึ้น" มีคำว่าเกิดซ้ำ ในบทนี้ใช้ "เกิดเหตุการณ์ไม่คาดฝัน")

## ตัวอย่างวิธีคิด

**ตัวอย่างที่ 1: "บ้านที่อยู่ริมแม่น้ำถูกน้ำท่วม" เป็นประโยคแบบใด**
1. ประโยคหลัก: บ้าน / ถูกน้ำท่วม
2. "ที่อยู่ริมแม่น้ำ" มีกริยา (อยู่) และขยายนาม "บ้าน"
3. จึงเป็น **ประโยคความซ้อน** มี **คุณานุประโยค**

**ตัวอย่างที่ 2: "เด็กหญิงคนนั้นร้องเพลงเพราะ" เป็นความรวมไหม**
1. "เพราะ" ในที่นี้แปลว่า ไพเราะ (วิเศษณ์) ไม่ใช่สันธาน
2. มีประธาน 1 กริยาหลัก 1
3. ตอบ **ประโยคความเดียว**

**ตัวอย่างที่ 3: "นักเรียนที่ตั้งใจเรียนจะสอบได้คะแนนดีและครูจะชมเชย"**
1. ส่วนแรก "นักเรียนที่ตั้งใจเรียนจะสอบได้คะแนนดี" = ความซ้อน
2. ส่วนหลัง "ครูจะชมเชย" = ความเดียว
3. เชื่อมด้วย "และ" → **ประโยคความรวม** (ซ้อน + เดียว/สามัญ)

**ตัวอย่างที่ 4: "เราไปห้องสมุดด้วยกันไหม" มีเจตนาอะไร**
รูปเป็นคำถาม แต่ผู้พูดต้องการชวนให้ไปด้วยกัน → **ชักชวน**

## จุดที่มักสับสน

- **วลี vs ประโยค**: วลียังไม่มีภาคแสดงครบ เช่น "ผ้าทอพื้นบ้านของจังหวัดสุรินทร์"
- **ขยายกรรม vs ขยายกริยา**: "ตัวใหญ่" ขยายเสื้อ (กรรม) แต่ "เป็นประจำ" ขยายกริยาสวม
- **"ที่" นำคุณานุประโยค** ขยายนาม แต่ **"ว่า" นำนามานุประโยค** (เป็นกรรม)
- **"เพราะ" สองความหมาย**: สันธาน (เหตุผล) กับ วิเศษณ์ (ไพเราะ)
- **ประโยครวมที่มีประโยคซ้อนอยู่ข้างใน** ยังเรียกว่า ประโยครวม
- **รูปคำถามแต่เจตนาชักชวน** ดูเจตนาผู้พูด
- **เน้นกริยา** ใช้ได้กับ เกิด มี ปรากฏ เท่านั้น

## ⭐ Key Takeaways

- วลี 7 ชนิด ดูคำแรกและดูว่าขาดองค์ประกอบประโยค
- ประโยค = ภาคประธาน (ประธาน + ขยาย) + ภาคแสดง (กริยา ขยายกริยา กรรม ขยายกรรม)
- ความเดียว: S + V เดียว; ความรวม: ประโยค + สันธาน + ประโยค; ความซ้อน: ประโยคหลัก + อนุประโยค
- อนุประโยค 3 แบบ: นามานุ (แทนนาม) คุณานุ (ขยายนาม) วิเศษณานุ (ขยายกริยา)
- เจตนา: บอกเล่า/ปฏิเสธ คำถาม คำสั่ง ขอร้อง เสนอแนะ ห้าม ชักชวน ขู่ คาดคะเน
- รูปแบบ: เน้นประธาน เน้นกรรม เน้นกริยา (เกิด มี ปรากฏ)

## แผนทบทวน

- **วันนี้**: ดูคลิปแล้วเติมช่องว่างในเอกสารหน้า 40–44 (PDF) และแยกส่วนประกอบประโยค 5 ประโยคลงตาราง
- **พรุ่งนี้**: แต่งประโยคความเดียว ความรวม (4 ความสัมพันธ์) และความซ้อน (3 อนุประโยค) อย่างละ 1 ประโยค
- **อีก 3 วัน**: อ่านนิทาน 1 เรื่อง หาประโยคความซ้อน 3 ประโยคและบอกชนิดอนุประโยค
- **อีก 1 สัปดาห์**: ทำแบบทดสอบท้ายบท แล้วทบทวนหัวข้อที่ผิด
