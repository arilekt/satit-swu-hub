questions:
- question: If you heat ice, it ______.
  options:
  - melted
  - would melt
  - had melted
  - melts
  answer: 3
  explanation: 'ข้อถูก: ความจริงทางวิทยาศาสตร์ใช้ Type 0 (If + V1, V1) จึงเป็น melts / ตัวลวง: melted เป็นอดีต, would melt เป็นผลของ Type 2 (สมมติ) ซึ่งไม่ตรงกับ If-clause ปัจจุบัน, had melted เป็น Past Perfect'
- question: If it rains tomorrow, we ______ at home and watch movies.
  options:
  - stayed
  - would have stayed
  - will stay
  - staying
  answer: 2
  explanation: 'ข้อถูก: เหตุการณ์ที่เป็นไปได้จริงในอนาคต (tomorrow) ใช้ Type 1: If + V1, will + Vinf / ตัวลวง: stayed เป็นอดีต, would have stayed เป็นผลของ Type 3 (อดีต), staying ขาดกริยาแท้'
- question: If I ______ a lot of money, I would buy a big house for my parents.
  options:
  - had
  - have
  - will have
  - has had
  answer: 0
  explanation: 'ข้อถูก: main clause ใช้ would + Vinf เป็น Type 2 ดังนั้น If-clause ใช้ V2 คือ had / ตัวลวง: have เป็น Type 1, will have ใช้ will ใน If-clause ไม่ได้, has had ผิดทั้งประธาน I และโครงสร้าง'
- question: If I ______ you, I would study harder for the test.
  options:
  - were
  - am
  - will be
  - been
  answer: 0
  explanation: 'ข้อถูก: If I were you, I would ... เป็น Type 2 สำหรับให้คำแนะนำ ใช้ were กับทุกประธาน / ตัวลวง: am เป็นปัจจุบันจริงซึ่งเราเป็นอีกคนไม่ได้, will be ใช้ will ใน If-clause ไม่ได้, been ต้องมี have/had นำหน้า'
- question: If she had studied harder, she ______ the exam last week.
  options:
  - would have passed
  - will pass
  - would pass
  - passes
  answer: 0
  explanation: 'ข้อถูก: If + had + V3 และเป็นเรื่องอดีต (last week) จึงเป็น Type 3 ผลคือ would have + V3 / ตัวลวง: will pass เป็นผลของ Type 1, would pass เป็นผลของ Type 2 (ปัจจุบัน) ไม่เข้ากับ last week, passes เป็น Present Simple'
- question: '"If I had wings, I would fly to the moon." ข้อใดคือความจริง'
  options:
  - ผู้พูดมีปีก
  - ผู้พูดเคยบินไปดวงจันทร์
  - ผู้พูดไม่มีปีก
  - ผู้พูดจะบินไปดวงจันทร์พรุ่งนี้
  answer: 2
  explanation: 'ข้อถูก: Type 2 เป็นการสมมติสิ่งที่ไม่จริงในปัจจุบัน If I had wings จึงหมายความว่าความจริงคือไม่มีปีก / ตัวลวง: ''มีปีก'' ตรงข้ามความจริง, ''เคยบินไปดวงจันทร์'' ไม่มีในประโยค, ''จะบินพรุ่งนี้'' ทำไม่ได้เพราะเป็นเพียงการสมมติ'
- question: Unless you hurry, you ______ the school bus.
  options:
  - would have missed
  - missed
  - missing
  - will miss
  answer: 3
  explanation: 'ข้อถูก: Unless = If ... not เป็นเงื่อนไขที่เป็นไปได้จริง (Type 1) ผลจึงใช้ will + Vinf / ตัวลวง: would have missed เป็น Type 3, missed เป็นอดีต, missing ขาดกริยาแท้'
- question: I don't have a bike. I wish I ______ a bike.
  options:
  - have
  - had
  - will have
  - having
  answer: 1
  explanation: 'ข้อถูก: wish สิ่งที่ไม่จริงในปัจจุบันใช้ S + wish + S + V2 จึงเป็น had / ตัวลวง: have ไม่ถอย tense, will have ใช้ will ผิดโครงสร้าง (ถ้าอนาคตใช้ would), having ขาดกริยาแท้'
- question: I didn't go to Ploy's party last night. Now I wish I ______ to the party.
  options:
  - went
  - had gone
  - go
  - have gone
  answer: 1
  explanation: 'ข้อถูก: wish สิ่งที่ไม่จริงในอดีต (last night) ใช้ S + wish + S + had + V3 → had gone / ตัวลวง: went ใช้กับ wish เรื่องปัจจุบัน, go ไม่ถอย tense, have gone เป็น Present Perfect ไม่ใช่โครงสร้าง wish อดีต'
- question: We wish you ______ happy New Year!
  options:
  - to
  - a
  - for
  - with
  answer: 1
  explanation: 'ข้อถูก: wish + คน + สิ่งที่อวยพร (a happy New Year) จึงใช้ a / ตัวลวง: to, for และ with ไม่ใช้ในโครงสร้างอวยพร wish + O + N'
- question: Good morning. I wish ______ to the manager, please.
  options:
  - speak
  - to speak
  - speaking
  - spoke
  answer: 1
  explanation: 'ข้อถูก: wish ในความหมาย ''ต้องการ'' (ทางการ) ใช้ wish + to + Vinf / ตัวลวง: speak ขาด to, speaking ใช้ V-ing หลัง wish ไม่ได้, spoke เป็นอดีตซึ่งใช้กับ wish + S + V2 เท่านั้น ไม่ใช่ wish + V2 ตรง ๆ'
- question: My birthday is ______ May.
  options:
  - 'on'
  - at
  - by
  - in
  answer: 3
  explanation: 'ข้อถูก: เดือนใช้ in / ตัวลวง: on ใช้กับวันหรือวันที่ (on 5 May), at ใช้กับเวลาตามนาฬิกา, by แปลว่าภายใน/โดย ไม่ใช่การบอกเดือนเกิด'
- question: Our English class starts ______ 8:30.
  options:
  - in
  - 'on'
  - since
  - at
  answer: 3
  explanation: 'ข้อถูก: เวลาตามนาฬิกาใช้ at / ตัวลวง: in ใช้กับเดือน ปี ช่วงของวัน, on ใช้กับวันและวันที่, since ใช้กับ Present Perfect บอกจุดเริ่มต้น'
- question: We are having a family dinner ______ Saturday evening.
  options:
  - in
  - 'on'
  - at
  - for
  answer: 1
  explanation: 'ข้อถูก: มีวันเจาะจง (Saturday) จึงใช้ on แม้จะตามด้วย evening / ตัวลวง: in ใช้กับ in the evening เมื่อไม่ระบุวัน, at ใช้กับเวลาเป็นจุด, for ใช้บอกระยะเวลา'
- question: (แมวอยู่ใต้โต๊ะ) The cat is ______ the table.
  options:
  - under
  - above
  - 'on'
  - behind
  answer: 0
  explanation: 'ข้อถูก: ''ใต้'' ใช้ under / ตัวลวง: above แปลว่าเหนือ, on แปลว่าบน (สัมผัสพื้นผิว), behind แปลว่าข้างหลัง'
- question: (สมชายเดินเข้าไปในห้องแล้วนั่งลง) Somchai walked ______ the room and sat down.
  options:
  - out of
  - across
  - along
  - into
  answer: 3
  explanation: 'ข้อถูก: การเคลื่อนเข้าไปข้างในใช้ into / ตัวลวง: out of แปลว่าออกจาก, across แปลว่าข้าม, along แปลว่าไปตามแนว ไม่ตรงกับความหมายเดินเข้าไป'
- question: My house is near my school, so I usually go there ______ foot.
  options:
  - by
  - with
  - 'on'
  - in
  answer: 2
  explanation: 'ข้อถูก: การเดินใช้สำนวน on foot / ตัวลวง: by ใช้กับพาหนะ (by bus) แต่ by foot ไม่ใช่รูปมาตรฐาน, with ใช้กับเครื่องมือ, in ไม่ใช้กับ foot ในความหมายนี้'
- question: We stayed at home all day ______ the heavy rain.
  options:
  - because
  - although
  - because of
  - unless
  answer: 2
  explanation: 'ข้อถูก: หลังช่องว่างเป็นนาม (the heavy rain) และบอกเหตุผล จึงใช้ because of / ตัวลวง: because ต้องตามด้วยประโยค (because it rained), although แปลว่าแม้ว่าและต้องตามด้วยประโยค, unless แปลว่าถ้า...ไม่'
- question: Which conditional sentence is correct?
  options:
  - If he was here, he will help us.
  - If he is here, he would help us.
  - If he were here, he would help us.
  - If he will be here, he helps us.
  answer: 2
  explanation: 'ข้อถูก: Type 2 ใช้ If + were, would + Vinf สอดคล้องกัน / ตัวลวง: was ... will help ผสม Type 2 กับ Type 1, is ... would help ผสม Type 1 กับ Type 2, will be ใช้ will ใน If-clause ไม่ได้'
- question: Pojai was born ______ 2014, ______ June 5th.
  options:
  - in / on
  - on / in
  - at / on
  - in / at
  answer: 0
  explanation: 'ข้อถูก: ปีใช้ in (in 2014) และวันที่ใช้ on (on June 5th) / ตัวลวง: on / in สลับกัน, at ใช้กับเวลาตามนาฬิกาไม่ใช่ปี, at กับวันที่ก็ผิดเช่นกัน'
