- question: ข้อใดแสดงสมบัติการแจกแจง
  options:
  - a(b + c) = ab + ac
  - (a + b) + c = a + (b + c)
  - a + 0 = a
  - a + b = b + a
  answer: 0
  explanation: 'ข้อถูก: a(b + c) = ab + ac คือการแจกแจง (กระจายตัวคูณเข้าไปคูณทุกพจน์ในวงเล็บ) / ตัวลวง: a + b = b + a คือสมบัติการสลับที่, (a + b) + c = a + (b + c) คือสมบัติการเปลี่ยนหมู่, a + 0 = a คือสมบัติเอกลักษณ์การบวก'
