- question: คำสมาสเกิดจากการรวมคำในภาษาใด
  options:
  - ภาษาไทยกับภาษาบาลี
  - ภาษาเขมรกับภาษาสันสกฤต
  - ภาษาใดก็ได้ที่มี 2 คำขึ้นไป
  - ภาษาบาลีและสันสกฤตเท่านั้น
  answer: 3
  explanation: 'ข้อถูก: คำสมาสต้องเป็นคำบาลีหรือสันสกฤตทั้งหมด / ตัวลวง: ถ้ามีคำไทยหรือเขมรปนอยู่จะเป็นคำประสม ไม่ใช่สมาส และการรวมคำภาษาใดก็ได้คือหลักของคำประสม'
- question: คำใดเป็นคำสมาส
  options:
  - ราชวัง
  - ผลไม้
  - อุบัติเหตุ
  - ทหารเรือ
  answer: 2
  explanation: 'ข้อถูก: อุบัติเหตุ = อุบัติ + เหตุ เป็นคำบาลี/สันสกฤตทั้งคู่ และอ่านเชื่อมเสียง อุ-บัด-ติ-เหด / ตัวลวง: ราชวัง (วัง เป็นคำไทย) ผลไม้ (ไม้ เป็นคำไทย) ทหารเรือ (เรือ เป็นคำไทย) จึงเป็นคำประสม'
- question: คำว่า "มัจจุราช" มีความหมายว่าอย่างไร
  options:
  - ความตายของพระราชา
  - เจ้าแห่งความตาย
  - พระราชาผู้ล่วงลับ
  - ราชการที่เกี่ยวกับความตาย
  answer: 1
  explanation: 'ข้อถูก: คำสมาสแปลจากหลังมาหน้า ราช (เจ้า/ราชา) แห่ง มัจจุ (ความตาย) จึงได้ เจ้าแห่งความตาย / ตัวลวง: ความตายของพระราชาและพระราชาผู้ล่วงลับเป็นการแปลจากหน้าไปหลัง, ราชการ ไม่เกี่ยวกับความหมายของคำนี้'
- question: ข้อใดอ่านคำสมาสได้ถูกต้อง
  options:
  - ภูมิศาสตร์ อ่านว่า พู-มิ-สาด
  - เอกราช อ่านว่า เอก-ราด
  - อุบัติเหตุ อ่านว่า อุ-บัด-เหด
  - ราชการ อ่านว่า ราด-การ
  answer: 0
  explanation: 'ข้อถูก: ภูมิศาสตร์ อ่านเชื่อมเสียง มิ ระหว่างคำ เป็น พู-มิ-สาด / ตัวลวง: เอกราช ต้องอ่าน เอก-กะ-ราด, อุบัติเหตุ ต้องอ่าน อุ-บัด-ติ-เหด, ราชการ ต้องอ่าน ราด-ชะ-กาน ล้วนขาดเสียงเชื่อม'
- question: วิทยา + อาลัย สนธิกันแล้วได้คำใด
  options:
  - วิทยาอาลัย
  - วิทยอาลัย
  - วิทยลัย
  - วิทยาลัย
  answer: 3
  explanation: 'ข้อถูก: สระสนธิ ตัดสระท้ายคำหน้าแล้วใช้สระ อา ของคำหลัง ได้ วิทยาลัย / ตัวลวง: วิทยาอาลัย และ วิทยอาลัย ยังไม่ได้หลอมเสียง, วิทยลัย ตัดเสียง อา หายไปจึงผิด'
- question: ธนุ + อาคม สนธิกันแล้วได้คำใด
  options:
  - ธนุอาคม
  - ธันวาคม
  - ธนาคม
  - ธนอาคม
  answer: 1
  explanation: 'ข้อถูก: สระ อุ ท้ายคำ ธนุ เปลี่ยนเป็น ว แล้วต่อกับสระ อา ของ อาคม ได้ ธันวาคม (ชื่อเดือน) / ตัวลวง: ธนุอาคม และ ธนอาคม ไม่ได้หลอมเสียง, ธนาคม ตัดเสียง อุ ทิ้งไปเฉย ๆ ไม่ใช่รูปสนธิที่ใช้จริง'
- question: สํ + อาคม สนธิกันแล้วได้คำใด
  options:
  - สังคม
  - สัมคม
  - สมาคม
  - สนาคม
  answer: 2
  explanation: 'ข้อถูก: นิคหิตสนธิกับคำที่ขึ้นต้นด้วยสระ นิคหิตเปลี่ยนเป็น ม ได้ สมาคม / ตัวลวง: สังคม มาจาก สํ + คม (คำหลังขึ้นต้นด้วยพยัญชนะ), สัมคม และ สนาคม ไม่ใช่รูปสนธิที่ถูกต้อง'
- question: คำใดเกิดจากนิคหิตสนธิ
  options:
  - สัมพันธ์
  - นิรภัย
  - ชิโนรส
  - ราชการ
  answer: 0
  explanation: 'ข้อถูก: สัมพันธ์ = สํ + พันธ์ นิคหิตเปลี่ยนเป็น ม ตามวรรคของ พ / ตัวลวง: นิรภัย เป็นพยัญชนะสนธิ (นิร + ภัย), ชิโนรส เป็นสระสนธิ (ชิน + โอรส), ราชการ เป็นสมาสธรรมดาไม่มีสนธิ'
- question: คำใดเป็นคำสมาสแบบไม่มีสนธิ (นำคำมาชนกันโดยไม่เปลี่ยนเสียง)
  options:
  - ธนบัตร
  - วิทยาลัย
  - นรินทร์
  - สมาคม
  answer: 0
  explanation: 'ข้อถูก: ธนบัตร = ธน + บัตร นำมาต่อกันตรง ๆ ไม่มีการหลอมเสียง / ตัวลวง: วิทยาลัย (วิทยา+อาลัย) และ นรินทร์ (นร+อินทร์) เป็นสระสนธิ, สมาคม (สํ+อาคม) เป็นนิคหิตสนธิ'
- question: ข้อใดเป็นคำไทยแท้ทุกคำ
  options:
  - ภาพ เมฆ กิน นอน
  - ขนม ถนน พ่อ แม่
  - รถ ครู พ่อ แม่
  - พ่อ แม่ กิน นอน
  answer: 3
  explanation: 'ข้อถูก: พ่อ แม่ กิน นอน เป็นคำพยางค์เดียว สะกดตรงมาตรา ไม่มีการันต์ เป็นคำไทยแท้ / ตัวลวง: ภาพ เมฆ เป็นคำบาลี/สันสกฤต, ขนม ถนน เป็นคำเขมร, รถ (บาลี) ครู (สันสกฤต) เป็นคำยืม'
- question: คำใดเป็นคำยืมจากภาษาเขมร
  options:
  - กีฬา
  - ศึกษา
  - เสด็จ
  - บะหมี่
  answer: 2
  explanation: 'ข้อถูก: เสด็จ สะกดด้วย จ และเป็นคำราชาศัพท์ ตรงกับลักษณะภาษาเขมร / ตัวลวง: กีฬา ใช้ ฬ เป็นภาษาบาลี, ศึกษา ใช้ ศ ษ เป็นภาษาสันสกฤต, บะหมี่ เป็นภาษาจีน'
- question: คำแผลงแบบภาษาเขมรของคำว่า "จ่าย" คือข้อใด
  options:
  - จับจ่าย
  - จำหน่าย
  - จำจ่าย
  - จ่ายจำ
  answer: 1
  explanation: 'ข้อถูก: จ่าย แผลงเป็น จำหน่าย (เติม อำ และ น) เหมือน เดิน เป็น ดำเนิน / ตัวลวง: จับจ่าย เป็นคำซ้อน ไม่ใช่คำแผลง, จำจ่าย และ จ่ายจำ ไม่ใช่คำในภาษาไทย'
- question: คำที่ขึ้นต้นด้วย "บรร" คำใดไม่ใช่คำยืมภาษาเขมร
  options:
  - บรรทม
  - บรรจุ
  - บรรเทา
  - บรรพต
  answer: 3
  explanation: 'ข้อถูก: บรรพต (ภูเขา) มาจากภาษาสันสกฤต จึงเป็นข้อควรระวังที่เอกสารใส่ดอกจันไว้ / ตัวลวง: บรรทม บรรจุ บรรเทา เป็นคำเขมรที่ขึ้นต้นด้วย บรร ตามลักษณะทั่วไป'
- question: คำใดเป็นคำยืมภาษาบาลี
  options:
  - กรีฑา
  - ศิลปะ
  - กีฬา
  - ธรรม
  answer: 2
  explanation: 'ข้อถูก: กีฬา ใช้ ฬ ซึ่งภาษาบาลีนิยมใช้ / ตัวลวง: กรีฑา ใช้ ฑ และมีควบกล้ำแบบสันสกฤต, ศิลปะ ใช้ ศ เป็นสันสกฤต, ธรรม ใช้ รร เป็นสันสกฤต'
- question: คำใดเป็นคำยืมภาษาสันสกฤต
  options:
  - วิชา
  - วิทยา
  - ภิกขุ
  - อัคคี
  answer: 1
  explanation: 'ข้อถูก: วิทยา เป็นรูปสันสกฤต คู่กับ วิชา ที่เป็นรูปบาลี / ตัวลวง: วิชา ภิกขุ (สันสกฤตคือ ภิกษุ) และ อัคคี (สันสกฤตคือ อัคนี) เป็นรูปภาษาบาลี'
- question: คำใดใช้ตัวสะกดตัวตามตามหลักภาษาบาลี
  options:
  - เมตตา
  - สัตย์
  - ธรรม
  - จักร
  answer: 0
  explanation: 'ข้อถูก: เมตตา มี ต สะกดและ ต ตาม (พยัญชนะวรรคเดียวกัน ตัวที่ 1 ตามด้วยตัวที่ 1) ตรงหลักบาลี / ตัวลวง: สัตย์ (ย การันต์) ธรรม (รร) จักร (ร ตามตัวสะกด) เป็นลักษณะภาษาสันสกฤต'
- question: ข้อใดเขียนคำทับศัพท์ได้ถูกต้องตามหลักราชบัณฑิตยสถาน
  options:
  - อัพเดท
  - เฟสบุ๊ค
  - อัปเดต
  - โควต้า
  answer: 2
  explanation: 'ข้อถูก: อัปเดต เขียนตามหลักทับศัพท์ / ตัวลวง: อัพเดท ต้องเขียน อัปเดต, เฟสบุ๊ค ต้องเขียน เฟซบุ๊ก, โควต้า ต้องเขียน โควตา (ไม่ใส่ไม้โท)'
- question: ข้อใดเป็นคำยืมภาษาจีนทุกคำ
  options:
  - เก้าอี้ ซามูไร บะหมี่
  - เก้าอี้ เต้าหู้ ก๋วยเตี๋ยว
  - บุหงา เต้าหู้ เก๊กฮวย
  - โมจิ เก๊กฮวย กิโมโน
  answer: 1
  explanation: 'ข้อถูก: เก้าอี้ เต้าหู้ ก๋วยเตี๋ยว เป็นคำจีนทั้งหมด / ตัวลวง: ซามูไร โมจิ กิโมโน เป็นคำญี่ปุ่น, บุหงา เป็นคำชวา ทำให้ชุดอื่นไม่ใช่ภาษาจีนทั้งหมด'
- question: คำว่า "บุหลัน" มาจากภาษาใด และมีความหมายว่าอะไร
  options:
  - ภาษาชวา แปลว่า ดวงจันทร์
  - ภาษาชวา แปลว่า ดอกไม้
  - ภาษาญี่ปุ่น แปลว่า ดวงจันทร์
  - ภาษาจีน แปลว่า ดอกไม้
  answer: 0
  explanation: 'ข้อถูก: บุหลัน เป็นคำชวา แปลว่า ดวงจันทร์ / ตัวลวง: คำชวาที่แปลว่าดอกไม้คือ บุหงา, บุหลันไม่ได้มาจากภาษาญี่ปุ่นหรือจีน'
- question: คำว่า "สมุทัย" เกิดจากการสร้างคำแบบใด
  options:
  - สระสนธิ (สมุ + อุทัย)
  - พยัญชนะสนธิ (สมุท + ทัย)
  - สมาสแบบไม่มีสนธิ (สมุ + ทัย)
  - นิคหิตสนธิ (สํ + อุทัย)
  answer: 3
  explanation: 'ข้อถูก: สมุทัย = สํ + อุทัย คำหลังขึ้นต้นด้วยสระ นิคหิตจึงเปลี่ยนเป็น ม ได้ สมุ- (แบบเดียวกับ สมาคม สโมสร) / ตัวลวง: สมุ ไม่ใช่คำเดิม จึงไม่ใช่สระสนธิ, ไม่มีคำ นิร หรือ ทุร จึงไม่ใช่พยัญชนะสนธิ, และมีการเปลี่ยนเสียงนิคหิตจึงไม่ใช่สมาสธรรมดา'
