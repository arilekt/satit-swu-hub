    บทเรียน

    กำลังโหลดบทเรียน…

    ผลเรียนและวันสอบที่ตั้งเองซิงก์ผ่าน Google Sheet เมื่อเข้าสู่ระบบ ส่วนกิจกรรมที่แก้ในหน้านี้ยังบันทึกเฉพาะเบราว์เซอร์เครื่องนี้ หากต้องการให้ทุกเครื่องเห็นตรงกัน ให้ส่งออกไฟล์กิจกรรมแล้วนำไปอัปเดตใน repository

    บัญชี Google และการบันทึกลง Google Sheet

    เข้าสู่ระบบด้วยบัญชี Google ที่คุณพ่ออนุญาตไว้ ผลเรียน ประวัติข้อสอบ และวันสอบที่ตั้งเองจะบันทึกลง Google Sheet และใช้ร่วมกันได้ทุกเครื่องที่เข้าสู่ระบบ

    ยังไม่ได้ตั้งค่า Google Sheet ดูวิธีตั้งค่าใน docs/GOOGLE-SHEET-SYNC.md

    กำหนดสอบภาคปกติ

    การเตือนตรวจผลแสดงเมื่อเปิด Dashboard หลังวัน Pre-Test ไม่มีการแจ้งเตือนเมื่อปิดเว็บ

    จัดการกิจกรรมอื่น

    เพิ่มหรือแก้กิจกรรม เช่น สัมมนา นัดติว หรือวันไปงานนิทรรศการ

    ผลเรียนและการสำรองข้อมูล

    เอกสาร → บทเรียนและข้อสอบ

    วางเอกสารใน local/inbox/ชื่อวิชา/ บนคอมพิวเตอร์ แล้วสั่ง Python ตามคู่มือ เครื่องมือ AI อยู่บนเครื่องคุณพ่อ ไม่เรียก API จากเว็บของพอใจ
